# AISLE 系統架構

多功能、模組化的內部網頁系統。依「身份」(EE / PE) 決定每位使用者能看到哪些功能頁面，介面採用駭客任務 (The Matrix) 綠色終端機風格。

| 層級 | 技術 | 備註 |
|---|---|---|
| 後端 | PHP 5.4 | 不使用 5.5+ 語法；資料庫一律 PDO prepared statement |
| 資料庫 | MariaDB 5.5 / 10.x | InnoDB、utf8mb4 |
| 輔助腳本 | Python 2.7、Bash | 權限檢查、建帳號、備份、產生模組 |
| 前端 | HTML5、jQuery 1.12.4、原生 Canvas | 不需要 Node / 建置工具 |

## 2. 資料庫

`sql/schema.sql` 建立三張表：

| 資料表 | 用途 |
|---|---|
| `users` | 帳號 `account`、密碼雜湊 `password_hash`、身份 `role`、啟用狀態、失敗次數與鎖定時間、強制改密碼旗標、最後登入時間與 IP |
| `login_logs` | 每次登入嘗試（成功或失敗原因），供稽核與暴力破解追查 |
| `audit_logs` | 模組操作紀錄，例如匯出報表、建立帳號、重設密碼 |

設計重點：

- **`role` 用 VARCHAR 而非 ENUM**：新增身份只要改 `config.ini`，不必 `ALTER TABLE`。
- **`password_hash` 留 255 長度**：目前 bcrypt 固定 60 字元，保留未來更換演算法的空間。
- **`created_at` 用 DATETIME 由程式寫入**：MariaDB 5.5 一張表只能有一個 TIMESTAMP 使用 `CURRENT_TIMESTAMP`，這個位置留給 `updated_at`。
- 有索引的 VARCHAR 欄位長度 ≤ 191，避免舊版 InnoDB 在 utf8mb4 下超過 767 bytes 索引上限。

### 密碼雜湊（PHP 5.4 的做法）

`password_hash()` / `password_verify()` 是 PHP 5.5 才有的函式。`core/password_compat.php` 在函式不存在時補上同名函式：以 `crypt()` 搭配 `$2y$` bcrypt（PHP ≥ 5.3.7 支援），鹽來自 `openssl_random_pseudo_bytes`，驗證時使用常數時間比較。因此程式碼照標準 API 寫 `password_hash($pw, PASSWORD_BCRYPT)`，在 PHP 5.4 與 5.5+ 都能執行，雜湊格式也完全相同；日後升級 PHP 只要刪掉這個檔案，舊密碼不需重設。

## 3. 身份 → 頁面權限與路由（`config/config.ini` + `core/auth_check.php`）

### config.ini

```ini
[roles]
EE    = "EE 工程師"
PE    = "PE 工程師"
ADMIN = "系統管理員"

; ★ 身份 → 可用頁面清單。同一頁面同時列在 EE 與 PE 就是兩者都能看；"*" = 全部
[access]
EE    = "dashboard, shared_report, report_daily, report_weekly, ee_equipment, ee_daily_check, profile"
PE    = "dashboard, shared_report, report_daily, report_weekly, pe_recipe, pe_notice, profile"
ADMIN = "*"

; ★ 選單分類（選用）：可收折，頁面寫 group = "report" 就收在這底下
[group.report]
title = "共用報表 // REPORTS"
order = 20
open  = Off                           ; 預設收起；瀏覽器會記住使用者的展開狀態

; ★ 頁面與路由
[page.shared_report]
title = "Report1 // 綜合報表"
route = "module:shared_report"        ; modules/shared_report/controller.php
group = "report"
order = 1                             ; 分類內的排序
action.export = "PE"                  ; EE、PE 都能看，只有 PE 能匯出

[page.report_daily]
title = "Report2 // 日報"
route = "pages/report_daily.php"
group = "report"
order = 2

[page.ee_daily_check]
title = "每日點檢 // DAILY CHECK"
route = "pages/ee_daily_check.php"    ; 一般 PHP 頁面

[page.pe_notice]
title = "製程公告 // NOTICE"
route = "public/legacy/pe_notice.php" ; 既有的獨立頁面
```

選單分類只影響顯示：權限仍由 `[access]` 決定，某身份在分類裡看不到任何頁面時整個分類不會出現；目前所在頁面的分類一律展開；沒寫 `group` 的頁面照舊單層顯示。

`route` 有三種寫法：

| route | 程式位置 | 網址 | 適合 |
|---|---|---|---|
| `module:<資料夾>` | `modules/<資料夾>/controller.php` | `index.php?m=<代號>&a=<動作>` | 有多個動作、AJAX 的功能 |
| `pages/xxx.php` | `pages/xxx.php` | `index.php?m=<代號>` | 單純頁面，不用寫 Controller，自動套用版面 |
| `public/xxx.php` | `public/xxx.php` | 直接開啟該檔案 | 既有網站的舊頁面，只需在第一行加一行 require |

### auth_check.php：所有頁面共用同一套檢查

```
使用者開啟頁面
  ├─ index.php?m=xxx  →  App 路由 ──────────┐
  └─ public/legacy/xxx.php（第一行 require）─┤
                                             ▼
                              core/auth_check.php
                    1. 未登入           → 導向 login.php（AJAX 回 401）
                    2. 頁面未登記在 config.ini → 403
                    3. 首次登入未改密碼 → 導向個人設定
                    4. 身份不在 [access] 清單、或不符 action.* → 403
                                             ▼
                          通過 → 依 route 載入頁面程式
```

既有頁面接上權限只要在第一行加入（依檔案位置調整 `../`）：

```php
<?php require_once dirname(__FILE__) . '/../../core/auth_check.php';
// 通過檢查後才會執行到這裡；可用 $AUTH_USER、$AUTH_PAGE
```

auth_check.php 用「目前執行的檔案」對照 config.ini 的 route 找出頁面代號，所以頁面本身不用寫自己的代號或身份。檔案若沒登記在 config.ini，即使加了 require 也一律拒絕，避免漏設權限的頁面被看到。獨立頁面送出 POST 時會檢查 CSRF，舊表單請加上 `<?php echo csrf_field(); ?>`；若一時無法修改，可把 `[settings] direct_page_csrf` 設為 `Off`。

權限一律在伺服器端檢查，隱藏選單只是介面效果；直接輸入網址也會得到 403。目前範例的結果：

| 頁面 | EE | PE | ADMIN |
|---|:-:|:-:|:-:|
| 主控台 dashboard | ✓ | ✓ | ✓ |
| 共用報表 › Report1 shared_report | ✓（不可匯出） | ✓ | ✓ |
| 共用報表 › Report2 report_daily、Report3 report_weekly（pages/） | ✓ | ✓ | ✓ |
| 個人設定 profile | ✓ | ✓ | ✓ |
| 設備狀態 ee_equipment | ✓ | | ✓ |
| 每日點檢 ee_daily_check（pages/） | ✓ | | ✓ |
| 製程配方 pe_recipe | | ✓ | ✓ |
| 製程公告 pe_notice（獨立頁面） | | ✓ | ✓ |
| 圖表 › M1BF m1bf（module:charts） | ✓ | ✓ | ✓ |
| 使用者管理 admin_users | | | ✓ |

修改 config.ini 後執行 `python scripts/python/check_config.py`，會列出每個身份可用的頁面，並檢查拼字、route 檔案是否存在、獨立頁面有沒有 require auth_check.php。

## 4. 註冊、登入、登出與權限檢查

### 流程

| 檔案 | 方法 | 行為 |
|---|---|---|
| `public/register.php` | GET | 註冊頁 |
| | GET `?check_account=xxx`（AJAX） | 回傳帳號是否可用 |
| | POST | 驗證 → 依 EE 名單判定身份 → 寫入 `users`，並在 `audit_logs` 記錄身份來源 |
| `public/login.php` | GET / POST | 驗證帳密，成功後 `session_regenerate_id()` 並把使用者與身份寫入 `$_SESSION['user']` |
| `public/logout.php` | POST（或 `?_csrf=`） | 清除 Session 與 Cookie，導回 `login.php?bye=1` |

登入與註冊表單由 `js/auth.js` 以 jQuery 做即時驗證，並用 `$.ajax` 非同步送出，伺服器回 JSON。瀏覽器關閉 JavaScript 時表單照常以一般 POST 送出，伺服器端也會做完整驗證。

### 註冊時的身份判定（`config.ini` 的 `[register]` 與 `[ee_accounts]`）

註冊表單只填帳號、顯示名稱與密碼。身份在註冊當下依 INI 名單判定，直接寫入 `users.role`：

```ini
[register]
enabled          = On
require_approval = Off     ; On = 註冊後需管理員啟用
listed_role      = "EE"    ; 名單上的帳號
unlisted_role    = "PE"    ; 名單外的帳號；設為 "" 則名單外不能註冊

[ee_accounts]              ; EE 正面表列，一行一個帳號，不分大小寫
account[] = "neo"
account[] = "trinity"
```

- 名單只在註冊時讀取。之後增減名單，不會改變已經註冊的人的身份，要調整請直接改資料庫的 `users.role`。
- ADMIN 永遠無法經由註冊取得；`listed_role`、`unlisted_role` 若設成 superuser 角色會被忽略。
- `audit_logs` 會記錄每個帳號的身份來源（`ee_accounts` 或 `unlisted_role`）。
- 改完名單可以執行 `python scripts/python/check_config.py`，它會列出名單內容，並檢查帳號格式與重複。

### 共用權限檢查函式（`core/guard.php`）

```php
require_login();                    // 未登入 → 導向 login.php；AJAX 回 401
require_role('PE');                 // 身份不符 → 403（ADMIN 一律通過）
require_role('EE,PE');              // 多個身份用逗號
if (has_role('EE,PE')) { ... }      // 只判斷、不中止
if (can_access('shared_report', 'export')) { ... }   // 依 [access] 與 [page.xxx] 判斷
echo csrf_field();                  // 表單的 CSRF 隱藏欄位
current_user();  current_role();  is_logged_in();
```

頁面層級的權限由 `auth_check.php` 處理；這些函式用在頁面內更細的判斷，例如只對某身份顯示某個按鈕。

## 5. 新增功能頁面

只需要改 config.ini，核心程式（`core/`）不用動：

1. 放好頁面程式（擇一）：`pages/xxx.php`、`public/xxx.php`（第一行 require auth_check.php），或建立模組
2. 在 `[access]` 把頁面代號加進能使用它的身份
3. 新增 `[page.xxx]`，寫上 `title` 與 `route`
4. （選用）要放進選單分類就加上 `group = "<分類代號>"`；新分類再加一段 `[group.<分類代號>]`

例：新增一個 EE、PE 都能看的聯絡人頁面

```ini
[access]
EE = "dashboard, ..., team_contacts"
PE = "dashboard, ..., team_contacts"

[page.team_contacts]
title = "聯絡人 // CONTACTS"
route = "pages/team_contacts.php"
order = 60
```

需要多個動作或 AJAX 時用模組，腳本會產生程式骨架並自動完成上面第 2、3 步：

```bash
# 產生 modules/ee_alarm/，加入 EE、PE 的 [access] 清單並新增 [page.ee_alarm]
bash scripts/shell/new_module.sh ee_alarm "EE,PE" "警報中心 // ALARMS" 35
```

產生的骨架：

```php
<?php
class EeAlarmController extends Controller
{
    public function indexAction()          // index.php?m=ee_alarm
    {
        $this->render('index', array('message' => '...'));
    }

    public function listAction()           // index.php?m=ee_alarm&a=list
    {
        $rows = Database::fetchAll('SELECT ... WHERE x = ?', array($x));
        $this->json(array('ok' => true, 'rows' => $rows));
    }
}
```

Controller 可用的方法：`render()`、`json()`、`redirect()`、`can('動作')`、`isPost()`、`input()`、`query()`、`flash()`。View 中輸出變數一律用 `e($var)`；要放進 `<script>` 用 `js($var)`。

## 6. 安全機制

- bcrypt 密碼雜湊，提高 `bcrypt_cost` 後使用者下次登入自動升級雜湊
- 連續失敗 5 次鎖定 15 分鐘（`app.ini` 可調），帳號不存在時也執行一次 bcrypt，避免從回應時間猜出帳號
- 登入成功 `session_regenerate_id()`，閒置 30 分鐘自動登出，Cookie 設 HttpOnly
- 所有 POST（含 jQuery AJAX，透過 `X-CSRF-Token` 標頭）都檢查 CSRF token；登出也需要 token，避免被外部連結強制登出
- 註冊無法取得 ADMIN 身份；可開啟 `require_approval` 讓新帳號需管理員啟用，或把 `unlisted_role` 設為空字串只開放名單內帳號註冊
- 首次登入或被管理員重設密碼後強制改密碼
- 所有 SQL 使用 PDO prepared statement，`ATTR_EMULATE_PREPARES = false`

## 7. PHP 5.4 相容規範

可以用：`array()` 與 `[]` 短陣列、closure、`http_response_code()`、`JSON_UNESCAPED_UNICODE`、`session_status()`。

不能用：

| 不能用 | 版本 | 替代寫法 |
|---|---|---|
| `password_hash()` / `password_verify()` | 5.5 | 已由 `core/password_compat.php` 補上，可直接使用 |
| `finally`、`yield`、`::class`、`array_column()`、`empty(函式())` | 5.5 | try/catch、迴圈、字串類別名稱、先存變數 |
| `hash_equals()`、`...$args`、`const` 運算式 | 5.6 | `Security::equals()` |
| `??`、`<=>`、純量 type hint、回傳型別、`random_bytes()` | 7.0 | `array_get()`、`Security::randomBytes()` |
| `?->`、`match`、`fn() =>` | 8.0 | 一般寫法 |

## 10. 圖表（charts）

多張圖表（BSLr、M1BF、CDM、BMMF…）共用同一個模組 `modules/charts`，每張圖表是選單「圖表 // CHARTS」底下的一頁。圖表使用 ECharts 5.4.3（`public/assets/vendor/` 有檔案時用本機的，否則走 jsDelivr CDN）。

每張圖表只由兩個同名檔案定義，新增圖表不需要改任何程式：

| 檔案 | 內容 |
|---|---|
| `charts/<名稱>.ini` | 畫什麼、怎麼畫：`[page]` 整頁設定、`[plot.<代號>]` 每組圖 |
| `charts/<名稱>.php` | 部署者寫 SQL，整理成資料格式（`class <名稱>Chart extends ChartSource`） |
| `config/config.ini` | `[page.<小寫名稱>]`，`route = "module:charts"`、`group = "charts"`；哪些身份看得到寫在 `[access]` |

頁面代號 = 圖表名稱轉小寫：`[page.bslr]` → `charts/BSLr.ini`、`charts/BSLr.php`，網址 `index.php?m=bslr`。

| 區塊 | 內容 |
|---|---|
| 全域選擇器 | 起訖日期（快捷按鈕由 `quick_days` 設定）、單台機台 |
| single 單台機台趨勢 | 所選機台，每組一張圖，組內每個參數一條線；X 軸時間 |
| Newest_TBT 最新值排排站 | 每組一張長條圖，X 軸機台、每個參數一根長條，取每台在區間內的最後一個值；機型篩選（`model.<機型>`）；點長條會切換上方的單台機台 |
| TBT 歷史趨勢排排站 | 每組一張圖，每台一個區段（依機台名稱排序），區段內依時間排序；圖例可開關機台，下方可拖曳縮放 |

### 新增一張圖表

```bash
bash scripts/shell/new_chart.sh CDM      # 建立 charts/CDM.ini、charts/CDM.php，並印出 config.ini 要貼的區段
```

1. 編輯 `charts/CDM.ini` 的 `[plot.xxx]`；此時 `source = sample`，用範例資料就能看到完整畫面
2. 編輯 `charts/CDM.php` 寫 `tools()`、`series()` 的 SQL，寫好把 ini 改成 `source = php`
3. 把腳本印出的 `[page.cdm]` 貼進 `config/config.ini`，並把 `cdm` 加到 `[access]` 要看得到的身份
4. `python scripts/python/check_config.py` 檢查

### 設定檔：`charts/<名稱>.ini`

```ini
[page]
source       = php          ; php = 用 <名稱>.php 查資料庫；sample = 內建範例資料
default_days = 60           ; 預設顯示最近幾天
max_days     = 366          ; 一次最多查幾天
quick_days   = "7, 30, 90"  ; 快速區間按鈕
model.1980   = "PAN"        ; 機台代號含 PAN → 機型 1980（不設定就沒有機型下拉選單）
model.2000   = "PAP"

[db]                        ; 這張圖表的資料庫連線；ip 留空 = 使用 AISLE 自己的資料庫
ip       = "10.x.x.x"       ; 帳號密碼只填在主機上，repo 裡一律留空
port     = 3306
name     = "資料庫名稱"
user     = "唯讀帳號"
password = "密碼"
charset  = "utf8mb4"

[plot.m1bf_z]
title  = "M1BF_Z"
params = "M1BF_Z_C1, M1BF_Z_C2"   ; 畫在同一張圖的參數
single = On                        ; 是否畫單台機台趨勢
newest = On                        ; 是否畫最新值排排站
tbt    = On                        ; 是否畫歷史趨勢排排站
single_ymin = 0                    ; 只設單台趨勢的 Y 軸（ymin / ymax 則是三張圖共用）
single_ymax = 6
target = 2.5                       ; 各機台 target（選用）：寫了任何 target → spec 改成「距離 target 多遠」
target.APAN01 = 3                  ; 這台所有參數
target.APAN02.M1BF_Z_C2 = 2.6      ; 這台的某個參數
upper_oos = 1.5                    ; spec 線（可留空 = 不畫）；APAN01 → OOS 4.5
upper_ooc = 1.2                    ; APAN01 → OOC 4.2
lower_ooc = 1.2                    ; APAN01 → OOC 1.8
lower_oos = 1.5                    ; APAN01 → OOS 1.5

[plot.m1bf_ry]
title  = "M1BF_Ry"
params = "M1BF_Ry_C1, M1BF_Ry_C2"
newest = Off                       ; 這組不顯示最新值排排站
tbt_ymin = 0                       ; 只設歷史趨勢排排站的上下限，單台趨勢維持自動
tbt_ymax = 6
```

- 每個 `[plot.<代號>]` 是一組，頁面依檔案順序畫圖；`single` / `newest` / `tbt` 省略時為 On
- 某區塊沒有任何一組開啟時，整個區塊不顯示
- 可選 `unit` 設定 Y 軸名稱（預設 `Data`）；`connect = On` 讓線跨過空值連起來（參數來自取樣時間不同的 table 時使用）
- Y 軸上下限：`ymin` / `ymax` 套用到該組三張圖；`single_ymin`、`newest_ymax`、`tbt_ymin` 等只套用到該區塊並優先；不設或留空為自動，超出範圍的資料會被裁切
- spec 線：`upper_oos` / `upper_ooc` / `lower_ooc` / `lower_oos`，可省略或留空（不畫）。三個區塊都畫成水平線，OOS 紅色實線、OOC 橘色虛線；有填的值須符合 `lower_oos <= lower_ooc < upper_ooc <= upper_oos`。Y 軸自動時會把 spec 線納入範圍
- 各機台 target（偏移模式）：組內寫了任何一行 `target` / `target.<機台>` / `target.<機台>.<參數>`（含留空的 `target =`）時，四個 spec 改成距離 target 的偏移量（一律 >= 0，同側 OOS >= OOC，上下同一層不能同時為 0）
  - target 取值順序：`target.<機台>.<參數>` → `target.<機台>` → `target.<機型>` → `target` → 0；機台不分大小寫，寫了不存在的機台會被忽略；機型寫 `[page]` 的機型名稱（例 `2000`）或比對字（例 `PAP`）都可以；參數必須在 `params` 裡
  - single：畫原始值，spec 線在所選機台的 `target + upper_xxx`、`target - lower_xxx`，另畫 target 線（青色點線）；同組參數 target 不同時每個參數各一組線，標籤加參數名稱
  - newest / tbt：畫「值 - target」，各機台放在同一個基準比較，spec 線為 +偏移 / 0 / -偏移；tooltip 與資料表仍顯示原始值；`newest_ymin`、`tbt_ymax` 等是偏差值的範圍
  - 沒寫任何 target 的組維持原本的絕對值 spec（例 m1bf_ry）
- 依機台 / 機型覆蓋 spec 寬度：`upper_ooc.APAP01 = 4.6`（機台）、`upper_ooc.PAP = 4.8`（機型，寫機型名稱 `2000` 也可以），四條都可以覆蓋，只寫要不同的那幾條；留空（`lower_oos.APAN03 =`）= 這台不畫這一條
  - 每一條各自依 機台 → 機型 → 整組 取值，合併後的值一樣要符合大小關係；偏移模式時覆蓋值也是偏移量
  - single 用所選機台的 spec；newest / tbt 各台相同時畫一條橫線，不同時每台在自己的長條 / 區段畫一段線，標籤只在和前一台不同時顯示
- 存檔後重新整理頁面即生效；格式錯誤時頁面會顯示錯誤（`modules/charts/ChartConfig.php` 檢查）

### 資料來源：`charts/<名稱>.php`

```php
<?php
class BSLrChart extends ChartSource
{
    public function tools()
    {
        $rows = $this->fetchAll('SELECT DISTINCT tool_id FROM bslr_x_data');
        $tools = array();
        foreach ($rows as $r) {
            $tools[] = $r['tool_id'];
        }
        return $tools;
    }

    public function series($tools, $params, $start, $end)
    {
        $where = 'tool_id IN (' . $this->in($tools) . ')
                  AND data_time >= ? AND data_time < DATE_ADD(?, INTERVAL 1 DAY)';
        $bind  = array_merge($tools, array($start, $end));

        // 長表（tool_id, data_time, param, value）
        $a = self::pivot($this->fetchAll(
            'SELECT tool_id, DATE_FORMAT(data_time, \'%Y-%m-%d %H:%i:%s\') AS d, param, value
               FROM bslr_x_data WHERE ' . $where, $bind), 'tool_id', 'd', 'param', 'value');

        // 寬表，欄位 c1 / c2 對應參數 BSLr_Y_C1 / BSLr_Y_C2
        $b = self::wide($this->fetchAll(
            'SELECT tool_id, DATE_FORMAT(data_time, \'%Y-%m-%d %H:%i:%s\') AS d, c1, c2
               FROM bslr_y_summary WHERE ' . $where, $bind),
            'tool_id', 'd', array('BSLr_Y_C1' => 'c1', 'BSLr_Y_C2' => 'c2'));

        return self::merge($a, $b);   // 不同 table 的結果依機台 + 時間合併
    }
}
```

| 工具（`modules/charts/ChartSource.php`） | 用途 |
|---|---|
| `$this->fetchAll($sql, $bind)` | prepared statement 查詢，值一律用 `?` 綁定 |
| `$this->in($list)` | 產生 `IN (...)` 用的 `?,?,?` |
| `self::pivot($rows, 機台欄, 時間欄, 參數欄, 值欄)` | 長表（一列一個參數值）→ 資料格式 |
| `self::wide($rows, 機台欄, 時間欄, 參數 => 欄位)` | 寬表（每個參數一個欄位）→ 資料格式 |
| `self::merge($a, $b, ...)` | 多個 table 的結果合併，對不到的位置補 null |
| `$this->machineOf($tool)` / `$this->machinesOf($tools)` / `$this->toolOf($machine)` | tool_id 與 machine_id 互換（要先實作 `machines()`） |
| `self::table($name)` | 組出來的 table 名稱（例 `'M1BF_' . $machineId`）檢查後加反引號；table 名稱不能用 `?` 綁定，一定要經過它 |

**table 用 machine_id 時**（例 table `M1BF_HP23`，`HP23` 是 `APAN01` 的 machine_id）：在 `<名稱>.php` 實作 `machines()`，回傳 `array('APAN01' => 'HP23', ...)`（可寫死或從對照表查）。實作後 `tools()` 可以省略（預設用 `machines()` 的 tool_id），`series()` 回傳的 key 也可以直接是 machine_id，controller 會自動換成 tool_id；網頁上的機台名稱一律是 tool_id。範例見 `charts/_template.php` 的寫法 4（每台一個 table）、寫法 5（machine_id 欄位）。

資料庫連線在各圖表自己的 `charts/<名稱>.ini` 的 `[db]`（ip / port / name / user / password / charset）；`ip` 留空時使用 AISLE 自己的 `[database]`。帳號密碼只在主機上的檔案填寫，**不要 commit 到 GitHub**（repo 裡一律留空）。`charts/` 從網址讀不到（根目錄 `.htaccess`），`[db]` 也不會送到瀏覽器。

### 資料格式與載入

後端 `index.php?m=<頁面代號>&a=tbt&start=&end=` 回傳區間內全部機台、ini 用到的全部參數：

```json
{
  "APAN01": { "Date": ["2026-01-01", "2026-01-02"],
              "Data": { "M1BF_Z_C1": [1.0, 2.0], "M1BF_Z_C2": [1.1, 2.1], "M1BF_Ry_C1": [1.0, 2.0], "M1BF_Ry_C2": [1.1, 2.1] } }
}
```

- 選用 `"Url": [...]`（與 `Date` 等長）：單台機台趨勢圖點擊數據點會在瀏覽器新分頁開啟該時間點的網址，tooltip 會提示「點擊數據點開啟連結」，資料表多一欄 URL。只接受 `http://`、`https://` 或 `/` 開頭的網址（其他如 `javascript:` 一律忽略）；`pivot()` / `wide()` 最後多給網址欄位名稱即可產生，`merge()` 會保留。沒有 `Url` 時與原本相同
- 每個參數陣列與 `Date` 等長，沒有值的位置是 `null`；排序、型別、補 null、只留 ini 用到的參數由 controller 統一處理，`<名稱>.php` 不需要先排好
- 進入頁面時只呼叫一次，所有圖都從這份資料取得。切換機台、切換機型只在瀏覽器端重畫，不再向後端要資料；只有改日期區間（查詢 / 快速區間）才重新取
- 編碼：**顏色 = 機台**（同機型內依序取色，跟著機台走，篩選後不變）、**線型 / 長條紋理 = 參數**（組內第 1 個參數實線，第 2 個虛線、斜線紋理…）
- 每張圖都有「資料表」按鈕可切換成表格檢視
- 網址參數（選用）：`&tool=APAN01` 預選「單台機台趨勢」的機台並捲到該區塊（機台不在清單時忽略）；`&days=30` 預設區間改成最近 30 天（不超過 `max_days`）。選機表點數值格就是用這個（見第 13 節）
- 錯誤處理：設定錯誤直接顯示在頁面上；資料庫 / SQL 錯誤只在 `debug = 1` 時顯示內容，否則寫到 PHP error log

## 11. Pending Issue Control Table（`?m=pending_issue`）

追蹤各機台的 pending issue。只有 **EE** 能進入：所有 EE 都能查詢、匯出；**新增、編輯（含上傳圖片）只限列在 `config/pending_issue.ini` `[editors]` 的 EE 帳號**，其他 EE 打開 issue 是唯讀；**刪除只有 ADMIN**。**ADMIN** 全部可以（含刪除、看已刪除、還原），PE 看不到選單、直接開網址會 403。

| 檔案 | 用途 |
|---|---|
| `config/config.ini` `[page.pending_issue]` | 頁面登記；`action.delete` / `action.trash` / `action.restore` = `"ADMIN"`（刪除、看已刪除、還原） |
| `config/pending_issue.ini` | 可新增 / 編輯的 EE 帳號（`[editors]`）、機型、分類、狀態名稱、Sponsor 身份、匯出開關、圖片上限、輪詢 / 閒置秒數 |
| `modules/pending_issue/` | controller + view |
| `public/assets/js/pending_issue.js` | 表格、篩選、Sponsor 元件、貼圖、輪詢、衝突視窗 |
| `sql/migrations/20261110_pending_issue.sql` | 建表（`pending_issues`、`pending_issue_status_logs`、`pending_issue_images`、`pending_issue_presence`） |
| `storage/uploads/pending_issue/<年月>/` | 圖片檔（網址無法直接讀取） |

**欄位**：機台（必填，機型依代號自動判定，例 `APAN01` → 1980 (PAN)）、機型、分類（PE/YED HL / 選機表 / Aging parts / Others）、Issue 描述（必填）、Initial date、狀態（Open / Monitor / Close）、Sponsor（AISLE 使用者）、Check point date、Remark、圖片。

**畫面**

- 上方機型頁籤（括號內是未結案筆數），下方是分類 × 狀態統計，點數字直接套用篩選
- 篩選：Issue 狀態（多選，預設 Open + Monitor）、分類（多選）、機台、Sponsor、關鍵字、只看 Check point 逾期；條件寫在網址上，重新整理或分享網址都會保留
- 點欄位標題排序（第三次點回預設：Open → Monitor → Close、Check point 早的在前）；Check point 已過且未 Close 顯示紅字「逾期 N 天」
- **Sponsor**：點 ▼ 展開清單，或直接打字篩選（比對帳號與顯示名稱、不分大小寫），↑↓ / Enter / Esc 操作；只能選清單裡的人（`[sponsor] roles` 的啟用帳號）
- **狀態紀錄**：每次狀態改變都寫進 `pending_issue_status_logs`（誰、何時、從哪個狀態），表格顯示最後改狀態的人，編輯視窗有完整歷程
- **圖片**：編輯視窗中 Ctrl+V 貼上截圖、拖曳或選檔；只收 PNG / JPG / GIF（以檔案內容判斷）。圖片經 `?a=image` 檢查權限後才輸出：未存檔的暫存圖只有上傳者、已刪除 issue 的圖只有 ADMIN 看得到
- **軟刪除（只有 ADMIN）**：刪除只標記 `deleted_at`；EE 的編輯視窗沒有刪除按鈕，直接呼叫也會 403。ADMIN 勾「顯示已刪除」後可以還原
- **匯出 CSV**：匯出目前篩選與排序的結果（UTF-8 BOM，Excel 直接開）；`[export] enabled = Off` 時按鈕隱藏、網址回 404
- **IE11**：開啟頁面時跳出警告視窗（IE11 無法貼上截圖，拖曳與選檔可用）

**多人同時操作**

- 樂觀鎖：每筆有 `version`，存檔時比對。別人先存過 → 回 409，視窗列出「你的版本 / 最新版本」不同的欄位，可選 **覆蓋（用我的版本）**、**載入最新** 或取消。覆蓋時仍會比對版本，不會蓋掉自己沒看過的第三人修改
- 每 `poll_seconds`（預設 10）秒輪詢一次，同步別人的新增 / 修改 / 刪除，並顯示「某某 編輯中」；別人改了你正在編輯的那筆，視窗上方會立刻提示
- 閒置 `idle_seconds`（預設 300）秒沒操作，或分頁切到背景，就暫停輪詢（右上角顯示「⏸ 已暫停同步」），讓登入依 `session_idle` 照常逾時；有操作時立即恢復。不設人數上限

## 12. 機台借機與 PM 排程看板（`?m=tool_board`）

Tool Reservation & Maintenance Management Board。上方機型頁籤 **1980 (PAN) / 2000 (PAP) / YSM (POV)**，每個機型分開維護與設定；左欄 Tool ID，右邊是今天前 3 天到後 60 天（共 64 天）的日格子，第一列是該機型每日預估可用率。

| 檔案 | 用途 |
|---|---|
| `config/config.ini` `[page.tool_board]` | 頁面登記；EE、PE 都在 `[access]`；`action.save` / `action.move` / `action.delete` = `"EE"` |
| `config/tool_board.ini` | 共用：機型清單、時間視窗、格寬、預設起頭時間、Action 類別（名稱 / Hex 顏色 / 是否算停機 / 預設時數 / 預設 WIP）、可用率公式與門檻、PM JSON 路徑、輪詢秒數 |
| `config/tool_board/<機型>.ini` | 各機型：`[tools]` 機台清單、`[editors]` 可編輯的 EE 帳號、`[wip.<代碼>]` WIP 處理方式（名稱 / 字色 / 粗體）；也可覆蓋共用的 `[category.*]`、`[availability]` |
| `modules/tool_board/` | controller、設定讀取（BoardConfig）、可用率（Availability）、PM 讀取（PmSource）、view |
| `modules/tool_board/formulas/` | （選用）自訂可用率公式，一個公式一個檔 |
| `public/assets/js/tool_board.js` | 看板、右鍵選單、表單、拖曳、輪詢、衝突視窗 |
| `sql/migrations/20261111_tool_board.sql` | 建表（`tool_board_actions`、`tool_board_locks`、`tool_board_action_log`、`tool_board_presence`） |
| `storage/cache/` | PM JSON 解析快取（檔案改變才重新解析） |

**權限**

| 身份 | 看 | 新增 / 修改 / 拖曳 / 刪除 |
|---|---|---|
| ADMIN | 全部機型 | 全部機型 |
| EE（列在該機型 `[editors]`） | 全部機型 | 只有列名的機型（頁籤上有 ✎） |
| EE（沒列名）、PE | 全部機型 | 唯讀（雙擊色塊可檢視） |

後端每個寫入動作都會檢查，不只是隱藏按鈕。

**操作**

- 在格子上按右鍵 →「新增 Action」：類別、WIP 處理方式（單選，選項來自目前機型的 `[wip.*]`）、開始 / 結束（日期 + 時:分，新增時預帶點的那天 `default_start_time`，可自行調整；改開始時間時結束時間跟著平移、時長不變）、**時長（小時）**（直接 key in 小時數，可有小數如 1.5，結束時間自動換算；快捷 4h / 8h / 12h / 24h；反過來改結束時間，時長也會跟著更新；新增時換類別會帶入該類別的 `default_hours`）、是否需要 Monitor（時數，快捷 2h / 4h）、是否需要 Pilot（時數，快捷 12h / 24h）、備註
- 色塊右鍵：編輯 / 複製 / 刪除；雙擊色塊 = 編輯；編輯視窗下方有異動紀錄（誰、何時、新增 / 修改 / 拖曳）
- **拖曳**：拖色塊中間 = 整段搬移；拖左右邊緣 = 改開始或結束（色塊太窄時只能整段搬移）。預設以「天」對齊（保留原本的時分），按住 **Shift** 以 1 小時對齊；拖曳時旁邊顯示即時起訖，重疊會變紅、放開後還原
- **全螢幕**：看板標題列右邊 `[ ⛶ 全螢幕 ]`（或在頁面上按 **F**）把頁籤 + 看板放大到整個螢幕，右鍵選單、表單都照常可用；按 `[ 🗗 恢復 ]`、Esc 或再按 F 回到原本大小。瀏覽器不允許全螢幕時改成鋪滿瀏覽器視窗
- 開始時間最早只能到今天往前 3 天（`days_before`），方便補登實際時間；再更早的不能新增或修改

**畫法**

- 色塊背景色 = 類別的 `color`；文字色 = WIP 的 `text_color`（例 Purge WIP 紅字粗體）
- 有 Monitor / Pilot 時，色塊上顯示 `Mon: 4h | Pilot: 12h`（太窄時 `M4 P12`），並在 Action 結束後接著畫 Monitor 尾巴（深色斜線）、再畫 Pilot 尾巴（淡色斜線）
- 今天整欄醒目底色加粗框，紅色直線是「現在」；過去的日子加斜線底紋
- 同一台**不允許時間重疊**，判斷時包含 Monitor / Pilot 尾巴（伺服器檢查）

**每日預估可用率**

- 預設：`Σ(每台當天可用時數) / (該機型機台數 × 24h) × 100%`；停機時段 = `counts_down = On` 的類別的 Action 本體 ＋ Monitor 尾巴（`count_monitor`，預設算）＋ Pilot 尾巴（`count_pilot`，預設不算，因為 Pilot 有在跑貨）
- 低於 `alert_below`（預設 80）紅底，其他不上色（舊設定的 `warn_below` 已不使用，寫了也忽略）；滑鼠移上去顯示可用時數、目前的公式與門檻，圖例也會顯示
- 換公式：在 `modules/tool_board/formulas/` 新增 `<名稱>.php`（`class <名稱>Availability extends AvailabilityFormula`），設定 `formula = "<名稱>"`，範例見該資料夾的 README.txt
- **每個機型各自設定**：`config/tool_board.ini` 的 `[availability]` 是預設值，機型檔 `config/tool_board/<機型>.ini` 加 `[availability]` 只寫要改的項目即可，例：
  ```ini
  ; config/tool_board/PAP.ini
  [availability]
  formula     = "pap_hours"   ; → modules/tool_board/formulas/PapHours.php 的 PapHoursAvailability
  alert_below = 85            ; 這個機型低於 85 紅底
  count_pilot = On            ; 這個機型 Pilot 也算停機
  ```
  某個機型的公式檔載入失敗時，只有該機型改用預設公式並提示錯誤，其他機型不受影響。改完執行 `python scripts/python/check_config.py`，會逐一列出每個機型實際使用的公式與門檻

**PM 射程**

- `config/tool_board.ini` `[pm] json_path` 指定一個 JSON 檔（三個機型共用，各機型只顯示自己的機台）：
  ```json
  {"APAN01": {"PM":     {"window_start_date": "2026-06-01 09:30", "first_due": "2026-06-10 09:30", "due_date": "2026-06-17 09:30", "period": "week26"},
              "AMC_PM": {"window_start_date": "2026-07-01 09:30", "first_due": "2026-07-10 09:30", "due_date": "2026-07-17 09:30"}}}
  ```
- `period`（PM 週期，選填）：同機型 PM 週期不同時使用。有的話射程上顯示 `PM · week26`，滑鼠提示也會加上 `（week26）`；沒有這個 key（或空白）時維持只顯示 `PM`。文字最多 32 字
- 不匯入資料庫：每次讀取比對檔案修改時間與大小，有變才重新解析，下一次輪詢就更新所有人的畫面
- 產生端請用 Python `json.dump` 輸出；若是單引號（Python dict 印法，含 `u'..'`、`True/False/None`）也會自動轉換，但畫面會提示
- 格式錯誤的項目略過，畫面顯示略過筆數（原因只有 ADMIN 看得到）；檔案不存在或整個壞掉時看板照常運作，只顯示警告
- 畫法：射程（window_start_date → due_date）淡色斜線底帶、到點日 ▼ 橘線、最後到期日 ! 紅線；射程內已有 PM 類別的 Action → 綠色（已排），已到點未排 → 橘框，已過最後到期日未排 → 紅色閃爍
- 在射程上按右鍵「依此 PM 新增 Action」：類別帶 PM、開始時間 = 到點日、記下 PM 類型；有 period 時備註預填 `週期：week26`（可改）

**多人同時操作**（不需要 WebSocket，沿用 Pending Issue 的做法）

- 樂觀鎖：每筆有 `version`，存檔 / 拖曳 / 刪除時比對；別人先改過 → 409，視窗列出「你的版本 / 最新版本」，可選 **覆蓋（用我的版本）**、**使用最新版本** 或取消
- 重疊檢查在交易內先鎖住該機台（`tool_board_locks`），兩個人同時把不同 Action 排進同一段時間時，後到的會被擋下
- 每 `poll_seconds`（預設 5）秒輪詢：同步別人的新增 / 修改 / 拖曳 / 刪除、可用率、PM 檔更新；顯示同機型的線上使用者，以及「🔒 某某 編輯中 / 拖曳中」
- 閒置 `idle_seconds` 或分頁在背景時暫停輪詢，讓登入照常逾時
- IE11 開啟時跳出警告（拖曳在 IE11 無法正常使用）

## 13. 設備選機表（`?m=tool_select`）

Tool Selection Matrix。上方機型頁籤 **1980 (PAN) / 2000 (PAP) / YSM (POV)**；表格欄位 `分類 | 項目 | uOOS | uOOC | lOOC | lOOS | 各機台`，數值超出 OOC / OOS 時格子上底色。EE、PE 都能看（唯讀），也都能匯出 CSV。

| 檔案 | 用途 |
|---|---|
| `config/config.ini` `[page.tool_select]` | 頁面登記；EE、PE 都在 `[access]`；`action.export = "EE,PE"` |
| `config/tool_select.ini` | 共用：機型清單、超規底色（暗色 / 亮色主題各一組）、狀態文字底色 |
| `config/tool_select/<機型>.ini` | 各機型：`[page]` 數值 JSON 路徑、`[tools]` 機台、`[category]` 分類、`[item.<代號>]` 項目 |
| `modules/tool_select/` | controller（頁面 / 資料 / 匯出）、設定讀取（SelectConfig）、JSON 讀取（ValueSource）、view |
| `public/assets/js/tool_select.js` | 表格、篩選、超規判斷、機台下拉選單 |
| `storage/cache/` | JSON 解析快取（檔案改變才重新解析） |

不需要建資料表，也不連資料庫。

**項目設定**（`config/tool_select/<機型>.ini`）

```ini
[category]
focus = "Focus"
ovl   = "OVL"

[item.m1bf_ry]
category  = "focus"           ; 必填，[category] 的代號
label     = "M1BF Ry"         ; 顯示名稱
key       = "M1BF_Ry"         ; JSON 裡的名稱（省略 = 代號），不分大小寫
unit      = "nm"              ; 選用
decimals  = 2                 ; 選用，顯示幾位小數
upper_oos = 5.5               ; spec 四條都選用，留空 = 不判斷那一條
upper_ooc = 5
lower_ooc =
lower_oos =
upper_oos.APAN03 = 6          ; 機台覆蓋：只有 APAN03 用不同的 spec，只寫要不同的那幾條
upper_ooc.APAN03 = 5.5
; target = 2.5                ; 各機台 target（選用），寫了就變偏移模式，見下方說明
; target.APAN01 = 3
href      = "?m=m1bf&tool={tool}"   ; 選用，可留空 = 沒有連結
ooc_bg    = "#A0522D"         ; 選用，這個項目自己的 OOC 底色（還有 oos_bg、ooc_bg_light、oos_bg_light）
```

- 表格依 `[category]` 的順序分組，同分類內依 `[item.*]` 的順序；同分類的分類格合併
- spec 必須符合 `lower_oos <= lower_ooc < upper_ooc <= upper_oos`（機台覆蓋後也要符合），錯了頁面與 `check_config.py` 都會指出是哪一項
- 有機台覆蓋的格子右上角有小三角，滑鼠移上去顯示那台實際用的 spec；超規一律用那台的 spec 判定
- 各機台 target（偏移模式）：項目寫了任何一行 `target` / `target.<機台>`（含留空的 `target =`）時，spec 與機台覆蓋都改成距離 target 的偏移量（>= 0），判定用 `target + upper_xxx`、`target - lower_xxx`；target 取值 `target.<機台>` → `target` → 0，機台不分大小寫且必須在 `[tools]` 裡
  - spec 欄顯示帶正負號的偏移量（例 `+1.5 / +1.2 / -1.2 / -1.5`），項目名稱旁標 `±T`；CSV 的 spec 欄同畫面，不另加 target 欄
  - 格子 tooltip 顯示該台的 target 與換算後的 spec；target 與預設不同的機台也有右上角小三角

**限定身份檢視**（分類 `<代號>.view`、項目 `view`）

```ini
[category]
focus  = "Focus"
hand18 = "18掌"
hand18.view = "EE"          ; 只有 EE（與 ADMIN）看得到這個分類

[item.m1bf_ry]
category = "focus"
view     = "EE,PE"          ; 項目層級：只有 EE、PE（與 ADMIN）看得到這一項
```

- 值是逗號分隔的身份（同 `action.export` 寫法），身份必須在 `config/config.ini [roles]`；**沒寫 = 能進選機表的人都看得到**
- 留空（`hand18.view = ""`）= 只有 ADMIN 看得到；ADMIN 一律看得到
- 兩層都要符合才看得到：分類限 EE、項目寫 `"EE,PE"` → PE 仍看不到（`check_config.py` 會警告）；分類底下的項目全看不到時，分類也不顯示
- 在伺服器端過濾：看不到的分類、項目與數值不會送到瀏覽器，匯出 CSV 手動帶項目代號也匯不出來
- 看得到的人在分類 / 項目名稱旁看到小標記（例 `[EE]`），提醒這是限定內容；CSV 不加標記
- 某機型一個分類都看不到時，頁籤照常顯示，表格區顯示「此機型沒有你可檢視的分類」
- 項目 href 連到的 chart 頁不受影響，權限照 `config.ini [access]`

**超規判定與底色**

| 判定 | 條件 | 底色 |
|---|---|---|
| OOS | 大於 `upper_oos` 或小於 `lower_oos` | `oos_bg`（預設紅） |
| OOC | 不是 OOS，且大於 `upper_ooc` 或小於 `lower_ooc` | `ooc_bg`（預設橘黃） |
| 正常 | 其他（**剛好等於界限算正常**） | 無 |

- 顏色：`config/tool_select.ini [color]` 是全站預設（`*_light` 給亮色主題），項目可用同名欄位覆蓋；文字依底色深淺自動用黑或白
- 非數字的值（例 `Down`、`PM`）當作狀態，不判斷 spec，依 `[status]` 上底色

**數值 JSON**（`[page] json_path`，每個機型各自一個檔）

```json
{"updated": "2026-11-15 08:00",
 "data": {"APAN01": {"M1BF_Ry": 3.21, "LUSU": "Down", "SAMOS": {"v": -3.4, "t": "2026-11-15 07:30"}},
          "APAN02": {"M1BF_Ry": 5.12}}}
```

- 機台 → 項目 → 值；值可以是數字、數字字串、狀態文字，或 `{"v": 值, "t": "資料時間"}`（`t` 顯示在滑鼠提示）
- `updated` 顯示在表格右上（省略時顯示檔案修改時間）；也可以省略 `data` 這一層直接 `{"APAN01": {...}}`
- JSON 裡多的機台 / 項目忽略；ini 有、JSON 沒有的顯示 `-`
- 不自動刷新，按標題列 `[ ⟳ 重新整理 ]` 重新讀取；檔案沒變時用快取
- 產生端請用 Python `json.dump`；單引號（Python dict 印法）也會自動轉換，但畫面會提示
- JSON 還沒準備好時 `sample = On` 用內建範例值先看畫面

**篩選**（全部在瀏覽器端即時套用，條件依機型記在瀏覽器）

- 分類：多選下拉；關鍵字：比對分類與項目名稱，空白分隔多個 = 任一符合
- 機台：下拉選單，可搜尋（例輸入 `05`），有全選 / 全不選 / 反選（搜尋中只作用在搜尋結果）；沒勾的機台整欄隱藏

- 表頭、分類 / 項目 / 四個 spec 欄固定不捲動
- **全螢幕**：標題列 `[ ⛶ 全螢幕 ]`（或在頁面上按 **F**）把頁籤 + 選機表放大到整個螢幕，篩選、下拉選單照常可用；按 **Esc**（有開著的下拉選單時先收起選單，再按一次 Esc）或 `[ 🗗 恢復 ]` 回到原本大小。瀏覽器不允許全螢幕時改成鋪滿瀏覽器視窗

- `href = "?m=m1bf"`：點項目名稱在新分頁開 chart 頁（自動接上 `base_url`，proxy 前綴下也正常）

    public static function shared()
    {
        if (self::$shared !== null) {

        }
        $ini = self::parse(AISLE_ROOT . '/config/tool_select.ini', 'config/tool_select.ini');

            if (preg_match('/^[A-Z0-9_]{1,16}$/', $k)) {

        if (!$models) {
            throw new ToolSelectConfigException('config/tool_select.ini 的 [models] 沒有任何機型');
        }

        );
        $colorIni = array_get($ini, 'color', array());

                    $target = $n === null ? 0.0 : $n;
                } elseif (strpos($k, 'target.') === 0) {
                    $offset = true;
                    $tool = strtoupper(trim(substr($k, 7)));
                    if (!in_array($tool, $tools, true)) {
                        throw new ToolSelectConfigException($where . '：' . $k . ' 的機台 ' . $tool . ' 不在 [tools] 裡');
                    }
                    $n = self::number($val, $where . ' ' . $k);
                    if ($n !== null) {
                        $targets[$tool] = $n;
                    }
                }
            }
            self::checkSpec($spec, $where, $offset);

            // 機台覆蓋：upper_oos.APAN03 = 6
            $toolSpec = array();
            foreach ($v as $k => $val) {
                if (strpos($k, '.') === false || strpos($k, 'target.') === 0) {
                    continue;
                }
                list($base, $tool) = explode('.', $k, 2);
                $idx = array_search($base, self::$SPEC_KEYS, true);
                if ($idx === false) {
                    throw new ToolSelectConfigException($where . '：不認得的欄位 ' . $k . '（機台覆蓋只能用 upper_oos / upper_ooc / lower_ooc / lower_oos / target）');
                }
                $tool = strtoupper(trim($tool));
                if (!in_array($tool, $tools, true)) {
                    throw new ToolSelectConfigException($where . '：' . $k . ' 的機台 ' . $tool . ' 不在 [tools] 裡');
                }
                if (!isset($toolSpec[$tool])) {
                    $toolSpec[$tool] = $spec;
                }
                $toolSpec[$tool][$idx] = self::number($val, $where . ' ' . $k);
            }
            foreach ($toolSpec as $tool => $s) {
                self::checkSpec($s, $where . ' 機台 ' . $tool, $offset);
            }

            // 偏移模式：每台換算成絕對 spec（target + upper、target - lower），判斷邏輯不用改
            $abs = array();
            if ($offset) {
                foreach ($tools as $tool) {
                    $s = isset($toolSpec[$tool]) ? $toolSpec[$tool] : $spec;
                    $t = isset($targets[$tool]) ? $targets[$tool] : $target;
                    $abs[$tool] = array(
                        $s[0] === null ? null : round($t + $s[0], 10),
                        $s[1] === null ? null : round($t + $s[1], 10),
                        $s[2] === null ? null : round($t - $s[2], 10),
                        $s[3] === null ? null : round($t - $s[3], 10),
                    );
                }
            }

            $colors = array();
            foreach (self::$COLOR_KEYS as $k) {
                if (array_key_exists($k, $v) && trim((string) $v[$k]) !== '') {
                    $c = self::color($v[$k], '');
                    if ($c === '') {
                        throw new ToolSelectConfigException($where . '：' . $k . ' 必須是 Hex 顏色，例 "#7A0000"');
                    }
                    $colors[$k] = $c;
                }
            }

            $href = trim((string) array_get($v, 'href', ''));
            if ($href !== '' && !self::validHref($href)) {
                throw new ToolSelectConfigException($where . '：href 只能是 "?m=..."、"/..." 或 http(s):// 開頭');
            }

            // view = "EE"：只有這些身份看得到這一項（留空 = 只有 ADMIN；沒寫 = 看得到分類的人都看得到）
            $view = array_key_exists('view', $v) ? self::roleList($v['view'], $where . ' view') : null;

            $dec = trim((string) array_get($v, 'decimals', ''));
            $key = trim((string) array_get($v, 'key', ''));
            $items[] = array(
                'id'       => $id,
                'category' => $cat,
                'label'    => trim((string) array_get($v, 'label', '')) !== '' ? trim((string) $v['label']) : $id,
                'key'      => $key !== '' ? $key : $id,
                'unit'     => trim((string) array_get($v, 'unit', '')),
                'decimals' => $dec === '' ? null : max(0, min(8, (int) $dec)),
                'spec'     => $spec,
                'toolSpec' => $toolSpec,
                'offset'   => $offset,
                'target'   => $target,
                'targets'  => $targets,
                'abs'      => $abs,
                'colors'   => $colors,
                'href'     => $href,
                'view'     => $view,
                '_cat'     => array_search($cat, array_keys($categories), true),
                '_order'   => $order++,
            );
        }

        // 依分類順序排，同分類保留 ini 順序（usort 不穩定，所以比兩個欄位）
        usort($items, function ($a, $b) {
            if ($a['_cat'] !== $b['_cat']) {
                return $a['_cat'] < $b['_cat'] ? -1 : 1;
            }
            return $a['_order'] < $b['_order'] ? -1 : 1;
        });
        foreach ($items as $i => $it) {
            unset($items[$i]['_cat'], $items[$i]['_order']);
        }

        self::$models[$model] = array(
            'model'      => $model,
            'label'      => $shared['models'][$model],
            'json_path'  => trim((string) array_get($page, 'json_path', '')),
            'sample'     => (bool) array_get($page, 'sample', false),
            'tools'      => $tools,
            'categories' => $categories,
            'catView'    => $catView,
            'items'      => $items,
        );
        return self::$models[$model];
    }

    /**
     * 依身份過濾：拿掉看不到的分類與項目（回傳複本，不動 forModel 的快取）
     * - 分類有 .view 且身份不在清單 → 整個分類與底下項目都拿掉
     * - 項目有 view 且身份不在清單 → 拿掉該項目（兩層都要符合才看得到）
     * - 分類原本有項目、但項目全被拿掉 → 分類也不顯示
     * - ADMIN（超級身份）一律看得到
     * 另外加上：'noAccess' => 原本有分類、過濾後一個都不剩；'restricted' => array(代號 => "EE,PE") 供畫面標記
     */
    public static function forRole($cfg, $role)
    {
        $cats = array();
        foreach ($cfg['categories'] as $code => $label) {
            if (!isset($cfg['catView'][$code]) || Acl::roleMatches($role, $cfg['catView'][$code])) {
                $cats[$code] = $label;
            }
        }
        $had = array();
        $kept = array();
        $items = array();
        foreach ($cfg['items'] as $it) {
            $had[$it['category']] = true;
            if (!isset($cats[$it['category']])) {
                continue;
            }
            if ($it['view'] !== null && !Acl::roleMatches($role, $it['view'])) {
                continue;
            }
            $kept[$it['category']] = true;
            $items[] = $it;
        }
        foreach ($cats as $code => $label) {
            if (isset($had[$code]) && !isset($kept[$code])) {
                unset($cats[$code]);
            }
        }
        $restricted = array();
        foreach ($cfg['catView'] as $code => $roles) {
            if (isset($cats[$code])) {
                $restricted[$code] = self::roleTag($roles);
            }
        }

        $out = $cfg;
        $out['categories'] = $cats;
        $out['items'] = $items;
        $out['restricted'] = $restricted;
        $out['noAccess'] = !empty($cfg['categories']) && empty($cats);
        return $out;
    }

    /** 身份清單 → 畫面標記文字；空清單 = 只有 ADMIN */
    public static function roleTag($roles)
    {
        return $roles ? implode(',', $roles) : 'ADMIN';
    }

    /** 該項目在某台機台的有效 spec（絕對值；偏移模式時已換算成 target ± 偏移） */
    public static function specOf($item, $tool)
    {
        if (!empty($item['offset'])) {
            return isset($item['abs'][$tool]) ? $item['abs'][$tool] : array(null, null, null, null);
        }
        return isset($item['toolSpec'][$tool]) ? $item['toolSpec'][$tool] : $item['spec'];
    }

    /**
     * 超規判定（剛好等於界限算正常）
     * @param float|null $v
     * @param array $s array(upper_oos, upper_ooc, lower_ooc, lower_oos)，null = 不判斷
     */
    public static function judge($v, $s)
    {
        if ($v === null) {
            return '';
        }
        if (($s[0] !== null && $v > $s[0]) || ($s[3] !== null && $v < $s[3])) {
            return 'oos';
        }
        if (($s[1] !== null && $v > $s[1]) || ($s[2] !== null && $v < $s[2])) {
            return 'ooc';
        }
        return '';
    }

    /** href：?m=...、/...、http(s)://...（不接受 //host 與 javascript: 等） */
    public static function validHref($href)
    {
        if (preg_match('/[\s"\'<>\\\\]/', $href)) {
            return false;
        }
        return (bool) preg_match('#^(\?|/(?!/)|https?://)#i', $href);
    }

    // ------------------------------------------------------------------

    /** "EE, PE" → array('EE', 'PE')；身份必須在 config/config.ini 的 [roles] 裡；留空 → array()（只有 ADMIN） */
    private static function roleList($value, $where)
    {
        $out = array();
        foreach (explode(',', (string) $value) as $r) {
            $r = trim($r);
            if ($r === '') {
                continue;
            }
            if (!Acl::roleExists($r)) {
                throw new ToolSelectConfigException($where . '：身份「' . $r . '」不在 config/config.ini 的 [roles] 裡');
            }
            if (!in_array($r, $out, true)) {
                $out[] = $r;
            }
        }
        return $out;
    }

    private static function parse($file, $label)
    {
        if (!is_file($file)) {
            throw new ToolSelectConfigException('找不到設定檔 ' . $label);
        }
        $ini = @parse_ini_file($file, true);
        if ($ini === false) {
            throw new ToolSelectConfigException('INI 解析失敗：' . $label . '（字串請加雙引號）');
        }
        return $ini;
    }

    private static function number($value, $where)
    {
        $value = trim((string) $value);
        if ($value === '') {
            return null;
        }
        if (!is_numeric($value)) {
            throw new ToolSelectConfigException($where . ' 必須是數字或留空（目前是「' . $value . '」）');
        }
        return (float) $value;
    }

    /** lower_oos <= lower_ooc < upper_ooc <= upper_oos（只比有填的） */
    private static function checkOrder($s, $where)
    {
        list($uoos, $uooc, $looc, $loos) = $s;
        $bad = ($loos !== null && $looc !== null && $loos > $looc)
            || ($looc !== null && $uooc !== null && $looc >= $uooc)
            || ($uooc !== null && $uoos !== null && $uooc > $uoos)
            || ($loos !== null && $uoos !== null && $loos >= $uoos)
            || ($loos !== null && $uooc !== null && $loos >= $uooc)
            || ($looc !== null && $uoos !== null && $looc >= $uoos);
        if ($bad) {
            throw new ToolSelectConfigException($where . '：spec 必須符合 lower_oos <= lower_ooc < upper_ooc <= upper_oos');
        }
    }

    private static function checkSpec($s, $where, $offset)
    {
        if ($offset) {
            self::checkOffset($s, $where);
        } else {
            self::checkOrder($s, $where);
        }
    }

    /** 偏移模式：都是距離 target 的偏移量，必須 >= 0；同側 OOS >= OOC；上下同一層不能同時為 0 */
    private static function checkOffset($s, $where)
    {
        list($uoos, $uooc, $looc, $loos) = $s;
        foreach ($s as $i => $x) {
            if ($x !== null && $x < 0) {
                throw new ToolSelectConfigException($where . '：有寫 target 時 ' . self::$SPEC_KEYS[$i] .
                    ' 是距離 target 的偏移量，必須 >= 0（例 lower_ooc = 1.5 表示 target - 1.5）');
            }
        }
        if (($uoos !== null && $uooc !== null && $uoos < $uooc) || ($loos !== null && $looc !== null && $loos < $looc)) {
            throw new ToolSelectConfigException($where . '：有寫 target 時，同一側的 OOS 偏移量必須大於等於 OOC');
        }
        if (($uooc === 0.0 && $looc === 0.0) || ($uoos === 0.0 && $loos === 0.0)) {
            throw new ToolSelectConfigException($where . '：upper 與 lower 同一層的偏移量不能同時為 0');
        }
    }

    private static function color($value, $default)
    {
        $value = trim((string) $value);
        return preg_match('/^#([0-9A-Fa-f]{3}|[0-9A-Fa-f]{6})$/', $value) ? strtoupper($value) : $default;
    }
}

    public function exportAction()
    {

            return;
        }
        $vals = ToolSelectValues::forModel($cfg);
        $values = $vals['values'];

        $tools = $this->pick($this->query('tools'), $cfg['tools'], true);
        $ids = array();

            $ids[] = $it['id'];

        $filename = 'tool_select_' . $cfg['model'] . '_' . date('Ymd_Hi') . '.csv';
        header('Content-Type: text/csv; charset=utf-8');
        header('Content-Disposition: attachment; filename="' . $filename . '"');
        header('Cache-Control: private, no-store');
        $out = fopen('php://output', 'w');
        fwrite($out, "\xEF\xBB\xBF"); // UTF-8 BOM，Excel 直接開不會亂碼
        fputcsv($out, array_merge(array('分類', '項目', 'uOOS', 'uOOC', 'lOOC', 'lOOS'), $tools, array('OOC 機台', 'OOS 機台')));
        foreach ($cfg['items'] as $it) {
            if (!isset($wanted[$it['id']])) {
                continue;
            }
            $label = $it['label'] . ($it['unit'] !== '' ? ' (' . $it['unit'] . ')' : '');
            $line = array(self::safe($cfg['categories'][$it['category']]), self::safe($label));
            foreach ($it['spec'] as $k => $s) {
                // 偏移模式：與畫面相同，填帶正負號的偏移量（upper +、lower -）
                $sign = $it['offset'] ? ($k < 2 ? '+' : '-') : '';
                $line[] = $s === null ? '' : $sign . self::num($s, null);
            }
            $ooc = array();
            $oos = array();
            foreach ($tools as $tool) {
                $cell = isset($values[$it['id']][$tool]) ? $values[$it['id']][$tool] : null;
                if ($cell === null) {
                    $line[] = '';
                    continue;
                }
                if ($cell['v'] === null) {
                    $line[] = self::safe($cell['s']);
                    continue;
                }
                $line[] = self::num($cell['v'], $it['decimals']);
                $j = ToolSelectConfig::judge($cell['v'], ToolSelectConfig::specOf($it, $tool));
                if ($j === 'oos') {
                    $oos[] = $tool;
                } elseif ($j === 'ooc') {
                    $ooc[] = $tool;
                }
            }
            $line[] = implode(' ', $ooc);
            $line[] = implode(' ', $oos);
            fputcsv($out, $line);
        }
        fclose($out);

    private function modelConfig()
    {
        $model = strtoupper($this->query('model'));
        try {
            $models = ToolSelectConfig::models();
            if (!isset($models[$model])) {
                $this->json(array('ok' => false, 'error' => '沒有這個機型：' . $model), 404);
                return null;

            // 依身份拿掉看不到的分類、項目：data、export、數值都只剩看得到的

    /** 逗號分隔的清單 → 只留 $all 裡有的，依 $all 的順序；空白 = 全部 */
    private function pick($param, $all, $upper)
    {
        if ($param === '') {
            return $all;
        }
        $want = array();
        foreach (explode(',', $param) as $v) {
            $v = trim($v);
            $want[$upper ? strtoupper($v) : $v] = true;
        }
        $out = array();
        foreach ($all as $v) {
            if (isset($want[$v])) {
                $out[] = $v;
            }
        }
        return $out;
    }

    private static function num($v, $decimals)
    {
        if ($decimals !== null) {
            return number_format($v, $decimals, '.', '');
        }
        // 去掉浮點數尾巴（0.1 + 0.2 之類），最多 10 位有效小數
        return rtrim(rtrim(sprintf('%.10F', $v), '0'), '.');
    }

    /** 避免 Excel 把 = + - @ 開頭的文字當公式執行 */
    private static function safe($s)
    {
        $s = (string) $s;
        return ($s !== '' && strpos('=+-@', $s[0]) !== false) ? "'" . $s : $s;
    }

def unquote(value):
    value = value.strip()
    if not value.startswith('"'):
        value = value.split(';', 1)[0].strip()
    if len(value) >= 2 and value[0] == '"' and value[-1] == '"':

                section = line.strip('[]')
            elif section == section_name and pattern.match(line):
                values.append(unquote(line.split('=', 1)[1]))
    return values


def chart_names():

    if not os.path.isdir(CHARTS):

DB_KEYS = ('ip', 'port', 'name', 'user', 'password', 'charset')
SPEC_KEYS = ('upper_oos', 'upper_ooc', 'lower_ooc', 'lower_oos')


def check_chart_db(label, parser, get, errors):
    """[db]：只能有 DB_KEYS；port 為整數；ip 留空時 name / user / password 也要留空"""
    for opt in parser.options('db'):
        if opt not in DB_KEYS:
            errors.append('%s [db] 不認得的欄位：%s（可用：%s）' % (label, opt, '、'.join(DB_KEYS)))
    ip = get('db', 'ip')
    if ip and not re.match(r'^[A-Za-z0-9._:-]+$', ip):
        errors.append('%s [db] ip 格式錯誤（只能是 IP 或主機名稱）' % label)
    port = get('db', 'port')
    if port and (not port.isdigit() or not 1 <= int(port) <= 65535):
        errors.append('%s [db] port 必須是 1 ~ 65535 的整數' % label)
    for key in ('name', 'charset'):
        v = get('db', key)
        if v and not re.match(r'^[A-Za-z0-9_$-]+$', v):
            errors.append('%s [db] %s 只能有英文、數字、底線、$、-' % (label, key))
    if not ip:
        for key in ('name', 'user', 'password'):
            if get('db', key):
                errors.append('%s [db] 有填 %s 但沒有填 ip（ip 留空 = 使用 AISLE 自己的資料庫）' % (label, key))


def check_offset_spec(where, vals, errors):
    """偏移模式（有寫 target）：spec 是距離 target 的偏移量，>= 0；同側 OOS >= OOC；上下同一層不能同時為 0"""
    for key in SPEC_KEYS:
        if vals.get(key) is not None and vals[key] < 0:
            errors.append('%s：有寫 target 時 %s 是距離 target 的偏移量，必須 >= 0' % (where, key))
    for side in ('upper', 'lower'):
        oos, ooc = vals.get(side + '_oos'), vals.get(side + '_ooc')
        if oos is not None and ooc is not None and oos < ooc:
            errors.append('%s：%s_oos（%s）必須大於等於 %s_ooc（%s）' % (where, side, oos, side, ooc))
    for lv in ('ooc', 'oos'):
        if vals.get('upper_' + lv) == 0 and vals.get('lower_' + lv) == 0:
            errors.append('%s：upper_%s 與 lower_%s 不能同時為 0' % (where, lv, lv))


def check_chart_target(label, section, parser, get, errors):
    """target / target.<機台> / target.<機台>.<參數>：數字或留空，參數在 params 裡。回傳是否為偏移模式"""
    params = split_list(get(section, 'params'))
    offset = False
    for opt in parser.options(section):
        if opt != 'target' and not opt.startswith('target.'):
            continue
        offset = True
        v = get(section, opt)
        if v:
            try:
                float(v)
            except ValueError:
                errors.append('%s [%s] %s 必須是數字或留空：%s' % (label, section, opt, v))
        if opt == 'target':
            continue
        rest = opt[len('target.'):].split('.', 1)
        if not rest[0].strip() or (len(rest) > 1 and not rest[1].strip()):
            errors.append('%s [%s] %s 格式錯誤，應為 target.<機台> 或 target.<機台>.<參數>' % (label, section, opt))
        elif len(rest) > 1 and rest[1].strip() not in params:
            errors.append('%s [%s] %s 的參數 %s 不在 params 裡（區分大小寫）' % (label, section, opt, rest[1].strip()))
    return offset


def check_spec_values(where, vals, offset, errors):
    """一套 spec（key → 數字或 None）的大小關係"""
    if offset:
        check_offset_spec(where, vals, errors)
        return
    for i, a in enumerate(SPEC_KEYS):
        for b in SPEC_KEYS[i + 1:]:
            if vals.get(a) is None or vals.get(b) is None:
                continue
            same_side = a[:5] == b[:5]
            if (vals[a] < vals[b]) if same_side else (vals[a] <= vals[b]):
                errors.append('%s %s（%s）必須%s %s（%s）' % (
                    where, a, vals[a], '大於等於' if same_side else '大於', b, vals[b]))


def check_spec(label, section, parser, get, errors, offset=False, models=None):
    """spec 線：數字或留空；絕對值模式 lower_oos <= lower_ooc < upper_ooc <= upper_oos
    upper_ooc.<機台或機型> 等覆蓋：合併後（機台 → 機型 → 整組）也要符合"""
    def num(key):
        v = get(section, key)
        if not v:
            return None
        try:
            return float(v)
        except ValueError:
            errors.append('%s [%s] %s 必須是數字或留空：%s' % (label, section, key, v))
            return None
    vals = dict((key, num(key)) for key in SPEC_KEYS)
    where = '%s [%s]' % (label, section)
    check_spec_values(where, vals, offset, errors)

    models = models or {}

    def model_of_name(name):
        for m, needle in models.items():
            if name.lower() in (m.lower(), needle.lower()):
                return m
        return None

    by_model, by_tool = {}, {}
    for opt in parser.options(section):
        base = opt.split('.', 1)[0]
        if '.' not in opt or base not in SPEC_KEYS:
            continue
        name = opt.split('.', 1)[1].strip()
        if not name:
            errors.append('%s %s 格式錯誤，應為 %s.<機台或機型>' % (where, opt, base))
            continue
        m = model_of_name(name)
        if m is not None:
            by_model.setdefault(m, {})[base] = num(opt)
        else:
            by_tool.setdefault(name.lower(), {})[base] = num(opt)
    for m, o in by_model.items():
        merged = dict(vals)
        merged.update(o)
        check_spec_values('%s 機型 %s' % (where, m), merged, offset, errors)
    for tool, o in by_tool.items():
        merged = dict(vals)
        for m, needle in models.items():
            if needle.lower() in tool:
                merged.update(by_model.get(m, {}))
                break
        merged.update(o)
        check_spec_values('%s 機台 %s' % (where, tool.upper()), merged, offset, errors)


def check_chart(name, errors, warnings):
    """檢查一張 chart 的 ini 與 php"""
    label = 'charts/%s.ini' % name
    parser = RawConfigParser()
    parser.optionxform = str
    try:
        with open(os.path.join(CHARTS, name + '.ini')) as fp:
            parser.readfp(fp)
    except Exception as e:  # 語法錯誤
        errors.append('%s 解析失敗：%s' % (label, e))
        return

    def get(section, key):
        return unquote(parser.get(section, key)) if parser.has_option(section, key) else ''

    source = (get('page', 'source') or 'php').lower() if parser.has_section('page') else 'php'
    if source not in ('php', 'sample'):
        errors.append('%s [page] source 只能是 php 或 sample' % label)
    for key in ('default_days', 'max_days'):
        v = get('page', key) if parser.has_section('page') else ''
        if v and (not v.isdigit() or int(v) < 1):
            errors.append('%s [page] %s 必須是正整數' % (label, key))

    if parser.has_section('db'):
        check_chart_db(label, parser, get, errors)

    models = {}
    if parser.has_section('page'):
        for opt in parser.options('page'):
            if opt.startswith('model.') and opt[6:] and get('page', opt):
                models[opt[6:]] = get('page', opt)

    plots = 0
    for section in parser.sections():
        if section in ('page', 'db'):
            continue
        if not RE_PLOT.match(section):
            errors.append('%s 區段名稱錯誤：[%s]，應為 [page]、[db] 或 [plot.<小寫代號>]' % (label, section))
            continue
        plots += 1
        if not split_list(get(section, 'params')):
            errors.append('%s [%s] 沒有設定 params' % (label, section))
        for opt in parser.options(section):
            if opt.endswith('ymin') or opt.endswith('ymax'):
                v = get(section, opt)
                if v:
                    try:
                        float(v)
                    except ValueError:
                        errors.append('%s [%s] %s 必須是數字：%s' % (label, section, opt, v))
        check_spec(label, section, parser, get, errors,
                   check_chart_target(label, section, parser, get, errors), models)
    if plots == 0:
        errors.append('%s 沒有任何 [plot.xxx] 圖' % label)

    php = os.path.join(CHARTS, name + '.php')
    if source == 'php':
        if not os.path.isfile(php):
            errors.append('charts/%s.php 不存在（尚未寫好時可先把 ini 的 source 設為 sample）' % name)
        else:
            with open(php) as fp:
                code = fp.read()
            if not re.search(r'class\s+' + re.escape(name) + r'Chart\s+extends\s+ChartSource\b', code):
                errors.append('charts/%s.php 裡找不到 class %sChart extends ChartSource' % (name, name))
            if '尚未實作' in code:
                warnings.append('charts/%s.php 似乎還沒寫好 SQL（仍有「尚未實作」），但 ini 的 source = php' % name)

def check_tool_board(ee_accounts, errors, warnings):
    """借機 / PM 看板設定"""
    shared_file = os.path.join(ROOT, 'config', 'tool_board.ini')
    label = 'config/tool_board.ini'
    if not os.path.isfile(shared_file):
        errors.append('找不到 %s' % label)
        return
    shared = RawConfigParser()
    try:
        with open(shared_file) as fp:
            shared.readfp(fp)
    except Exception as e:  # noqa
        errors.append('%s 解析失敗：%s' % (label, e))
        return

    def sget(parser, section, key):
        return unquote(parser.get(section, key)) if parser.has_option(section, key) else ''

    models = [m.upper() for m in shared.options('models')] if shared.has_section('models') else []
    if not models:
        errors.append('%s 的 [models] 沒有任何機型' % label)

    def check_categories(parser, where):
        codes = []
        for section in parser.sections():
            if not section.startswith('category.'):
                continue
            code = section[len('category.'):]
            codes.append(code)
            if not RE_CODE.match(code):
                errors.append('%s [%s] 類別代碼只能用小寫英數字與底線' % (where, section))
            color = sget(parser, section, 'color')
            if color and not RE_HEX.match(color):
                errors.append('%s [%s] color "%s" 不是 Hex 色號（例 "#E67E22"）' % (where, section, color))
        return codes

    categories = check_categories(shared, label)
    if not categories:
        errors.append('%s 沒有任何 [category.<代碼>]' % label)
    pm_category = sget(shared, 'pm', 'category') or 'pm'
    if pm_category not in categories:
        warnings.append('%s [pm] category "%s" 不是已定義的類別' % (label, pm_category))

    def check_formula(formula, where):
        """可用率公式：default 或 modules/tool_board/formulas/<Camel>.php 的 <Camel>Availability"""
        if formula == 'default':
            return
        if not RE_FORMULA.match(formula):
            errors.append('%s [availability] formula "%s" 只能用小寫英數字與底線，且以英文字母開頭' % (where, formula))
            return
        camel = ''.join(w.capitalize() for w in formula.split('_'))
        php = os.path.join(MODULES, 'tool_board', 'formulas', camel + '.php')
        if not os.path.isfile(php):
            errors.append('%s [availability] formula "%s" 找不到 modules/tool_board/formulas/%s.php' % (where, formula, camel))
            return
        with open(php) as fp:
            if not re.search(r'class\s+%sAvailability\b' % camel, fp.read()):
                errors.append('modules/tool_board/formulas/%s.php 裡沒有 class %sAvailability（formula "%s"）' % (camel, camel, formula))

    def check_alert(parser, where):
        """回傳該檔的 alert_below（沒寫 = None）"""
        if parser.has_option('availability', 'warn_below'):
            warnings.append('%s [availability] warn_below 已不使用（只剩 alert_below 紅色門檻），可刪除' % where)
        v = sget(parser, 'availability', 'alert_below')
        if v == '':
            return None
        try:
            f = float(v)
        except ValueError:
            errors.append('%s [availability] alert_below 必須是數字：%s' % (where, v))
            return None
        if f < 0 or f > 100:
            warnings.append('%s [availability] alert_below = %s 不在 0 ～ 100 之間' % (where, v))
        return f

    shared_formula = (sget(shared, 'availability', 'formula') or 'default').lower()
    check_formula(shared_formula, label)
    shared_alert = check_alert(shared, label)
    if shared_alert is None:
        shared_alert = 80.0

    pm_path = sget(shared, 'pm', 'json_path')
    if pm_path:
        if not os.path.isfile(pm_path):
            warnings.append('%s [pm] json_path 檔案不存在：%s（看板會顯示警告，其他功能正常）' % (label, pm_path))
        else:
            import json
            import ast
            with open(pm_path) as fp:
                text = fp.read()
            data = None
            try:
                data = json.loads(text)
            except ValueError:
                try:
                    data = ast.literal_eval(text)
                    warnings.append('PM 檔 %s 不是標準 JSON（單引號），看板會自動轉換；請產生端改用 json.dump' % pm_path)
                except Exception:  # noqa
                    errors.append('PM 檔 %s 無法解析' % pm_path)
            # period（PM 週期，選填）：文字，最多 32 字，超過會被截斷
            if isinstance(data, dict):
                for tool, pms in data.items():
                    if not isinstance(pms, dict):
                        continue
                    for typ, p in pms.items():
                        if not isinstance(p, dict) or p.get('period') is None:
                            continue
                        per = p.get('period')
                        if isinstance(per, (dict, list, bool)):
                            warnings.append('PM 檔 %s / %s 的 period 不是文字，不會顯示' % (tool, typ))
                            continue
                        if isinstance(per, str):
                            per = per.decode('utf-8', 'replace')
                        if len(unicode(per).strip()) > 32:  # noqa: F821（Python 2.7）
                            warnings.append('PM 檔 %s / %s 的 period 超過 32 字，會被截斷' % (tool, typ))

    owner = {}
    defaults_wip = [(c, sget(shared, 'category.' + c, 'default_wip')) for c in categories]
    for m in models:
        rel = 'config/tool_board/%s.ini' % m
        path = os.path.join(ROOT, rel)
        if not os.path.isfile(path):
            errors.append('找不到機型設定檔 %s' % rel)
            continue
        parser = RawConfigParser()
        try:
            with open(path) as fp:
                parser.readfp(fp)
        except Exception as e:  # noqa
            errors.append('%s 解析失敗：%s' % (rel, e))
            continue
        tools = read_array('tools', 'tool', path)
        if not tools:
            warnings.append('%s 的 [tools] 沒有任何機台' % rel)
        for t in tools:
            if not RE_TOOL.match(t):
                errors.append('%s 機台代號格式錯誤：%s' % (rel, t))
                continue
            key = t.upper()
            if key in owner and owner[key] != m:
                errors.append('機台 %s 同時列在 %s 與 %s' % (key, owner[key], m))
            elif key in owner:
                warnings.append('%s 機台重複：%s' % (rel, key))
            owner[key] = m
        editors = read_array('editors', 'account', path)
        if not editors:
            warnings.append('%s 的 [editors] 沒有任何帳號，這個機型只有 ADMIN 能編輯' % rel)
        for a in editors:
            if not RE_ACCOUNT.match(a):
                errors.append('%s [editors] 帳號格式錯誤：%s' % (rel, a))
            elif a.lower() not in ee_accounts:
                warnings.append('%s [editors] %s 不在 [ee_accounts]，若不是 EE 帳號將無法編輯' % (rel, a))
        wips = []
        for section in parser.sections():
            if section.startswith('wip.'):
                code = section[len('wip.'):]
                wips.append(code)
                if not RE_CODE.match(code):
                    errors.append('%s [%s] WIP 代碼只能用小寫英數字與底線' % (rel, section))
                color = sget(parser, section, 'text_color')
                if color and not RE_HEX.match(color):
                    errors.append('%s [%s] text_color "%s" 不是 Hex 色號' % (rel, section, color))
        if not wips:
            errors.append('%s 沒有任何 [wip.<代碼>]（WIP 處理方式）' % rel)
        check_categories(parser, rel)
        for cat, dw in defaults_wip:
            if dw and dw not in wips:
                warnings.append('%s 沒有 [wip.%s]，類別 %s 的 default_wip 在這個機型改選第一個' % (rel, dw, cat))
        # 可用率：機型檔沒寫的項目沿用共用檔
        formula = (sget(parser, 'availability', 'formula') or shared_formula).lower()
        if parser.has_option('availability', 'formula'):
            check_formula(formula, rel)
        alert = check_alert(parser, rel)
        if alert is None:
            alert = shared_alert
        print('== 借機看板 %s：機台 %d 台、可編輯 %s、WIP %s、可用率公式 %s（低於 %g 紅）==' % (
            m, len(tools), ', '.join(editors) or '-', ', '.join(wips) or '-', formula, alert))

def check_tool_select(roles, errors, warnings):
    """設備選機表設定"""
    shared_file = os.path.join(ROOT, 'config', 'tool_select.ini')
    label = 'config/tool_select.ini'
    if not os.path.isfile(shared_file):
        errors.append('找不到 %s' % label)
        return
    shared = RawConfigParser()
    try:
        with open(shared_file) as fp:
            shared.readfp(fp)
    except Exception as e:  # noqa
        errors.append('%s 解析失敗：%s' % (label, e))
        return

    def sget(parser, section, key):
        return unquote(parser.get(section, key)) if parser.has_option(section, key) else ''

    models = [m.upper() for m in shared.options('models')] if shared.has_section('models') else []
    if not models:
        errors.append('%s 的 [models] 沒有任何機型' % label)
    for sec in ('color', 'status'):
        if shared.has_section(sec):
            for opt in shared.options(sec):
                v = sget(shared, sec, opt)
                if v and not RE_HEX.match(v):
                    errors.append('%s [%s] %s "%s" 不是 Hex 色號（例 "#7A0000"）' % (label, sec, opt, v))

    def number(v, where):
        if v == '':
            return None
        try:
            return float(v)
        except ValueError:
            errors.append('%s 必須是數字或留空：%s' % (where, v))
            return None

    def check_order(vals, where):
        uoos, uooc, looc, loos = vals
        pairs = ((loos, looc, False), (looc, uooc, True), (uooc, uoos, False),
                 (loos, uoos, True), (loos, uooc, True), (looc, uoos, True))
        for lo, hi, strict in pairs:
            if lo is None or hi is None:
                continue
            if (lo >= hi) if strict else (lo > hi):
                errors.append('%s：spec 必須符合 lower_oos <= lower_ooc < upper_ooc <= upper_oos' % where)
                return

    for m in models:
        rel = 'config/tool_select/%s.ini' % m
        path = os.path.join(ROOT, rel)
        if not os.path.isfile(path):
            errors.append('找不到機型設定檔 %s' % rel)
            continue
        parser = RawConfigParser()
        try:
            with open(path) as fp:
                parser.readfp(fp)
        except Exception as e:  # noqa
            errors.append('%s 解析失敗：%s' % (rel, e))
            continue
        tools = []
        for t in read_array('tools', 'tool', path):
            if not RE_TOOL.match(t):
                errors.append('%s 機台代號格式錯誤：%s' % (rel, t))
            elif t.upper() in tools:
                warnings.append('%s 機台重複：%s' % (rel, t))
            else:
                tools.append(t.upper())
        if not tools:
            warnings.append('%s 的 [tools] 沒有任何機台' % rel)
        opts = parser.options('category') if parser.has_section('category') else []
        cats = [c for c in opts if '.' not in c]
        for c in cats:
            if not RE_TS_CODE.match(c):
                errors.append('%s [category] 代號只能用小寫英文、數字、底線：%s' % (rel, c))

        def role_list(value, where):
            # "EE,PE" → ['EE', 'PE']；留空 = 只有 ADMIN
            out = [r.strip() for r in value.split(',') if r.strip()]
            for r in out:
                if r not in roles:
                    errors.append('%s：身份 "%s" 未定義於 config.ini [roles]' % (where, r))
            return out

        cat_view = {}
        for c in opts:
            if '.' not in c:
                continue
            base, suffix = c.split('.', 1)
            where = '%s [category] %s' % (rel, c)
            if suffix != 'view':
                errors.append('%s 不認得的寫法（只能用 <代號>.view 限定身份）' % where)
            elif base not in cats:
                errors.append('%s 的分類 "%s" 不存在' % (where, base))
            else:
                cat_view[base] = role_list(sget(parser, 'category', c), where)
        if not cats:
            errors.append('%s 沒有 [category]（分類）' % rel)

        items = 0
        keys = {}
        for section in parser.sections():
            if not section.startswith('item.'):
                continue
            items += 1
            iid = section[len('item.'):]
            where = '%s [%s]' % (rel, section)
            if not RE_TS_ITEM.match(iid):
                errors.append('%s 項目代號只能用小寫英文、數字、底線' % where)
            cat = sget(parser, section, 'category')
            if cat not in cats:
                errors.append('%s category "%s" 不在 [category] 裡' % (where, cat))
            if parser.has_option(section, 'view'):
                iview = role_list(sget(parser, section, 'view'), '%s view' % where)
                if cat in cat_view:
                    wider = [r for r in iview if r not in cat_view[cat]]
                    if wider:
                        warnings.append('%s view 含 %s，但分類 %s 只限 %s；兩層都要符合才看得到，%s 仍看不到' % (
                            where, ','.join(wider), cat, ','.join(cat_view[cat]) or 'ADMIN', ','.join(wider)))
            key = (sget(parser, section, 'key') or iid).lower()
            if key in keys:
                warnings.append('%s 的 JSON key "%s" 和 [%s] 重複，兩個項目會顯示相同的值' % (where, key, keys[key]))
            keys[key] = section
            spec = [number(sget(parser, section, k), '%s %s' % (where, k)) for k in SPEC_KEYS]
            offset = False
            for opt in parser.options(section):
                if opt == 'target' or opt.startswith('target.'):
                    offset = True
                    number(sget(parser, section, opt), '%s %s' % (where, opt))
                    tool = opt[len('target.'):].strip().upper()
                    if opt != 'target' and tool not in tools:
                        errors.append('%s %s 的機台 %s 不在 [tools] 裡' % (where, opt, tool))

            def check_vals(vals, w):
                if offset:
                    check_offset_spec(w, dict(zip(SPEC_KEYS, vals)), errors)
                else:
                    check_order(vals, w)

            check_vals(spec, where)
            overrides = {}
            for opt in parser.options(section):
                if opt == 'target' or opt.startswith('target.'):
                    continue
                if '.' in opt:
                    base, tool = opt.split('.', 1)
                    tool = tool.upper()
                    if base not in SPEC_KEYS:
                        errors.append('%s 不認得的欄位 %s（機台覆蓋只能用 %s）' % (where, opt, ' / '.join(SPEC_KEYS)))
                        continue
                    if tool not in tools:
                        errors.append('%s %s 的機台 %s 不在 [tools] 裡' % (where, opt, tool))
                        continue
                    overrides.setdefault(tool, list(spec))[SPEC_KEYS.index(base)] = \
                        number(sget(parser, section, opt), '%s %s' % (where, opt))
                elif opt not in TS_ITEM_KEYS:
                    warnings.append('%s 不認得的欄位：%s（會被忽略）' % (where, opt))
            for tool, vals in overrides.items():
                check_vals(vals, '%s 機台 %s' % (where, tool))
            for k in ('ooc_bg', 'oos_bg', 'ooc_bg_light', 'oos_bg_light'):
                v = sget(parser, section, k)
                if v and not RE_HEX.match(v):
                    errors.append('%s %s "%s" 不是 Hex 色號' % (where, k, v))
            href = sget(parser, section, 'href')
            if href and (re.search(r'[\s"\'<>\\]', href) or not re.match(r'^(\?|/(?!/)|https?://)', href, re.I)):
                errors.append('%s href 只能是 "?m=..."、"/..." 或 http(s):// 開頭：%s' % (where, href))
            dec = sget(parser, section, 'decimals')
            if dec and not dec.isdigit():
                errors.append('%s decimals 必須是 0 以上的整數' % where)
        if not items:
            warnings.append('%s 沒有任何 [item.<代號>]（項目）' % rel)

        sample = sget(parser, 'page', 'sample').lower() in ('1', 'on', 'yes', 'true')
        json_path = sget(parser, 'page', 'json_path')
        status = '範例值' if sample else (json_path or '未設定 json_path')
        if not sample and json_path:
            if not os.path.isfile(json_path):
                warnings.append('%s [page] json_path 檔案不存在：%s（頁面會顯示警告，數值顯示 "-"）' % (rel, json_path))
            else:
                import json
                import ast
                with open(json_path) as fp:
                    text = fp.read()
                try:
                    json.loads(text)
                except ValueError:
                    try:
                        ast.literal_eval(text)
                        warnings.append('數值檔 %s 不是標準 JSON（單引號），頁面會自動轉換；請產生端改用 json.dump' % json_path)
                    except Exception:  # noqa
                        errors.append('數值檔 %s 無法解析' % json_path)
        print('== 選機表 %s：機台 %d 台、分類 %d、項目 %d、數值 %s ==' % (m, len(tools), len(cats), items, status))


def main():
    errors = []
    warnings = []

    parser = RawConfigParser()
    parser.optionxform = str  # 保留 key 大小寫（EE / PE）
    with open(INI) as fp:
        parser.readfp(fp)

    def get(section, key):
        return unquote(parser.get(section, key)) if parser.has_option(section, key) else ''

    roles = parser.options('roles') if parser.has_section('roles') else []

    # 選單分類
    groups = set()
    for section in parser.sections():
        if section.startswith('group.'):
            key = section[len('group.'):]
            if not RE_KEY.match(key):
                errors.append('[%s] 分類代號格式錯誤' % section)
            groups.add(key)
    used_groups = set()

    # 頁面
    pages = {}
    for section in parser.sections():
        if not section.startswith('page.'):
            continue
        key = section[len('page.'):]
        if not RE_KEY.match(key):
            errors.append('[%s] 頁面代號格式錯誤' % section)
            continue
        route = get(section, 'route') or ('module:' + key)
        pages[key] = route
        if route.startswith('module:'):
            target = os.path.join(MODULES, route[len('module:'):].strip(), 'controller.php')
            if not os.path.isfile(target):
                errors.append('[%s] 找不到 %s' % (section, os.path.relpath(target, ROOT)))
        else:
            target = os.path.join(ROOT, route.lstrip('/'))
            if not os.path.isfile(target):
                errors.append('[%s] route 檔案不存在：%s' % (section, route))
            elif route.lstrip('/').startswith('public/'):
                with open(target) as fp:
                    head = fp.read(4000)
                if 'auth_check.php' not in head:
                    errors.append('[%s] 獨立頁面 %s 沒有 require core/auth_check.php，任何人都能直接開啟' % (section, route))
        group = get(section, 'group')
        if group:
            used_groups.add(group)
            if group not in groups:
                warnings.append('[%s] group "%s" 沒有對應的 [group.%s]，將以代號當分類標題' % (section, group, group))
        for opt in parser.options(section):
            if opt.startswith('action.'):
                for r in split_list(parser.get(section, opt)):
                    if r not in roles:
                        errors.append('[%s] %s 的身份 %s 未定義' % (section, opt, r))

    for g in sorted(groups - used_groups):
        warnings.append('[group.%s] 沒有任何頁面使用' % g)

    # 身份 → 頁面
    access = {}
    superusers = []
    if not parser.has_section('access'):
        errors.append('缺少 [access] 區段')
    else:
        for role in parser.options('access'):
            if role not in roles:
                errors.append('[access] 身份 %s 未定義於 [roles]' % role)
            items = split_list(parser.get('access', role))
            if '*' in items:
                superusers.append(role)
                access[role] = sorted(pages.keys())
                continue
            for p in items:
                if p not in pages:
                    errors.append('[access] %s 的頁面 %s 沒有對應的 [page.%s]' % (role, p, p))
            access[role] = [p for p in items if p in pages]
    for role in roles:
        if role not in access:
            warnings.append('身份 %s 沒有寫在 [access]，登入後看不到任何頁面' % role)

    for key in sorted(pages):
        if not any(key in access[r] for r in access if r not in superusers):
            warnings.append('頁面 %s 只有 * 身份能使用（若是刻意的可忽略）' % key)

    module_dirs = set(r[len('module:'):].strip() for r in pages.values() if r.startswith('module:'))
    for name in sorted(os.listdir(MODULES)):
        if os.path.isdir(os.path.join(MODULES, name)) and not name.startswith('_') and name not in module_dirs:
            warnings.append('modules/%s 沒有登記在 config.ini，目前無法存取' % name)

    # 圖表
    names = chart_names()
    lower = {}
    for n in names:
        if n.lower() in lower:
            errors.append('charts/%s.ini 與 charts/%s.ini 只差大小寫，頁面代號會衝突' % (lower[n.lower()], n))
        lower[n.lower()] = n
    chart_pages = [k for k, r in pages.items() if r == 'module:charts']
    for key in sorted(chart_pages):
        if key not in lower:
            errors.append('[page.%s] route = module:charts，但 charts/ 裡沒有同名（不分大小寫）的 ini' % key)
        else:
            check_chart(lower[key], errors, warnings)
    for n in names:
        if n.lower() not in chart_pages:
            warnings.append('charts/%s.ini 沒有對應的 [page.%s]（route = "module:charts"），目前無法存取' % (n, n.lower()))

    # 註冊
    if parser.has_section('register'):
        for key in ('listed_role', 'unlisted_role'):
            role = get('register', key)
            if key == 'unlisted_role' and role == '':
                continue
            if role not in roles:
                errors.append('[register] %s "%s" 未定義於 [roles]' % (key, role))
            elif role in superusers:
                errors.append('[register] %s 不可設為超級身份 %s' % (key, role))
    seen = set()
    for account in read_array('ee_accounts', 'account'):
        if not RE_ACCOUNT.match(account):
            errors.append('[ee_accounts] 帳號格式錯誤：%s' % account)
        if account.lower() in seen:
            warnings.append('[ee_accounts] 帳號重複：%s' % account)
        seen.add(account.lower())

    if 'tool_board' in pages:
        check_tool_board(seen, errors, warnings)
    if 'tool_select' in pages:
        check_tool_select(roles, errors, warnings)

    print('== 身份可用頁面 ==')
    for role in roles:
        note = ' (*)' if role in superusers else ''
        print('  %-6s%s: %s' % (role, note, ', '.join(access.get(role, [])) or '-'))
    print('== EE 名單 (%d) ==' % len(seen))
    print('  ' + (', '.join(sorted(seen)) or '-'))
    print()
    for w in warnings:
        print(YELLOW + '[WARN]  ' + w + RESET)
    for e in errors:
        print(RED + '[ERROR] ' + e + RESET)
    if not errors:
        print(GREEN + '[OK] config.ini 檢查通過' + RESET)
    return 1 if errors else 0


if __name__ == '__main__':
    sys.exit(main())
