# AISLE 系統架構

多功能、模組化的內部網頁系統。依「身份」(EE / PE) 決定每位使用者能看到哪些功能頁面，介面採用駭客任務 (The Matrix) 綠色終端機風格。

| 層級 | 技術 | 備註 |
|---|---|---|
| 後端 | PHP 5.4 | 不使用 5.5+ 語法；資料庫一律 PDO prepared statement |
| 資料庫 | MariaDB 5.5 / 10.x | InnoDB、utf8mb4 |
| 輔助腳本 | Python 2.7、Bash | 權限檢查、建帳號、備份、產生模組 |
| 前端 | HTML5、jQuery 1.12.4、原生 Canvas | 不需要 Node / 建置工具 |

## 2. 資料庫

`sql/schema.sql` 建立三張表：

| 資料表 | 用途 |
|---|---|
| `users` | 帳號 `account`、密碼雜湊 `password_hash`、身份 `role`、啟用狀態、失敗次數與鎖定時間、強制改密碼旗標、最後登入時間與 IP |
| `login_logs` | 每次登入嘗試（成功或失敗原因），供稽核與暴力破解追查 |
| `audit_logs` | 模組操作紀錄，例如匯出報表、建立帳號、重設密碼 |

設計重點：

- **`role` 用 VARCHAR 而非 ENUM**：新增身份只要改 `config.ini`，不必 `ALTER TABLE`。
- **`password_hash` 留 255 長度**：目前 bcrypt 固定 60 字元，保留未來更換演算法的空間。
- **`created_at` 用 DATETIME 由程式寫入**：MariaDB 5.5 一張表只能有一個 TIMESTAMP 使用 `CURRENT_TIMESTAMP`，這個位置留給 `updated_at`。
- 有索引的 VARCHAR 欄位長度 ≤ 191，避免舊版 InnoDB 在 utf8mb4 下超過 767 bytes 索引上限。

### 密碼雜湊（PHP 5.4 的做法）

`password_hash()` / `password_verify()` 是 PHP 5.5 才有的函式。`core/password_compat.php` 在函式不存在時補上同名函式：以 `crypt()` 搭配 `$2y$` bcrypt（PHP ≥ 5.3.7 支援），鹽來自 `openssl_random_pseudo_bytes`，驗證時使用常數時間比較。因此程式碼照標準 API 寫 `password_hash($pw, PASSWORD_BCRYPT)`，在 PHP 5.4 與 5.5+ 都能執行，雜湊格式也完全相同；日後升級 PHP 只要刪掉這個檔案，舊密碼不需重設。

## 3. 身份 → 頁面權限與路由（`config/config.ini` + `core/auth_check.php`）

### config.ini

```ini
[roles]
EE    = "EE 工程師"
PE    = "PE 工程師"
ADMIN = "系統管理員"

; ★ 身份 → 可用頁面清單。同一頁面同時列在 EE 與 PE 就是兩者都能看；"*" = 全部
[access]
EE    = "dashboard, shared_report, report_daily, report_weekly, ee_equipment, ee_daily_check, profile"
PE    = "dashboard, shared_report, report_daily, report_weekly, pe_recipe, pe_notice, profile"
ADMIN = "*"

; ★ 選單分類（選用）：可收折，頁面寫 group = "report" 就收在這底下
[group.report]
title = "共用報表 // REPORTS"
order = 20
open  = Off                           ; 預設收起；瀏覽器會記住使用者的展開狀態

; ★ 頁面與路由
[page.shared_report]
title = "Report1 // 綜合報表"
route = "module:shared_report"        ; modules/shared_report/controller.php
group = "report"
order = 1                             ; 分類內的排序
action.export = "PE"                  ; EE、PE 都能看，只有 PE 能匯出

[page.report_daily]
title = "Report2 // 日報"
route = "pages/report_daily.php"
group = "report"
order = 2

[page.ee_daily_check]
title = "每日點檢 // DAILY CHECK"
route = "pages/ee_daily_check.php"    ; 一般 PHP 頁面

[page.pe_notice]
title = "製程公告 // NOTICE"
route = "public/legacy/pe_notice.php" ; 既有的獨立頁面
```

選單分類只影響顯示：權限仍由 `[access]` 決定，某身份在分類裡看不到任何頁面時整個分類不會出現；目前所在頁面的分類一律展開；沒寫 `group` 的頁面照舊單層顯示。

`route` 有三種寫法：

| route | 程式位置 | 網址 | 適合 |
|---|---|---|---|
| `module:<資料夾>` | `modules/<資料夾>/controller.php` | `index.php?m=<代號>&a=<動作>` | 有多個動作、AJAX 的功能 |
| `pages/xxx.php` | `pages/xxx.php` | `index.php?m=<代號>` | 單純頁面，不用寫 Controller，自動套用版面 |
| `public/xxx.php` | `public/xxx.php` | 直接開啟該檔案 | 既有網站的舊頁面，只需在第一行加一行 require |

### auth_check.php：所有頁面共用同一套檢查

```
使用者開啟頁面
  ├─ index.php?m=xxx  →  App 路由 ──────────┐
  └─ public/legacy/xxx.php（第一行 require）─┤
                                             ▼
                              core/auth_check.php
                    1. 未登入           → 導向 login.php（AJAX 回 401）
                    2. 頁面未登記在 config.ini → 403
                    3. 首次登入未改密碼 → 導向個人設定
                    4. 身份不在 [access] 清單、或不符 action.* → 403
                                             ▼
                          通過 → 依 route 載入頁面程式
```

既有頁面接上權限只要在第一行加入（依檔案位置調整 `../`）：

```php
<?php require_once dirname(__FILE__) . '/../../core/auth_check.php';
// 通過檢查後才會執行到這裡；可用 $AUTH_USER、$AUTH_PAGE
```

auth_check.php 用「目前執行的檔案」對照 config.ini 的 route 找出頁面代號，所以頁面本身不用寫自己的代號或身份。檔案若沒登記在 config.ini，即使加了 require 也一律拒絕，避免漏設權限的頁面被看到。獨立頁面送出 POST 時會檢查 CSRF，舊表單請加上 `<?php echo csrf_field(); ?>`；若一時無法修改，可把 `[settings] direct_page_csrf` 設為 `Off`。

權限一律在伺服器端檢查，隱藏選單只是介面效果；直接輸入網址也會得到 403。目前範例的結果：

| 頁面 | EE | PE | ADMIN |
|---|:-:|:-:|:-:|
| 主控台 dashboard | ✓ | ✓ | ✓ |
| 共用報表 › Report1 shared_report | ✓（不可匯出） | ✓ | ✓ |
| 共用報表 › Report2 report_daily、Report3 report_weekly（pages/） | ✓ | ✓ | ✓ |
| 個人設定 profile | ✓ | ✓ | ✓ |
| 設備狀態 ee_equipment | ✓ | | ✓ |
| 每日點檢 ee_daily_check（pages/） | ✓ | | ✓ |
| 製程配方 pe_recipe | | ✓ | ✓ |
| 製程公告 pe_notice（獨立頁面） | | ✓ | ✓ |
| 圖表 Demo chart_demo | ✓ | ✓ | ✓ |
| 使用者管理 admin_users | | | ✓ |

修改 config.ini 後執行 `python scripts/python/check_config.py`，會列出每個身份可用的頁面，並檢查拼字、route 檔案是否存在、獨立頁面有沒有 require auth_check.php。

## 4. 註冊、登入、登出與權限檢查

### 流程

| 檔案 | 方法 | 行為 |
|---|---|---|
| `public/register.php` | GET | 註冊頁 |
| | GET `?check_account=xxx`（AJAX） | 回傳帳號是否可用 |
| | POST | 驗證 → 依 EE 名單判定身份 → 寫入 `users`，並在 `audit_logs` 記錄身份來源 |
| `public/login.php` | GET / POST | 驗證帳密，成功後 `session_regenerate_id()` 並把使用者與身份寫入 `$_SESSION['user']` |
| `public/logout.php` | POST（或 `?_csrf=`） | 清除 Session 與 Cookie，導回 `login.php?bye=1` |

登入與註冊表單由 `js/auth.js` 以 jQuery 做即時驗證，並用 `$.ajax` 非同步送出，伺服器回 JSON。瀏覽器關閉 JavaScript 時表單照常以一般 POST 送出，伺服器端也會做完整驗證。

### 註冊時的身份判定（`config.ini` 的 `[register]` 與 `[ee_accounts]`）

註冊表單只填帳號、顯示名稱與密碼。身份在註冊當下依 INI 名單判定，直接寫入 `users.role`：

```ini
[register]
enabled          = On
require_approval = Off     ; On = 註冊後需管理員啟用
listed_role      = "EE"    ; 名單上的帳號
unlisted_role    = "PE"    ; 名單外的帳號；設為 "" 則名單外不能註冊

[ee_accounts]              ; EE 正面表列，一行一個帳號，不分大小寫
account[] = "neo"
account[] = "trinity"
```

- 名單只在註冊時讀取。之後增減名單，不會改變已經註冊的人的身份，要調整請直接改資料庫的 `users.role`。
- ADMIN 永遠無法經由註冊取得；`listed_role`、`unlisted_role` 若設成 superuser 角色會被忽略。
- `audit_logs` 會記錄每個帳號的身份來源（`ee_accounts` 或 `unlisted_role`）。
- 改完名單可以執行 `python scripts/python/check_config.py`，它會列出名單內容，並檢查帳號格式與重複。

### 共用權限檢查函式（`core/guard.php`）

```php
require_login();                    // 未登入 → 導向 login.php；AJAX 回 401
require_role('PE');                 // 身份不符 → 403（ADMIN 一律通過）
require_role('EE,PE');              // 多個身份用逗號
if (has_role('EE,PE')) { ... }      // 只判斷、不中止
if (can_access('shared_report', 'export')) { ... }   // 依 [access] 與 [page.xxx] 判斷
echo csrf_field();                  // 表單的 CSRF 隱藏欄位
current_user();  current_role();  is_logged_in();
```

頁面層級的權限由 `auth_check.php` 處理；這些函式用在頁面內更細的判斷，例如只對某身份顯示某個按鈕。

## 5. 新增功能頁面

只需要改 config.ini，核心程式（`core/`）不用動：

1. 放好頁面程式（擇一）：`pages/xxx.php`、`public/xxx.php`（第一行 require auth_check.php），或建立模組
2. 在 `[access]` 把頁面代號加進能使用它的身份
3. 新增 `[page.xxx]`，寫上 `title` 與 `route`
4. （選用）要放進選單分類就加上 `group = "<分類代號>"`；新分類再加一段 `[group.<分類代號>]`

例：新增一個 EE、PE 都能看的聯絡人頁面

```ini
[access]
EE = "dashboard, ..., team_contacts"
PE = "dashboard, ..., team_contacts"

[page.team_contacts]
title = "聯絡人 // CONTACTS"
route = "pages/team_contacts.php"
order = 60
```

需要多個動作或 AJAX 時用模組，腳本會產生程式骨架並自動完成上面第 2、3 步：

```bash
# 產生 modules/ee_alarm/，加入 EE、PE 的 [access] 清單並新增 [page.ee_alarm]
bash scripts/shell/new_module.sh ee_alarm "EE,PE" "警報中心 // ALARMS" 35
```

產生的骨架：

```php
<?php
class EeAlarmController extends Controller
{
    public function indexAction()          // index.php?m=ee_alarm
    {
        $this->render('index', array('message' => '...'));
    }

    public function listAction()           // index.php?m=ee_alarm&a=list
    {
        $rows = Database::fetchAll('SELECT ... WHERE x = ?', array($x));
        $this->json(array('ok' => true, 'rows' => $rows));
    }
}
```

Controller 可用的方法：`render()`、`json()`、`redirect()`、`can('動作')`、`isPost()`、`input()`、`query()`、`flash()`。View 中輸出變數一律用 `e($var)`；要放進 `<script>` 用 `js($var)`。

## 6. 安全機制

- bcrypt 密碼雜湊，提高 `bcrypt_cost` 後使用者下次登入自動升級雜湊
- 連續失敗 5 次鎖定 15 分鐘（`app.ini` 可調），帳號不存在時也執行一次 bcrypt，避免從回應時間猜出帳號
- 登入成功 `session_regenerate_id()`，閒置 30 分鐘自動登出，Cookie 設 HttpOnly
- 所有 POST（含 jQuery AJAX，透過 `X-CSRF-Token` 標頭）都檢查 CSRF token；登出也需要 token，避免被外部連結強制登出
- 註冊無法取得 ADMIN 身份；可開啟 `require_approval` 讓新帳號需管理員啟用，或把 `unlisted_role` 設為空字串只開放名單內帳號註冊
- 首次登入或被管理員重設密碼後強制改密碼
- 所有 SQL 使用 PDO prepared statement，`ATTR_EMULATE_PREPARES = false`

## 10. 圖表 Demo（chart_demo）

資料視覺化頁面範本，網址 `index.php?m=chart_demo`，EE、PE 可用。圖表使用 ECharts 5.4.3（`public/assets/vendor/` 有檔案時用本機的，否則走 jsDelivr CDN）。

| 區塊 | 內容 |
|---|---|
| 全域選擇器 | 起訖日期（含 7D / 30D / 90D 快捷）、單台機台 |
| single 單台機台趨勢 | 所選機台，每組一張圖，組內每個參數一條線；X 軸時間 |
| Newest_TBT 最新值排排站 | 每組一張長條圖，X 軸機台、每個參數一根長條，取每台在區間內的最後一個值；機型篩選 1980 / 2000 / All；點長條會切換上方的單台機台 |
| TBT 歷史趨勢排排站 | 每組一張圖，每台一個區段（依機台名稱排序），區段內依時間排序；圖例可開關機台，下方可拖曳縮放 |

### 圖表分組：`config/chart_demo.ini`

```ini
[chart.m1bf_z]
title  = "M1BF_Z"
params = "M1BF_Z_C1, M1BF_Z_C2"   ; 畫在同一張圖的參數
single = On                        ; 是否畫單台機台趨勢
newest = On                        ; 是否畫最新值排排站
tbt    = On                        ; 是否畫歷史趨勢排排站
ymin   = 0                         ; Y 軸下限（三張圖共用）
ymax   = 6                         ; Y 軸上限（三張圖共用）
newest_ymax = 5                    ; 只改最新值排排站的上限

[chart.m1bf_ry]
title  = "M1BF_Ry"
params = "M1BF_Ry_C1, M1BF_Ry_C2"
newest = Off                       ; 這組不顯示最新值排排站
tbt_ymin = 0                       ; 只設歷史趨勢排排站的上下限，單台趨勢維持自動
tbt_ymax = 6
```

- 每個 `[chart.<代號>]` 是一組，頁面依檔案順序畫圖；`single` / `newest` / `tbt` 省略時為 On
- 某區塊沒有任何一組開啟時，整個區塊不顯示
- 可選 `unit` 設定 Y 軸名稱（預設 `Data`）
- Y 軸上下限：`ymin` / `ymax` 套用到該組三張圖；`single_ymin`、`newest_ymax`、`tbt_ymin` 等只套用到該區塊並優先；不設或留空為自動，超出範圍的資料會被裁切
- 存檔後重新整理頁面即生效；格式錯誤時頁面會顯示錯誤（`modules/chart_demo/ChartConfig.php` 檢查）

### 資料格式與載入

後端 `index.php?m=chart_demo&a=tbt&start=&end=` 回傳區間內全部機台、`chart_demo.ini` 用到的全部參數：

```json
{
  "APAN01": { "Date": ["2026-01-01", "2026-01-02"],
              "Data": { "M1BF_Z_C1": [1.0, 2.0], "M1BF_Z_C2": [1.1, 2.1], "M1BF_Ry_C1": [1.0, 2.0], "M1BF_Ry_C2": [1.1, 2.1] } }
}
```

- 每個參數陣列與 `Date` 等長，沒有值的位置是 `null`；排序、型別、補 null 由 controller 統一處理，資料來源不需要先排好
- 進入頁面時只呼叫一次，所有圖都從這份資料取得。切換機台、切換機型只在瀏覽器端重畫，不再向後端要資料；只有改日期區間（查詢 / 快速區間）才重新取
- 機型判斷：名稱含 `PAN` → 1980、含 `PAP` → 2000（`ChartDemoController::modelOf()`）
- 編碼：**顏色 = 機台**（同機型內依序取色，跟著機台走，篩選後不變）、**線型 / 長條紋理 = 參數**（組內第 1 個參數實線，第 2 個虛線、斜線紋理…）
- 每張圖都有「資料表」按鈕可切換成表格檢視；查詢區間上限 366 天（`ChartDemoController::MAX_DAYS`）

# AISLE 部署步驟

以下指令以實際環境為例：

| 項目 | 值 |
|---|---|
| 程式來源 | GitHub `bboysevenwu/AISLE` 的 `main` branch |
| 部署位置 | `/var/www/html/aisle/`（Apache DocumentRoot 為 `/var/www/html`） |
| 對外網址 | `http://sccproxyauth-a-dc1-38.scc.f18.tsmc.com/D1C1/aisle/`（proxy 前綴 `/D1C1/`） |
| Web Server 執行身份 | `apache`（Debian/Ubuntu 為 `www-data`） |

網址的對應關係：

```
瀏覽器  http://sccproxyauth-a-dc1-38.scc.f18.tsmc.com/D1C1/aisle/login.php
  │ proxy 去掉 /D1C1 前綴後轉給主機
主機    http://<主機>/aisle/login.php
  │ /var/www/html/aisle/.htaccess 在內部轉進 public/
檔案    /var/www/html/aisle/public/login.php
```

網址不會出現 `public/`；`config/`、`core/` 等目錄經由網址存取一律 404。

## 11. 設定 Apache

程式放在 `/var/www/html/aisle/`，靠專案根目錄的 `.htaccess` 把請求轉進 `public/`，所以需要：

1. 開啟 `mod_rewrite`：
   ```bash
   httpd -M | grep rewrite        # Debian/Ubuntu：a2enmod rewrite
   ```
2. 允許 `/var/www/html/aisle` 使用 `.htaccess`（寫在 `httpd.conf` 或 `conf.d/aisle.conf`）：
   ```apache
   <Directory /var/www/html/aisle>
       AllowOverride All
   </Directory>
   ```
3. 套用設定：
   ```bash
   apachectl configtest && apachectl graceful
   ```

沒有 `mod_rewrite` 時，根目錄 `.htaccess` 會拒絕整個 `/aisle/`（避免設定檔外洩），網站會是 403。

> 另一種做法：若可以為 AISLE 開一個獨立的 VirtualHost，可把 `DocumentRoot` 直接指向 `/var/www/html/aisle/public`，此時根目錄 `.htaccess` 不會被讀到，`base_url` 依對外路徑調整。

## 12. 確認網址與敏感檔案

先在主機上直接測（不經 proxy，路徑沒有 `/D1C1`）：

```bash
curl -I http://localhost/aisle/login.php             # 200
curl -I http://localhost/aisle/config/app.ini        # 404（不可是 200）
curl -I http://localhost/aisle/core/bootstrap.php    # 404
```

再從自己的電腦經 proxy 測：

```bash

curl -I $P/                      # 302，Location 為 /D1C1/aisle/login.php
curl -I $P/login.php             # 200，Set-Cookie 的 path=/D1C1/aisle/
curl -I $P/assets/css/matrix.css # 200
curl -I $P/config/app.ini        # 404
```

（proxy 需要登入驗證時，用瀏覽器開啟 `$P/` 確認會跳到登入頁、畫面有綠色樣式即可。）

注意：`base_url` 設成 `/D1C1/aisle` 後，網頁內的連結都帶 `/D1C1` 前綴，**直接連主機 `http://<主機>/aisle/` 時頁面能開但連結會失效**，這是正常的，請一律從 proxy 網址使用。若 proxy 轉址後出現 `/D1C1/D1C1/...` 或少了 `/D1C1`，代表 proxy 對 `Location` 標頭有另外改寫，請告知 proxy 管理者或改 `base_url`。

## 18. 不能 git pull 時的更新方式（單檔更新）

公司內只能開 GitHub 網頁複製文字時使用。每次更新會在 repo 的 `updates/` 放一個純文字更新檔，裡面包含這次新增、修改、刪除的所有檔案；在主機上貼成一個檔案，執行一次 `apply_update.py` 就全部更新完。

### 18-1. 第一次：把 apply_update.py 放到主機上

在 GitHub 打開 `scripts/python/apply_update.py`，按 **Raw**，全選複製，然後在主機上：

```bash
cd /var/www/html/aisle
cat > scripts/python/apply_update.py     # 貼上內容，最後按 Enter 再按 Ctrl-D
chmod +x scripts/python/apply_update.py
python scripts/python/apply_update.py -h # 出現用法說明即可
```

之後的更新檔若包含新版的 `apply_update.py`，會自動一起更新，不需要再手動複製。

### 18-2. 每次更新

1. 在 GitHub 打開 `updates/` 底下這次的更新檔（例 `update_20261104_7d8729a_xxxxxxx.txt`），按 **Raw**，`Ctrl-A` 全選、`Ctrl-C` 複製
2. 貼到主機上，放在網站目錄以外（例 `~/`）：
   ```bash
   cat > ~/update.txt     # 貼上，最後按 Enter 再按 Ctrl-D
   ```
   用 `vi` 貼上時，先輸入 `:set paste` 再進入插入模式，否則 vi 會自動加縮排，內容會對不上
3. 先預覽（不會改任何檔案）：
   ```bash
   cd /var/www/html/aisle
   python scripts/python/apply_update.py ~/update.txt
   ```
   會列出每個檔案是 `[新增]`、`[覆蓋]`、`[刪除]` 還是 `[相同]`，以及備份檔名
4. 確認後實際套用：
   ```bash
   python scripts/python/apply_update.py ~/update.txt --apply
   ```
5. 新增了 config.ini 的頁面時，照第 8 步執行 `check_config.py`

### 腳本會做的檢查

| 狀況 | 結果 |
|---|---|
| 複製時漏了一段、貼了兩次、更新檔被截斷 | 每個檔案都有 sha1，結尾有項目數；任何一個對不上就整批不寫入 |
| vi 自動縮排、Windows 換行（CRLF）、UTF-8 BOM | 換行與 BOM 會自動處理；縮排被改會被 sha1 擋下 |
| 主機上的檔案被直接改過（和更新前的版本不同） | 列為「衝突」並停止。確認可以覆蓋後加 `--force`（仍會先備份） |
| 寫入到一半失敗（權限不足等） | 自動把已經改過的檔案還原 |
| 同一個更新檔執行兩次 | 第二次全部顯示 `[相同]`，不會再改 |

### 備份與還原

- 被覆蓋的檔案先複製一份在原位置，檔名後面加上 `_<日期>_<時間>`，例 `core/Auth.php_20261104_204500`；被刪除的檔案改名成同樣格式，不會真的刪掉
- 同一次執行共用同一個時間，紀錄寫在 `storage/logs/update_<時間>.json`
- 根目錄與 `public/` 的 `.htaccess` 會擋掉這種備份檔名（403），避免舊版程式碼被當純文字下載
- 查看紀錄與主機目前的版本：
  ```bash
  python scripts/python/apply_update.py --list
  ```
- 還原某次更新（先預覽，再加 `--apply`；`last` 代表最近一次）：
  ```bash
  python scripts/python/apply_update.py --rollback 20261104_204500
  python scripts/python/apply_update.py --rollback 20261104_204500 --apply
  ```
  還原會把備份檔改回原檔名，並移除那次新增的檔案
- 備份檔確認不需要後可以手動刪除，例 `find . -name '*_20261104_204500' -delete`

### 產生更新檔（開發端）

在有 git 的電腦上，指定主機目前的版本（`--list` 最後一筆的「版本 → 」右邊，或部署時的 commit）：

```bash
python scripts/python/make_update.py 7d8729a HEAD --note "這次更新的說明"
```

輸出到 `updates/update_<日期>_<舊>_<新>.txt`，commit 後即可在 GitHub 打開。預設不打包 `updates/` 與 `docs/screenshots/`；圖片等非文字檔會用 base64 存放。主機版本不明時可用 `--all` 打包全部檔案（不檢查衝突）。`config/app.ini` 不在 git 裡，不會被更新檔覆蓋。
#@@@ FILE modules/chart_demo/ChartConfig.php sha1=068fa3ad8342e17594dc287a33a1d0c2afa1d944 base=- mode=644 enc=text nl=1
<?php
/**
 * 讀取 config/chart_demo.ini：哪些參數畫在同一張圖、各區塊是否顯示
 *
 * ChartConfig::groups() 回傳（依檔案順序）：
 *   array(
 *     array('id' => 'm1bf_z', 'title' => 'M1BF_Z', 'params' => array('M1BF_Z_C1', 'M1BF_Z_C2'),
 *           'unit' => 'Data', 'single' => true, 'newest' => true, 'tbt' => true,
 *           'limits' => array('single' => array('min' => 0, 'max' => 5), 'newest' => array(...), 'tbt' => array(...))),
 *   min / max 為 null 表示自動
 *     ...
 *   )
 */
class ChartConfig
{
    private static $groups = null;

    public static function file()
    {
        return AISLE_ROOT . '/config/chart_demo.ini';
    }

    public static function groups()
    {
        if (self::$groups !== null) {
            return self::$groups;
        }
        $file = self::file();
        if (!is_file($file)) {
            throw new RuntimeException('找不到 config/chart_demo.ini');
        }
        $ini = parse_ini_file($file, true);
        if ($ini === false) {
            throw new RuntimeException('config/chart_demo.ini 解析失敗，請檢查引號與語法');
        }

        $groups = array();
        foreach ($ini as $section => $conf) {
            if (!preg_match('/^chart\.([a-z][a-z0-9_]{0,63})$/', $section, $m)) {
                throw new RuntimeException('config/chart_demo.ini 區段名稱錯誤：[' . $section . ']，應為 [chart.<小寫代號>]');
            }
            $params = array();
            foreach (explode(',', (string) array_get($conf, 'params', '')) as $p) {
                $p = trim($p);
                if ($p !== '' && !in_array($p, $params, true)) {
                    $params[] = $p;
                }
            }
            if (!$params) {
                throw new RuntimeException('config/chart_demo.ini [' . $section . '] 沒有設定 params');
            }
            $groups[] = array(
                'id'     => $m[1],
                'title'  => (string) array_get($conf, 'title', $m[1]),
                'params' => $params,
                'unit'   => (string) array_get($conf, 'unit', 'Data'),
                'single' => self::flag($conf, 'single'),
                'newest' => self::flag($conf, 'newest'),
                'tbt'    => self::flag($conf, 'tbt'),
                'limits' => array(
                    'single' => self::limits($conf, 'single', $section),
                    'newest' => self::limits($conf, 'newest', $section),
                    'tbt'    => self::limits($conf, 'tbt', $section),
                ),
            );
        }
        if (!$groups) {
            throw new RuntimeException('config/chart_demo.ini 沒有任何 [chart.xxx] 圖表');
        }
        self::$groups = $groups;
        return $groups;
    }

    /** 所有圖表用到的參數（不重複，依出現順序） */
    public static function params()
    {
        $out = array();
        foreach (self::groups() as $g) {
            foreach ($g['params'] as $p) {
                if (!in_array($p, $out, true)) {
                    $out[] = $p;
                }
            }
        }
        return $out;
    }

    private static function limits($conf, $kind, $section)
    {
        $out = array();
        foreach (array('min', 'max') as $k) {
            $v = null;
            foreach (array($kind . '_y' . $k, 'y' . $k) as $key) {
                if (array_key_exists($key, $conf) && trim((string) $conf[$key]) !== '') {
                    $raw = trim((string) $conf[$key]);
                    if (!is_numeric($raw)) {
                        throw new RuntimeException('config/chart_demo.ini [' . $section . '] ' . $key . ' 必須是數字：' . $raw);
                    }
                    $v = (float) $raw;
                    break;
                }
            }
            $out[$k] = $v;
        }
        if ($out['min'] !== null && $out['max'] !== null && $out['min'] >= $out['max']) {
            throw new RuntimeException('config/chart_demo.ini [' . $section . '] ' . $kind . ' 的 Y 軸下限必須小於上限');
        }
        return $out;
    }

    /** On / Off；未設定時為 On。parse_ini_file 會把 On 轉成 "1"、Off 轉成 "" */
    private static function flag($conf, $key)
    {

            return true;
        }
        $v = strtolower(trim((string) $conf[$key]));
        return !($v === '' || $v === '0' || $v === 'off' || $v === 'false' || $v === 'no');
    }

     * $param = '' 時只用來判斷這天是否停機
     */
    private static function sampleValue($tool, $param, $day)
    {
        if ($param === '') {
            return abs(crc32($tool . '|' . $day)) % 9 === 0 ? null : 0;
        }
        $h = abs(crc32($tool . '|' . $param . '|' . $day));
        $seed = abs(crc32($tool));
        // 同一台的參數走勢相近，各參數再加一點固定偏移
        $base = 1.2 + ($seed % 300) / 100 + (abs(crc32($param)) % 60) / 100 - 0.3;
        $n = floor(strtotime($day) / 86400);               // 絕對天數
        $wave = 0.6 * sin($n / (5 + $seed % 7) + $seed % 10);
        $noise = (($h % 1000) / 1000 - 0.5) * 0.5;
        return round(max(0, $base + $wave + $noise), 3);
    }

    /** 讀取並檢查 start / end，失敗時已輸出錯誤並回傳 null */
    private function range()
    {
        $start = $this->query('start');
        $end = $this->query('end');
        if (!self::isDate($start) || !self::isDate($end)) {
            $this->fail('日期格式需為 YYYY-MM-DD');
            return null;
        }
        if ($start > $end) {
            $this->fail('起始日期不可晚於結束日期');
            return null;
        }
        $days = (strtotime($end) - strtotime($start)) / 86400 + 1;
        if ($days > self::MAX_DAYS) {
            $this->fail('查詢區間最多 ' . self::MAX_DAYS . ' 天');
            return null;
        }
        return array($start, $end);

    private static function isDate($s)
    {
        if (!preg_match('/^(\d{4})-(\d{2})-(\d{2})$/', $s, $m)) {
            return false;
        }
        return checkdate((int) $m[2], (int) $m[3], (int) $m[1]);
    }

    private function sortTools($tools)
    {
        $tools = array_values(array_unique(array_map('strval', $tools)));
        sort($tools, SORT_NATURAL | SORT_FLAG_CASE);
        return $tools;

    /**
     * 統一整理資料來源的結果：
     *   - 只保留 $tools 中的機台，並依 $tools 的順序輸出
     *   - 每台依 Date 排序；Data 只保留 $params，依 $params 的順序輸出，缺少的參數整列補 null
     *   - 數值轉成數字，不是數字的轉成 null；所有參數都是 null 的時間點丟掉
     */
    private function normalize($data, $tools, $params)
    {
        $out = array();
        foreach ($tools as $tool) {
            if (!isset($data[$tool]['Date'], $data[$tool]['Data'])
                || !is_array($data[$tool]['Date']) || !is_array($data[$tool]['Data'])) {
                continue;
            }
            $dates = array_values($data[$tool]['Date']);
            $cols = array();
            foreach ($params as $p) {
                $cols[$p] = isset($data[$tool]['Data'][$p]) && is_array($data[$tool]['Data'][$p])
                    ? array_values($data[$tool]['Data'][$p]) : array();
            }
            $rows = array();  // array(date, array(param => value))
            foreach ($dates as $i => $date) {
                $values = array();
                $any = false;
                foreach ($params as $p) {
                    $v = null;
                    if (isset($cols[$p][$i]) && is_numeric($cols[$p][$i])) {
                        $v = (float) $cols[$p][$i];
                        $any = true;
                    }
                    $values[$p] = $v;
                }
                if ($any) {
                    $rows[] = array((string) $date, $values);
                }
            }
            if (!$rows) {
                continue;
            }
            usort($rows, array('ChartDemoController', 'cmpRow'));
            $series = array('Date' => array(), 'Data' => array());
            foreach ($params as $p) {
                $series['Data'][$p] = array();
            }
            foreach ($rows as $r) {
                $series['Date'][] = $r[0];
                foreach ($params as $p) {
                    $series['Data'][$p][] = $r[1][$p];
                }
            }
            $out[$tool] = $series;
        }
        return $out;
    }

    public static function cmpRow($a, $b)
    {
        return strcmp($a[0], $b[0]);
    }

    /** 輸出 JSON；沒有資料時輸出 {} 而不是 [] */
    private function output($data)
    {
        $this->json($data ? $data : new stdClass());
    }

    private function fail($message)
    {
        $this->json(array('ok' => false, 'error' => $message), 400);
    }

/*
 * chart_demo 頁面 (jQuery 1.12 + ECharts 5)
 *
 * 三個區塊：single 單台趨勢 / newest 最新值排排站 / tbt 歷史趨勢排排站
 * 每個區塊依 config/chart_demo.ini 的圖表分組各畫一張圖（CFG.groups），
 * 同一組的參數（例 M1BF_Z_C1、M1BF_Z_C2）畫在同一張圖上。
 *
 * 後端回傳格式：
 *   { "APAN01": { "Date": [...], "Data": { "M1BF_Z_C1": [...], "M1BF_Z_C2": [...] } }, ... }
 *   每個參數陣列與 Date 等長，沒有值的位置是 null
 *
 * 資料載入方式：
 *   進入頁面時只呼叫一次 tbt，取回日期區間內「全部機台、全部參數」的資料存在 cache，所有圖都從這份資料取得：
 *     TBT 直接畫；single 取出所選機台；Newest_TBT 取每台每個參數在區間內的最後一個值（再依機型篩選）
 *   之後切換機台、切換機型只用 cache 重畫，不再發 request；
 *   只有改日期區間（查詢 / 快速區間）才會重新取 tbt。
 *
 * 編碼方式：顏色 = 機台，線型 / 長條紋理 = 參數（同組第 1 個參數實線無紋理，第 2 個虛線斜紋…）
 * 只用 ES5 語法，避免舊瀏覽器出錯
 */
(function ($, window) {
    'use strict';

    var CFG = window.AISLE_CHART_DEMO;
    if (!$ || !CFG) {
        return;
    }

    // ---------- 主題 ----------
    // 機台顏色：8 色類別色盤（已用 dataviz validate_palette.js 檢查深色底 #001406：
    // 亮度、彩度、色盲區分、對比全部通過）。同機型內依序取色，APAN01 與 APAP01 同色，
    // 以 X 軸機台名稱區分。顏色跟著機台走，篩選後不會變色。
    var PALETTE = ['#3987e5', '#d95926', '#199e70', '#c98500', '#d55181', '#008300', '#9085e9', '#e66767'];
    // 參數：線型與長條紋理，依參數在組內的順序取用
    var LINE_TYPES = ['solid', 'dashed', 'dotted', [10, 4, 2, 4], [2, 6]];
    var LINE_NAMES = ['實線', '虛線', '點線', '點劃線', '稀點線'];
    var DECALS = [
        null,
        { symbol: 'rect', symbolSize: 1, dashArrayX: [1, 0], dashArrayY: [2, 4], rotation: Math.PI / 4, color: 'rgba(0,0,0,0.5)' },
        { symbol: 'circle', symbolSize: 0.6, dashArrayX: [[4, 4]], dashArrayY: [4, 0], color: 'rgba(0,0,0,0.5)' },
        { symbol: 'rect', symbolSize: 1, dashArrayX: [1, 0], dashArrayY: [2, 4], rotation: -Math.PI / 4, color: 'rgba(0,0,0,0.5)' },
        { symbol: 'rect', symbolSize: 1, dashArrayX: [1, 0], dashArrayY: [1, 3], rotation: 0, color: 'rgba(0,0,0,0.5)' }
    ];
    var INK = '#00ff41';       // 主要文字
    var INK_DIM = '#00b82e';   // 次要文字
    var GRID = '#0a2a12';      // 格線
    var AXIS = '#00661a';      // 軸線
    var NEUTRAL = '#7dffb0';   // 圖例中代表「參數」的中性色
    var BAND = 'rgba(0, 255, 65, 0.05)';  // TBT 交錯底色
    var FONT = '"Share Tech Mono", Consolas, "Courier New", "Microsoft JhengHei", monospace';

    var COLOR = {};
    (function assignColors() {
        var counter = {};
        $.each(CFG.tools, function (i, tool) {
            var model = CFG.models[tool] || '';
            counter[model] = counter[model] || 0;
            COLOR[tool] = PALETTE[counter[model] % PALETTE.length];
            counter[model]++;
        });
    })();

    var GROUPS = {};
    $.each(CFG.groups, function (i, g) { GROUPS[g.id] = g; });

    function colorOf(tool) { return COLOR[tool] || NEUTRAL; }
    function lineTypeOf(i) { return LINE_TYPES[i % LINE_TYPES.length]; }
    function decalOf(i) { return DECALS[i % DECALS.length]; }
    function shortName(param, group) {

        var prefix = group.title + '_';
        return param.indexOf(prefix) === 0 && param.length > prefix.length ? param.substring(prefix.length) : param;
    }

    function baseOption() {

                borderColor: INK_DIM,
                borderWidth: 1,
                textStyle: { color: INK, fontFamily: FONT, fontSize: 13 },

    // ---------- 3. TBT ----------
    // X 軸為類別軸：每台機台佔一段，段內依時間排列。每台每個參數一條 series，
    // 同一台的 series 用同一個名稱，所以圖例以機台為單位開關；其他段落填 null，
    // 所以每台只畫在自己的區段，相鄰機台以交錯底色分隔。
    function drawTbt(box, data) {
        var group = box.group;
        var keys = [];      // 類別值（唯一）："APAN01|2026-01-01"
        var segments = [];  // { tool, from, to }
        $.each(data, function (tool, s) {
            var from = keys.length;
            for (var i = 0; i < s.Date.length; i++) {
                keys.push(tool + '|' + s.Date[i]);
            }
            segments.push({ tool: tool, from: from, to: keys.length - 1 });
        });

        var centers = {};
        var bands = [];
        $.each(segments, function (i, seg) {
            centers[Math.floor((seg.from + seg.to) / 2)] = seg.tool;
            if (i % 2 === 1) {
                bands.push([{ xAxis: keys[seg.from] }, { xAxis: keys[seg.to] }]);
            }
        });

        var series = [];
        var legend = [];
        var paramOf = [];   // seriesIndex → 參數名稱（tooltip 用）
        $.each(segments, function (i, seg) {
            var s = data[seg.tool];
            legend.push(seg.tool);
            $.each(group.params, function (pi, param) {
                var col = s.Data[param] || [];
                var arr = new Array(keys.length);
                for (var k = 0; k < keys.length; k++) {
                    arr[k] = null;
                }
                for (var j = 0; j < s.Date.length; j++) {
                    arr[seg.from + j] = col[j] === undefined ? null : col[j];
                }
                paramOf.push(param);
                series.push({
                    name: seg.tool,
                    type: 'line',
                    data: arr,
                    connectNulls: false,
                    showSymbol: false,
                    symbolSize: 8,
                    color: colorOf(seg.tool),
                    lineStyle: { width: 2, type: lineTypeOf(pi) },
                    emphasis: { focus: 'series' }
                });
            });
        });
        // 交錯底色放在一條不顯示的輔助 series 上
        series.push({
            name: '_bands',
            type: 'line',
            data: [],
            silent: true,
            markArea: { silent: true, itemStyle: { color: BAND }, data: bands }
        });

        var opt = baseOption();
        opt.grid.top = 64;
        opt.grid.bottom = 70;
        opt.legend = legendBase(legend);
        opt.tooltip.trigger = 'axis';
        opt.tooltip.axisPointer = { type: 'line', lineStyle: { color: INK_DIM, type: 'dashed' } };
        opt.tooltip.formatter = function (params) {
            var html = '';
            $.each(params, function (i, p) {
                if (p.seriesName === '_bands' || p.value === null || p.value === undefined) {
                    return;
                }
                if (!html) {
                    html = p.marker + AISLE.escape(p.seriesName) + '<br>' + AISLE.escape(String(p.name).split('|')[1]);
                }
                html += '<br>' + AISLE.escape(paramOf[p.seriesIndex]) + '：<b>' + fmt(p.value) + '</b>';
            });
            return html;
        };
        opt.xAxis = {
            type: 'category',
            data: keys,
            boundaryGap: false,
            axisLine: axisLine(),
            axisTick: { show: false },
            axisLabel: {
                color: INK,
                interval: function (idx) { return centers.hasOwnProperty(idx); },
                formatter: function (v) { return String(v).split('|')[0]; }
            },
            splitLine: { show: false }
        };
        opt.yAxis = valueAxis(group, 'tbt');
        opt.dataZoom = [
            { type: 'inside' },
            {
                type: 'slider', height: 18, bottom: 12,
                borderColor: AXIS, fillerColor: 'rgba(0,255,65,0.12)',
                handleStyle: { color: INK_DIM }, moveHandleStyle: { color: INK_DIM },
                dataBackground: { lineStyle: { color: AXIS }, areaStyle: { color: 'rgba(0,255,65,0.08)' } },
                textStyle: { color: INK_DIM },
                labelFormatter: function (i, v) { return String(v).replace('|', ' '); }
            }

        box.chart.clear();

    function showNewest() {

                $.each(box.group.params, function (pi, p) {

                    latest.Data[p] = [null];
                    for (var i = col.length - 1; i >= 0; i--) {
                        if (col[i] !== null && col[i] !== undefined) {
                            latest.Date[p] = [s.Date[i]];
                            latest.Data[p] = [col[i]];
                            any = true;
                            break;
                        }
                    }
                });
                if (any) {
                    data[tool] = latest;
                }
            });
            show(box, data, drawNewest);
        });
    }

    function range() {
        var start = $.trim($('#cd-start').val());
        var end = $.trim($('#cd-end').val());
        var $msg = $('#cd-msg').text('');
        if (!isDate(start) || !isDate(end)) {
            $msg.text('> 日期格式需為 YYYY-MM-DD');
            return null;
        }
        if (start > end) {
            $msg.text('> 起始日期不可晚於結束日期');
            return null;
        }
        return { start: start, end: end };
    }

    /** 取日期區間內全部機台、全部參數的資料（所有圖共用），進頁面與改日期時呼叫 */
    function loadRange() {
        var r = range();
        if (!r) {
            return;
        }
        if (request) {
            request.abort();
        }
        eachBox(null, function (box) { box.chart.showLoading('default', loadingOpts()); });
        request = $.ajax({ url: CFG.urls.tbt, data: { start: r.start, end: r.end }, dataType: 'json', cache: false })
            .done(function (res) {
                cache.tbt = res || {};
                eachBox(null, function (box) { box.chart.hideLoading(); });
                showTbt();
                showSingle();
                showNewest();
            })
            .fail(function (xhr, status) {
                if (status === 'abort') {
                    return;
                }
                var msg = (xhr.responseJSON && xhr.responseJSON.error) || ('HTTP ' + xhr.status);
                eachBox(null, function (box) {
                    box.chart.hideLoading();
                    showMessage(box.chart, '> ERROR: ' + msg);
                });
            });
    }

        // 點最新值長條 → 切換單台機台

            box.chart.on('click', function (p) {

            resizeTimer = setTimeout(function () {
                eachBox(null, function (box) { box.chart.resize(); });
            }, 150);
        });

        loadRange();
    });

    return attrs


def check_path(path, lineno):
    bad = (not path or path.startswith('/') or '\\' in path or '\0' in path
           or ':' in path.split('/')[0])
    parts = path.split('/')
    if bad or '..' in parts or '.' in parts or '' in parts or parts[0] == '.git':
        raise UpdateError('第 %d 行：不允許的路徑 "%s"' % (lineno, path))
    return path


def build_content(entry, lines):
    """把更新檔內的區塊還原成要寫入的 bytes，並驗證 sha1"""
    enc = entry['enc']
    if enc == 'base64':
        try:
            data = base64.b64decode(''.join(l.strip() for l in lines))
        except (TypeError, binascii.Error):
            raise UpdateError('%s：base64 內容損毀（第 %d 行起）' % (entry['path'], entry['lineno']))
    elif enc == 'text':
        if lines:
            data = '\n'.join(lines) + '\n'
            if entry['nl'] == '0':
                data = data[:-1]
        else:
            data = ''
        if entry['eol'] == 'crlf':
            data = data.replace('\n', '\r\n')
    else:
        raise UpdateError('%s：不支援的 enc=%s' % (entry['path'], enc))

    actual = sha1_of(data)
    if actual != entry['sha1']:
        raise UpdateError(
            '%s 的內容和 sha1 不符（第 %d 行起，%d 行）。\n'
            '    通常是複製時漏了內容、多了內容，或編輯器自動改了縮排；請重新複製整個更新檔。\n'
            '    預期 %s\n    實際 %s' % (entry['path'], entry['lineno'], len(lines), entry['sha1'], actual))
    return data


def parse_update(path):
    fp = open(path, 'rb')
    try:
        raw = fp.read()
    finally:
        fp.close()
    if raw.startswith('\xef\xbb\xbf'):          # 有些編輯器會加 UTF-8 BOM
        raw = raw[3:]
    raw = raw.replace('\r\n', '\n')             # 從 Windows 瀏覽器複製可能變成 CRLF
    lines = raw.split('\n')

    meta = {}
    entries = []
    current = None
    block = []
    ended = False
    seen_header = False
    seen_paths = set()

    def finish():
        if current is not None and current['op'] == 'file':
            current['data'] = build_content(current, block)

    for idx, line in enumerate(lines):
        lineno = idx + 1
        if not seen_header:
            if line.strip() == '':
                continue
            if line.rstrip() != FORMAT_HEADER:
                raise UpdateError('第 %d 行：不是 AISLE 更新檔（第一行應為 "%s"）' % (lineno, FORMAT_HEADER))
            seen_header = True
            continue
        if ended:
            if line.strip():
                raise UpdateError('第 %d 行：END 之後還有內容，可能貼了兩次' % lineno)
            continue

        if line.startswith(MARK):
            finish()
            block = []
            current = None
            parts = line[len(MARK):].strip().split(None, 2)
            if not parts:
                raise UpdateError('第 %d 行：空的標記行' % lineno)
            kind = parts[0]
            if kind == 'END':
                attrs = parse_attrs(' '.join(parts[1:]), lineno)
                if 'count' in attrs and attrs['count'] != str(len(entries)):
                    raise UpdateError('更新檔應有 %s 個項目，實際讀到 %d 個，可能沒有複製完整'
                                      % (attrs['count'], len(entries)))
                ended = True
                continue
            if kind not in ('FILE', 'DELETE') or len(parts) < 2:
                raise UpdateError('第 %d 行：無法解析的標記 "%s"' % (lineno, line.strip()))
            fpath = check_path(parts[1], lineno)
            if fpath in seen_paths:
                raise UpdateError('第 %d 行：%s 出現兩次' % (lineno, fpath))
            seen_paths.add(fpath)
            attrs = parse_attrs(parts[2] if len(parts) > 2 else '', lineno)
            base = attrs.get('base')
            if base is not None and base != NO_FILE and not RE_SHA1.match(base):
                raise UpdateError('第 %d 行：base 格式錯誤' % lineno)
            current = {'op': kind.lower(), 'path': fpath, 'base': base, 'lineno': lineno + 1}
            if kind == 'FILE':
                if not RE_SHA1.match(attrs.get('sha1', '')):
                    raise UpdateError('第 %d 行：缺少 sha1' % lineno)
                current.update({
                    'sha1': attrs['sha1'],
                    'enc': attrs.get('enc', 'text'),
                    'nl': attrs.get('nl', '1'),
                    'eol': attrs.get('eol', 'lf'),
                    'mode': attrs.get('mode', ''),
                })
            entries.append(current)
            continue

        if current is None:
            if line.startswith('#@ '):           # 更新檔資訊：#@ key=value
                k, _, v = line[3:].partition('=')
                meta[k.strip()] = v.strip()
            elif line.strip() and not line.startswith('#'):
                raise UpdateError('第 %d 行：檔案區塊外出現內容' % lineno)
            continue
        if current['op'] == 'delete':
            if line.strip():
                raise UpdateError('第 %d 行：DELETE 後面不應有內容' % lineno)
            continue
        block.append(line)

    if not seen_header:
        raise UpdateError('更新檔是空的')
    if not ended:
        raise UpdateError('找不到結尾的 "%sEND"，更新檔沒有複製完整' % MARK)
    return meta, entries

def make_plan(root, entries):
    """比對主機上的現況，決定每個檔案的動作。回傳 (plan, conflicts)"""
    plan = []
    conflicts = []
    for e in entries:
        full = os.path.join(root, e['path'])
        if os.path.islink(full) or (os.path.lexists(full) and not os.path.isfile(full)):
            raise UpdateError('%s 在主機上是目錄或連結，無法處理' % e['path'])
        current = file_sha1(full)
        base = e['base']
        item = {'entry': e, 'path': e['path'], 'full': full, 'current': current, 'note': ''}

        if e['op'] == 'file':
            if current == e['sha1']:
                item['action'] = 'same'
            elif current is None:
                item['action'] = 'create'
                if base not in (None, NO_FILE):
                    item['note'] = '主機上沒有這個檔案（預期應該存在）'
            else:
                item['action'] = 'overwrite'
                if base == NO_FILE:
                    item['note'] = '主機上已經有這個檔案（預期是新檔）'
                elif base is not None and current != base:
                    item['note'] = '主機上的檔案和更新前的版本不同（可能被直接改過）'
        else:
            if current is None:
                item['action'] = 'gone'
            else:
                item['action'] = 'delete'
                if base not in (None, NO_FILE) and current != base:
                    item['note'] = '主機上的檔案和更新前的版本不同（可能被直接改過）'
        if item['note']:
            conflicts.append(item)
        plan.append(item)
    return plan, conflicts


LABELS = {
    'create': '[新增]',
    'overwrite': '[覆蓋]',
    'delete': '[刪除]',
    'same': '[相同]',
    'gone': '[已無]',
}


def print_plan(plan, stamp):
    counts = {}
    for item in plan:
        a = item['action']
        counts[a] = counts.get(a, 0) + 1
        line = '  %s %s' % (LABELS[a], item['path'])
        if a in ('overwrite', 'delete'):
            line += '    → 備份 %s_%s' % (item['path'], stamp)
        if a == 'same':
            line += '    (內容相同，略過)'
        if a == 'gone':
            line += '    (主機上已經沒有，略過)'
        out(line)
        if item['note']:
            out('      ! 衝突：%s' % item['note'])
    out()
    out('  新增 %d、覆蓋 %d、刪除 %d、相同 %d' % (
        counts.get('create', 0), counts.get('overwrite', 0),
        counts.get('delete', 0), counts.get('same', 0) + counts.get('gone', 0)))

def is_root_user():
    return hasattr(os, 'geteuid') and os.geteuid() == 0


def copy_owner(path, ref_stat):
    if is_root_user():
        try:
            os.chown(path, ref_stat.st_uid, ref_stat.st_gid)
        except OSError:
            pass


def make_dirs(root, rel_dir, created_dirs):
    """逐層建立目錄，擁有者跟上一層相同；記下新建的目錄以便還原"""
    parent = root
    for part in rel_dir.split('/'):
        if not part:
            continue
        path = os.path.join(parent, part)
        if not os.path.isdir(path):
            os.mkdir(path, 0o755)
            copy_owner(path, os.stat(parent))
            created_dirs.append(os.path.relpath(path, root).replace(os.sep, '/'))
        parent = path


def write_file(full, data, ref_stat, mode):
    tmp = os.path.join(os.path.dirname(full), '.%s.aisle-tmp' % os.path.basename(full))
    try:
        fp = open(tmp, 'wb')
        try:
            fp.write(data)
        finally:
            fp.close()
        if ref_stat is not None:
            perm = ref_stat.st_mode & 0o7777
            if mode == '755':
                perm |= 0o111
            os.chmod(tmp, perm)
            copy_owner(tmp, ref_stat)
        else:
            os.chmod(tmp, 0o755 if mode == '755' else 0o644)
            copy_owner(tmp, os.stat(os.path.dirname(full)))
        os.rename(tmp, full)
    except (OSError, IOError):
        if os.path.exists(tmp):
            os.remove(tmp)
        raise


def log_path(root, stamp):
    return os.path.join(root, LOG_DIR, 'update_%s.json' % stamp)


def save_log(root, record):
    d = os.path.join(root, LOG_DIR)
    if not os.path.isdir(d):
        os.makedirs(d)
    fp = open(log_path(root, record['stamp']), 'wb')
    try:
        fp.write(json.dumps(record, indent=2, sort_keys=True, separators=(',', ': ')))
    finally:
        fp.close()


def undo(root, done):
    """把已完成的動作倒著還原（套用中途失敗時使用）"""
    for act in reversed(done):
        full = os.path.join(root, act['path'])
        try:
            if act['op'] == 'create':
                if os.path.exists(full):
                    os.remove(full)
            elif act['op'] in ('overwrite', 'delete'):
                backup = os.path.join(root, act['backup'])
                if os.path.exists(backup):
                    os.rename(backup, full)
            elif act['op'] == 'mkdir':
                os.rmdir(full)
        except OSError as ex:
            out('  ! 還原 %s 失敗：%s' % (act['path'], ex))


def apply_plan(root, plan, stamp, update_file, meta):
    record = {
        'stamp': stamp,
        'update_file': os.path.abspath(update_file),
        'from': meta.get('from', ''),
        'to': meta.get('to', ''),
        'applied_at': time.strftime('%Y-%m-%d %H:%M:%S'),
        'status': 'applying',
        'actions': [],
    }
    done = record['actions']
    try:
        for item in plan:
            e = item['entry']
            a = item['action']
            full = item['full']
            rel_backup = '%s_%s' % (e['path'], stamp)
            backup = os.path.join(root, rel_backup)
            if a == 'create':
                created_dirs = []
                rel_dir = os.path.dirname(e['path'])
                if rel_dir:
                    make_dirs(root, rel_dir, created_dirs)
                for d in created_dirs:
                    done.append({'op': 'mkdir', 'path': d})
                write_file(full, e['data'], None, e['mode'])
                done.append({'op': 'create', 'path': e['path'], 'sha1': e['sha1']})
            elif a == 'overwrite':
                st = os.stat(full)
                shutil.copy2(full, backup)
                copy_owner(backup, st)
                done.append({'op': 'overwrite', 'path': e['path'], 'backup': rel_backup,
                             'sha1': e['sha1'], 'old_sha1': item['current']})
                write_file(full, e['data'], st, e['mode'])
            elif a == 'delete':
                os.rename(full, backup)
                done.append({'op': 'delete', 'path': e['path'], 'backup': rel_backup,
                             'old_sha1': item['current']})
            else:
                continue
            out('  %s %s' % (LABELS[a], e['path']))
    except (OSError, IOError) as ex:
        out()
        out('[ERROR] 寫入 %s 時失敗：%s' % (item['path'], ex))
        out('        正在還原已經改過的檔案...')
        undo(root, done)
        record['status'] = 'failed'
        try:
            save_log(root, record)
        except (OSError, IOError):
            pass
        out('        已還原。請確認目錄權限（例：用 sudo 執行）後再試一次。')
        return False
    record['status'] = 'applied'
    save_log(root, record)
    return True

def to_str(value):
    """json.loads 在 Python 2 回傳 unicode，轉回 UTF-8 str，避免和中文訊息字串混用時出錯"""
    if isinstance(value, dict):
        return dict((to_str(k), to_str(v)) for k, v in value.items())
    if isinstance(value, list):
        return [to_str(v) for v in value]
    if sys.version_info[0] == 2 and isinstance(value, unicode):  # noqa: F821
        return value.encode('utf-8')
    return value


def load_logs(root):
    d = os.path.join(root, LOG_DIR)
    logs = []
    if os.path.isdir(d):
        for name in sorted(os.listdir(d)):
            m = re.match(r'^update_(\d{8}_\d{6})\.json$', name)
            if not m:
                continue
            try:
                fp = open(os.path.join(d, name), 'rb')
                try:
                    logs.append(to_str(json.loads(fp.read())))
                finally:
                    fp.close()
            except (IOError, ValueError):
                out('  ! 無法讀取 %s' % name)
    return logs


def cmd_list(root):
    logs = load_logs(root)
    if not logs:
        out('沒有更新紀錄（%s）' % os.path.join(root, LOG_DIR))
        return 0
    status_text = {'applied': '已套用', 'rolled_back': '已還原', 'failed': '失敗已還原', 'applying': '中斷'}
    for r in logs:
        n = len([a for a in r['actions'] if a['op'] != 'mkdir'])
        out('  %s  %s  %3d 個檔案  版本 %s → %s  %s' % (
            r['stamp'], status_text.get(r['status'], r['status']), n,
            (r.get('from') or '?')[:7], (r.get('to') or '?')[:7], os.path.basename(r['update_file'])))
    return 0


def cmd_rollback(root, stamp, do_apply, force):
    logs = load_logs(root)
    if stamp == 'last':
        applied = [r for r in logs if r['status'] == 'applied']
        if not applied:
            out('[ERROR] 沒有可以還原的更新')
            return 1
        record = applied[-1]
    else:
        if not RE_STAMP.match(stamp):
            out('[ERROR] 時間格式應為 YYYYMMDD_HHMMSS，例 20261104_204500')
            return 2
        found = [r for r in logs if r['stamp'] == stamp]
        if not found:
            out('[ERROR] 找不到 %s 的更新紀錄，可用 --list 查看' % stamp)
            return 1
        record = found[0]
    if record['status'] != 'applied':
        out('[ERROR] %s 的狀態是 %s，不能還原' % (record['stamp'], record['status']))
        return 1

    out('還原 %s 的更新（%s）' % (record['stamp'], os.path.basename(record['update_file'])))
    out()
    problems = 0
    for act in reversed(record['actions']):
        full = os.path.join(root, act['path'])
        note = ''
        if act['op'] == 'create':
            line = '  [移除] %s' % act['path']
            if file_sha1(full) not in (act['sha1'], None):
                note = '更新後又被改過，移除會遺失這些修改'
        elif act['op'] == 'overwrite':
            line = '  [還原] %s  ← %s' % (act['path'], os.path.basename(act['backup']))
            if not os.path.isfile(os.path.join(root, act['backup'])):
                out(line)
                out('      ! 找不到備份檔，無法還原')
                problems += 1
                continue
            if file_sha1(full) not in (act['sha1'], None):
                note = '更新後又被改過，還原會遺失這些修改'
        elif act['op'] == 'delete':
            line = '  [放回] %s  ← %s' % (act['path'], os.path.basename(act['backup']))
            if not os.path.isfile(os.path.join(root, act['backup'])):
                out(line)
                out('      ! 找不到備份檔，無法還原')
                problems += 1
                continue
            if os.path.exists(full):
                note = '原位置已經有新的檔案，會被覆蓋'
        else:
            continue
        out(line)
        if note:
            out('      ! 衝突：%s' % note)
            problems += 1
    out()
    if problems and not force:
        out('[ERROR] 有 %d 個問題。確認可以覆蓋後加上 --force' % problems)
        return 1
    if not do_apply:
        out('這是預覽，沒有改動任何檔案。確認無誤後加上 --apply 執行還原。')
        return 0

    for act in reversed(record['actions']):
        full = os.path.join(root, act['path'])
        try:
            if act['op'] == 'create':
                if os.path.exists(full):
                    os.remove(full)
            elif act['op'] in ('overwrite', 'delete'):
                backup = os.path.join(root, act['backup'])
                if os.path.isfile(backup):
                    os.rename(backup, full)
            elif act['op'] == 'mkdir':
                if os.path.isdir(full) and not os.listdir(full):
                    os.rmdir(full)
        except OSError as ex:
            out('[ERROR] %s：%s' % (act['path'], ex))
            return 1
    record['status'] = 'rolled_back'
    record['rolled_back_at'] = time.strftime('%Y-%m-%d %H:%M:%S')
    save_log(root, record)
    out('[OK] 已還原 %s 的更新，備份檔已改回原檔名' % record['stamp'])
    return 0

def find_root(opt_root):
    def ok(d):
        return os.path.isfile(os.path.join(d, 'core', 'bootstrap.php'))
    if opt_root:
        if not ok(opt_root):
            raise UpdateError('%s 不是 AISLE 根目錄（找不到 core/bootstrap.php）' % opt_root)
        return os.path.abspath(opt_root)
    here = os.path.dirname(os.path.abspath(__file__))
    for d in (os.path.join(here, '..', '..'), os.getcwd()):
        if ok(d):
            return os.path.abspath(d)
    raise UpdateError('找不到 AISLE 根目錄，請用 --root 指定，例 --root /var/www/html/aisle')


def usage():
    out(__doc__.strip())
    return 2


def main(argv):
    args = list(argv)
    opts = {'apply': False, 'force': False, 'list': False, 'root': None, 'rollback': None}
    files = []
    while args:
        a = args.pop(0)
        if a in ('-h', '--help'):
            return usage()
        elif a == '--apply':
            opts['apply'] = True
        elif a == '--force':
            opts['force'] = True
        elif a == '--list':
            opts['list'] = True
        elif a in ('--root', '--rollback'):
            if not args:
                out('[ERROR] %s 後面要接參數' % a)
                return 2
            opts[a[2:]] = args.pop(0)
        elif a.startswith('-'):
            out('[ERROR] 不認得的選項 %s（-h 看用法）' % a)
            return 2
        else:
            files.append(a)

    try:
        root = find_root(opts['root'])
        if opts['list']:
            return cmd_list(root)
        if opts['rollback']:
            return cmd_rollback(root, opts['rollback'], opts['apply'], opts['force'])
        if len(files) != 1:
            return usage()
        update_file = files[0]
        if not os.path.isfile(update_file):
            out('[ERROR] 找不到更新檔 %s' % update_file)
            return 1

        meta, entries = parse_update(update_file)
        out('更新檔：%s' % update_file)
        if meta.get('from') or meta.get('to'):
            out('版本　：%s → %s' % (meta.get('from', '?')[:7] or '?', meta.get('to', '?')[:7]))
        if meta.get('note'):
            out('說明　：%s' % meta['note'])
        out('目錄　：%s' % root)
        out('驗證　：%d 個項目的 sha1 都正確' % len(entries))
        out()

        stamp = time.strftime(STAMP_FORMAT)
        plan, conflicts = make_plan(root, entries)
        for item in plan:
            if item['action'] in ('overwrite', 'delete') and os.path.lexists(
                    os.path.join(root, '%s_%s' % (item['path'], stamp))):
                raise UpdateError('備份檔 %s_%s 已經存在，請稍等一秒再執行' % (item['path'], stamp))
        print_plan(plan, stamp)
        out()

        if conflicts and not opts['force']:
            out('[ERROR] 有 %d 個衝突：主機上的檔案不是更新檔預期的版本。' % len(conflicts))
            out('        確認可以覆蓋（會先備份）後加上 --force。')
            return 1
        changes = [p for p in plan if p['action'] in ('create', 'overwrite', 'delete')]
        if not changes:
            out('[OK] 所有檔案都已經是最新的，不需要更新')
            return 0
        if not opts['apply']:
            out('這是預覽，沒有改動任何檔案。確認無誤後加上 --apply 執行。')
            return 0

        out('開始套用（備份時間 %s）' % stamp)
        if not apply_plan(root, plan, stamp, update_file, meta):
            return 1
        out()
        out('[OK] 已更新 %d 個檔案，紀錄：%s' % (len(changes), log_path(root, stamp)))
        out('     要還原這次更新：python %s --rollback %s' % (sys.argv[0], stamp))
        return 0
    except UpdateError as ex:
        out('[ERROR] %s' % ex)
        out('        沒有改動任何檔案。')
        return 1


if __name__ == '__main__':
    sys.exit(main(sys.argv[1:]))

def fetch_series(tools, params, start, end):
    # TODO(部署者)：回傳 {tool: {"Date": [...], "Data": {param: [...]}}}，含 start 與 end 兩天
    out = {}
    for tool in tools:
        out[tool] = {'Date': [], 'Data': dict((p, []) for p in params)}
    day = start
    while day <= end:
        for tool in tools:
            if sample_down(tool, day):
                continue
            out[tool]['Date'].append(day.strftime('%Y-%m-%d'))
            for p in params:
                out[tool]['Data'][p].append(sample_value(tool, p, day))
        day += datetime.timedelta(days=1)
    return out


def pivot(rows):
    """(tool, date, param, value) 的資料列整理成輸出格式；同一台同一時間的參數合併，缺的補 None"""
    tmp = {}
    names = {}
    for tool, date, param, value in rows:
        tmp.setdefault(tool, {}).setdefault(str(date), {})[param] = None if value is None else float(value)
        names.setdefault(tool, set()).add(param)
    out = {}
    for tool, by_date in tmp.items():
        dates = sorted(by_date)
        out[tool] = {
            'Date': dates,
            'Data': dict((p, [by_date[d].get(p) for d in dates]) for p in names[tool]),
        }
    return out

def crc(s):
    return zlib.crc32(s.encode('utf-8')) & 0xffffffff


def sample_down(tool, day):
    """約 1/9 的日子整台沒有資料（模擬停機）"""
    return crc('%s|%s' % (tool, day.strftime('%Y-%m-%d'))) % 9 == 0


def sample_value(tool, param, day):
    h = crc('%s|%s|%s' % (tool, param, day.strftime('%Y-%m-%d')))
    seed = crc(tool)
    # 同一台的參數走勢相近，各參數再加一點固定偏移
    base = 1.2 + (seed % 300) / 100.0 + (crc(param) % 60) / 100.0 - 0.3
    n = (day - datetime.date(1970, 1, 1)).days
    wave = 0.6 * math.sin(float(n) / (5 + seed % 7) + seed % 10)
    noise = ((h % 1000) / 1000.0 - 0.5) * 0.5
    return round(max(0.0, base + wave + noise), 3)

#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
產生 AISLE 單檔更新（在有 git 的電腦上執行，Python 2.7 / 3 都可以）

把兩個版本之間的差異（新增、修改、刪除的檔案）打包成一個純文字檔，
主機上用 scripts/python/apply_update.py 套用。

用法：
  python scripts/python/make_update.py <舊版本> [<新版本>] [選項]
      <舊版本>  主機目前的版本（commit、branch 或 tag），例 7d8729a
      <新版本>  要更新到的版本，預設 HEAD

  python scripts/python/make_update.py --all [<版本>]
      打包該版本的所有檔案（主機版本不明、或第一次安裝時使用），不檢查主機上的舊版本

選項：
  -o <檔案>          輸出位置，預設 updates/update_<日期>_<舊>_<新>.txt
  --note "<說明>"    寫進更新檔的說明，套用時會顯示
  --exclude <路徑>   不打包的路徑前綴，可重複；預設排除 updates/ 與 docs/screenshots/
  --no-base          不記錄舊版本的 sha1（主機不檢查衝突）

範例：
  python scripts/python/make_update.py 7d8729a HEAD --note "新增單檔更新工具"
"""
from __future__ import print_function

import base64
import hashlib
import os
import subprocess
import sys
import time

FORMAT_HEADER = b'#AISLE-UPDATE v1'
MARK = b'#@@@ '
DEFAULT_EXCLUDES = ['updates/', 'docs/screenshots/']


PY2 = sys.version_info[0] == 2


def native(b):
    """git 輸出的 bytes 轉成本版本 Python 的 str（Python 2 本來就是 bytes）"""
    return b if PY2 else b.decode('utf-8')


def to_bytes(s):
    return s if isinstance(s, bytes) else s.encode('utf-8')


def die(msg):
    print('[ERROR] %s' % msg)
    sys.exit(1)


def git(*args):
    p = subprocess.Popen(('git',) + args, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    out, err = p.communicate()
    if p.returncode != 0:
        die('git %s 失敗：%s' % (' '.join(args), (err if PY2 else err.decode('utf-8', 'replace')).strip()))
    return out


def rev(ref):
    return native(git('rev-parse', '--verify', ref + '^{commit}')).strip()


def blob(commit, path):
    return git('show', '%s:%s' % (commit, path))


def file_mode(commit, path):
    out = native(git('ls-tree', commit, '--', path))
    return '755' if out.startswith('100755') else '644'


def encode_entry(path, data, base, mode):
    """回傳一個 FILE 區塊（bytes）"""
    sha1 = hashlib.sha1(data).hexdigest()
    attrs = ['sha1=' + sha1]
    if base is not None:
        attrs.append('base=' + base)
    attrs.append('mode=' + mode)
    is_text = b'\0' not in data
    if is_text:
        try:
            data.decode('utf-8')
        except UnicodeDecodeError:
            is_text = False
    eol = 'lf'
    body = data
    if is_text and b'\r' in data:
        # 整個檔案都是 CRLF 時轉成 LF 存放、套用時還原；混用或有單獨的 \r 就改用 base64
        if b'\r' not in data.replace(b'\r\n', b'') and data.count(b'\n') == data.count(b'\r\n'):
            eol = 'crlf'
            body = data.replace(b'\r\n', b'\n')
        else:
            is_text = False
    if is_text and any(line.startswith(MARK) for line in body.split(b'\n')):
        is_text = False          # 內容剛好有標記行，改用 base64 避免誤判

    if is_text:
        nl = '1'
        if body and not body.endswith(b'\n'):
            nl = '0'
            body += b'\n'
        attrs += ['enc=text', 'nl=' + nl]
        if eol == 'crlf':
            attrs.append('eol=crlf')
    else:
        b64 = base64.b64encode(data)
        body = b''.join(b64[i:i + 76] + b'\n' for i in range(0, len(b64), 76))
        attrs.append('enc=base64')
    head = MARK + b'FILE ' + to_bytes(path) + b' ' + ' '.join(attrs).encode('ascii') + b'\n'
    return head + body


def excluded(path, excludes):
    return any(path == e.rstrip('/') or path.startswith(e) for e in excludes)


def main(argv):
    args = list(argv)
    refs = []
    out_path = None
    note = ''
    excludes = []
    use_base = True
    full = False
    while args:
        a = args.pop(0)
        if a in ('-h', '--help'):
            print(__doc__.strip())
            return 0
        elif a in ('-o', '--note', '--exclude'):
            if not args:
                die('%s 後面要接參數' % a)
            v = args.pop(0)
            if a == '-o':
                out_path = v
            elif a == '--note':
                note = v
            else:
                excludes.append(v)
        elif a == '--no-base':
            use_base = False
        elif a == '--all':
            full = True
        elif a.startswith('-'):
            die('不認得的選項 %s（-h 看用法）' % a)
        else:
            refs.append(a)
    excludes = excludes or DEFAULT_EXCLUDES

    top = native(git('rev-parse', '--show-toplevel')).strip()
    os.chdir(top)

    if full:
        if len(refs) > 1:
            die('--all 只接一個版本')
        old = None
        new = rev(refs[0] if refs else 'HEAD')
        names = git('ls-tree', '-r', '-z', '--name-only', new).split(b'\0')
        changes = [('A', native(n)) for n in names if n]
        use_base = False
    else:
        if not refs or len(refs) > 2:
            die('要指定主機目前的版本，例：make_update.py 7d8729a HEAD（-h 看用法）')
        old = rev(refs[0])
        new = rev(refs[1] if len(refs) > 1 else 'HEAD')
        raw = git('diff', '--name-status', '--no-renames', '-z', old, new).split(b'\0')
        raw = [r for r in raw if r]
        changes = []
        for i in range(0, len(raw), 2):
            changes.append((native(raw[i])[0], native(raw[i + 1])))

    if git('status', '--porcelain', '--untracked-files=no').strip():
        print('[注意] 工作目錄有尚未 commit 的修改，更新檔只會包含已 commit 的內容')

    entries = []
    skipped = []
    for status, path in sorted(changes, key=lambda c: c[1]):
        if excluded(path, excludes):
            skipped.append(path)
            continue
        if status in ('A', 'M', 'T'):
            base = None
            if use_base:
                base = '-' if status == 'A' else hashlib.sha1(blob(old, path)).hexdigest()
            block = encode_entry(path, blob(new, path), base, file_mode(new, path))
            entries.append((status, path, block))
        elif status == 'D':
            line = MARK + b'DELETE ' + to_bytes(path)
            if use_base:
                line += b' base=' + hashlib.sha1(blob(old, path)).hexdigest().encode('ascii')
            entries.append((status, path, line + b'\n'))
        else:
            die('不支援的變更類型 %s：%s' % (status, path))

    if not entries:
        die('兩個版本之間沒有需要更新的檔案')

    short_old = old[:7] if old else 'all'
    short_new = new[:7]
    if not out_path:
        out_path = os.path.join('updates', 'update_%s_%s_%s.txt' % (time.strftime('%Y%m%d'), short_old, short_new))
    d = os.path.dirname(out_path)
    if d and not os.path.isdir(d):
        os.makedirs(d)

    lines = [FORMAT_HEADER + b'\n']
    lines.append(b'# AISLE single-file update. Apply on the server:\n')
    lines.append(b'#   python scripts/python/apply_update.py <this file>          (preview)\n')
    lines.append(b'#   python scripts/python/apply_update.py <this file> --apply  (apply)\n')
    lines.append(('#@ from=%s\n' % (old or '')).encode('ascii'))
    lines.append(('#@ to=%s\n' % new).encode('ascii'))
    lines.append(('#@ created=%s\n' % time.strftime('%Y-%m-%d %H:%M:%S')).encode('ascii'))
    if note:
        lines.append(b'#@ note=' + to_bytes(note) + b'\n')
    for _, _, block in entries:
        lines.append(block)
    lines.append(MARK + ('END count=%d\n' % len(entries)).encode('ascii'))

    fp = open(out_path, 'wb')
    try:
        fp.write(b''.join(lines))
    finally:
        fp.close()

    label = {'A': '新增', 'M': '修改', 'T': '修改', 'D': '刪除'}
    for status, path, _ in entries:
        print('  [%s] %s' % (label[status], path))
    for path in skipped:
        print('  [略過] %s' % path)
    print()
    print('[OK] %s → %s，%d 個項目，寫入 %s（%d KB）' % (
        short_old, short_new, len(entries), out_path, (os.path.getsize(out_path) + 1023) // 1024))
    return 0


if __name__ == '__main__':
    sys.exit(main(sys.argv[1:]))
