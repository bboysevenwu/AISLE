# AISLE 系統架構

多功能、模組化的內部網頁系統。依「身份」(EE / PE) 決定每位使用者能看到哪些功能頁面，介面採用駭客任務 (The Matrix) 綠色終端機風格。

| 層級 | 技術 | 備註 |
|---|---|---|
| 後端 | PHP 5.4 | 不使用 5.5+ 語法；資料庫一律 PDO prepared statement |
| 資料庫 | MariaDB 5.5 / 10.x | InnoDB、utf8mb4 |
| 輔助腳本 | Python 2.7、Bash | 權限檢查、建帳號、備份、產生模組 |
| 前端 | HTML5、jQuery 1.12.4、原生 Canvas | 不需要 Node / 建置工具 |

## 2. 資料庫

`sql/schema.sql` 建立三張表：

| 資料表 | 用途 |
|---|---|
| `users` | 帳號 `account`、密碼雜湊 `password_hash`、身份 `role`、啟用狀態、失敗次數與鎖定時間、強制改密碼旗標、最後登入時間與 IP |
| `login_logs` | 每次登入嘗試（成功或失敗原因），供稽核與暴力破解追查 |
| `audit_logs` | 模組操作紀錄，例如匯出報表、建立帳號、重設密碼 |

設計重點：

- **`role` 用 VARCHAR 而非 ENUM**：新增身份只要改 `config.ini`，不必 `ALTER TABLE`。
- **`password_hash` 留 255 長度**：目前 bcrypt 固定 60 字元，保留未來更換演算法的空間。
- **`created_at` 用 DATETIME 由程式寫入**：MariaDB 5.5 一張表只能有一個 TIMESTAMP 使用 `CURRENT_TIMESTAMP`，這個位置留給 `updated_at`。
- 有索引的 VARCHAR 欄位長度 ≤ 191，避免舊版 InnoDB 在 utf8mb4 下超過 767 bytes 索引上限。

### 密碼雜湊（PHP 5.4 的做法）

`password_hash()` / `password_verify()` 是 PHP 5.5 才有的函式。`core/password_compat.php` 在函式不存在時補上同名函式：以 `crypt()` 搭配 `$2y$` bcrypt（PHP ≥ 5.3.7 支援），鹽來自 `openssl_random_pseudo_bytes`，驗證時使用常數時間比較。因此程式碼照標準 API 寫 `password_hash($pw, PASSWORD_BCRYPT)`，在 PHP 5.4 與 5.5+ 都能執行，雜湊格式也完全相同；日後升級 PHP 只要刪掉這個檔案，舊密碼不需重設。

## 3. 身份 → 頁面權限與路由（`config/config.ini` + `core/auth_check.php`）

### config.ini

```ini
[roles]
EE    = "EE 工程師"
PE    = "PE 工程師"
ADMIN = "系統管理員"

; ★ 身份 → 可用頁面清單。同一頁面同時列在 EE 與 PE 就是兩者都能看；"*" = 全部
[access]
EE    = "dashboard, shared_report, report_daily, report_weekly, ee_equipment, ee_daily_check, profile"
PE    = "dashboard, shared_report, report_daily, report_weekly, pe_recipe, pe_notice, profile"
ADMIN = "*"

; ★ 選單分類（選用）：可收折，頁面寫 group = "report" 就收在這底下
[group.report]
title = "共用報表 // REPORTS"
order = 20
open  = Off                           ; 預設收起；瀏覽器會記住使用者的展開狀態

; ★ 頁面與路由
[page.shared_report]
title = "Report1 // 綜合報表"
route = "module:shared_report"        ; modules/shared_report/controller.php
group = "report"
order = 1                             ; 分類內的排序
action.export = "PE"                  ; EE、PE 都能看，只有 PE 能匯出

[page.report_daily]
title = "Report2 // 日報"
route = "pages/report_daily.php"
group = "report"
order = 2

[page.ee_daily_check]
title = "每日點檢 // DAILY CHECK"
route = "pages/ee_daily_check.php"    ; 一般 PHP 頁面

[page.pe_notice]
title = "製程公告 // NOTICE"
route = "public/legacy/pe_notice.php" ; 既有的獨立頁面
```

選單分類只影響顯示：權限仍由 `[access]` 決定，某身份在分類裡看不到任何頁面時整個分類不會出現；目前所在頁面的分類一律展開；沒寫 `group` 的頁面照舊單層顯示。

`route` 有三種寫法：

| route | 程式位置 | 網址 | 適合 |
|---|---|---|---|
| `module:<資料夾>` | `modules/<資料夾>/controller.php` | `index.php?m=<代號>&a=<動作>` | 有多個動作、AJAX 的功能 |
| `pages/xxx.php` | `pages/xxx.php` | `index.php?m=<代號>` | 單純頁面，不用寫 Controller，自動套用版面 |
| `public/xxx.php` | `public/xxx.php` | 直接開啟該檔案 | 既有網站的舊頁面，只需在第一行加一行 require |

### auth_check.php：所有頁面共用同一套檢查

```
使用者開啟頁面
  ├─ index.php?m=xxx  →  App 路由 ──────────┐
  └─ public/legacy/xxx.php（第一行 require）─┤
                                             ▼
                              core/auth_check.php
                    1. 未登入           → 導向 login.php（AJAX 回 401）
                    2. 頁面未登記在 config.ini → 403
                    3. 首次登入未改密碼 → 導向個人設定
                    4. 身份不在 [access] 清單、或不符 action.* → 403
                                             ▼
                          通過 → 依 route 載入頁面程式
```

既有頁面接上權限只要在第一行加入（依檔案位置調整 `../`）：

```php
<?php require_once dirname(__FILE__) . '/../../core/auth_check.php';
// 通過檢查後才會執行到這裡；可用 $AUTH_USER、$AUTH_PAGE
```

auth_check.php 用「目前執行的檔案」對照 config.ini 的 route 找出頁面代號，所以頁面本身不用寫自己的代號或身份。檔案若沒登記在 config.ini，即使加了 require 也一律拒絕，避免漏設權限的頁面被看到。獨立頁面送出 POST 時會檢查 CSRF，舊表單請加上 `<?php echo csrf_field(); ?>`；若一時無法修改，可把 `[settings] direct_page_csrf` 設為 `Off`。

權限一律在伺服器端檢查，隱藏選單只是介面效果；直接輸入網址也會得到 403。目前範例的結果：

| 頁面 | EE | PE | ADMIN |
|---|:-:|:-:|:-:|
| 主控台 dashboard | ✓ | ✓ | ✓ |
| 共用報表 › Report1 shared_report | ✓（不可匯出） | ✓ | ✓ |
| 共用報表 › Report2 report_daily、Report3 report_weekly（pages/） | ✓ | ✓ | ✓ |
| 個人設定 profile | ✓ | ✓ | ✓ |
| 設備狀態 ee_equipment | ✓ | | ✓ |
| 每日點檢 ee_daily_check（pages/） | ✓ | | ✓ |
| 製程配方 pe_recipe | | ✓ | ✓ |
| 製程公告 pe_notice（獨立頁面） | | ✓ | ✓ |
| 圖表 › M1BF m1bf（module:charts） | ✓ | ✓ | ✓ |
| 使用者管理 admin_users | | | ✓ |

修改 config.ini 後執行 `python scripts/python/check_config.py`，會列出每個身份可用的頁面，並檢查拼字、route 檔案是否存在、獨立頁面有沒有 require auth_check.php。

## 4. 註冊、登入、登出與權限檢查

### 流程

| 檔案 | 方法 | 行為 |
|---|---|---|
| `public/register.php` | GET | 註冊頁 |
| | GET `?check_account=xxx`（AJAX） | 回傳帳號是否可用 |
| | POST | 驗證 → 依 EE 名單判定身份 → 寫入 `users`，並在 `audit_logs` 記錄身份來源 |
| `public/login.php` | GET / POST | 驗證帳密，成功後 `session_regenerate_id()` 並把使用者與身份寫入 `$_SESSION['user']` |
| `public/logout.php` | POST（或 `?_csrf=`） | 清除 Session 與 Cookie，導回 `login.php?bye=1` |

登入與註冊表單由 `js/auth.js` 以 jQuery 做即時驗證，並用 `$.ajax` 非同步送出，伺服器回 JSON。瀏覽器關閉 JavaScript 時表單照常以一般 POST 送出，伺服器端也會做完整驗證。

### 註冊時的身份判定（`config.ini` 的 `[register]` 與 `[ee_accounts]`）

註冊表單只填帳號、顯示名稱與密碼。身份在註冊當下依 INI 名單判定，直接寫入 `users.role`：

```ini
[register]
enabled          = On
require_approval = Off     ; On = 註冊後需管理員啟用
listed_role      = "EE"    ; 名單上的帳號
unlisted_role    = "PE"    ; 名單外的帳號；設為 "" 則名單外不能註冊

[ee_accounts]              ; EE 正面表列，一行一個帳號，不分大小寫
account[] = "neo"
account[] = "trinity"
```

- 名單只在註冊時讀取。之後增減名單，不會改變已經註冊的人的身份，要調整請直接改資料庫的 `users.role`。
- ADMIN 永遠無法經由註冊取得；`listed_role`、`unlisted_role` 若設成 superuser 角色會被忽略。
- `audit_logs` 會記錄每個帳號的身份來源（`ee_accounts` 或 `unlisted_role`）。
- 改完名單可以執行 `python scripts/python/check_config.py`，它會列出名單內容，並檢查帳號格式與重複。

### 共用權限檢查函式（`core/guard.php`）

```php
require_login();                    // 未登入 → 導向 login.php；AJAX 回 401
require_role('PE');                 // 身份不符 → 403（ADMIN 一律通過）
require_role('EE,PE');              // 多個身份用逗號
if (has_role('EE,PE')) { ... }      // 只判斷、不中止
if (can_access('shared_report', 'export')) { ... }   // 依 [access] 與 [page.xxx] 判斷
echo csrf_field();                  // 表單的 CSRF 隱藏欄位
current_user();  current_role();  is_logged_in();
```

頁面層級的權限由 `auth_check.php` 處理；這些函式用在頁面內更細的判斷，例如只對某身份顯示某個按鈕。

## 5. 新增功能頁面

只需要改 config.ini，核心程式（`core/`）不用動：

1. 放好頁面程式（擇一）：`pages/xxx.php`、`public/xxx.php`（第一行 require auth_check.php），或建立模組
2. 在 `[access]` 把頁面代號加進能使用它的身份
3. 新增 `[page.xxx]`，寫上 `title` 與 `route`
4. （選用）要放進選單分類就加上 `group = "<分類代號>"`；新分類再加一段 `[group.<分類代號>]`

例：新增一個 EE、PE 都能看的聯絡人頁面

```ini
[access]
EE = "dashboard, ..., team_contacts"
PE = "dashboard, ..., team_contacts"

[page.team_contacts]
title = "聯絡人 // CONTACTS"
route = "pages/team_contacts.php"
order = 60
```

需要多個動作或 AJAX 時用模組，腳本會產生程式骨架並自動完成上面第 2、3 步：

```bash
# 產生 modules/ee_alarm/，加入 EE、PE 的 [access] 清單並新增 [page.ee_alarm]
bash scripts/shell/new_module.sh ee_alarm "EE,PE" "警報中心 // ALARMS" 35
```

產生的骨架：

```php
<?php
class EeAlarmController extends Controller
{
    public function indexAction()          // index.php?m=ee_alarm
    {
        $this->render('index', array('message' => '...'));
    }

    public function listAction()           // index.php?m=ee_alarm&a=list
    {
        $rows = Database::fetchAll('SELECT ... WHERE x = ?', array($x));
        $this->json(array('ok' => true, 'rows' => $rows));
    }
}
```

Controller 可用的方法：`render()`、`json()`、`redirect()`、`can('動作')`、`isPost()`、`input()`、`query()`、`flash()`。View 中輸出變數一律用 `e($var)`；要放進 `<script>` 用 `js($var)`。

## 6. 安全機制

- bcrypt 密碼雜湊，提高 `bcrypt_cost` 後使用者下次登入自動升級雜湊
- 連續失敗 5 次鎖定 15 分鐘（`app.ini` 可調），帳號不存在時也執行一次 bcrypt，避免從回應時間猜出帳號
- 登入成功 `session_regenerate_id()`，閒置 30 分鐘自動登出，Cookie 設 HttpOnly
- 所有 POST（含 jQuery AJAX，透過 `X-CSRF-Token` 標頭）都檢查 CSRF token；登出也需要 token，避免被外部連結強制登出
- 註冊無法取得 ADMIN 身份；可開啟 `require_approval` 讓新帳號需管理員啟用，或把 `unlisted_role` 設為空字串只開放名單內帳號註冊
- 首次登入或被管理員重設密碼後強制改密碼
- 所有 SQL 使用 PDO prepared statement，`ATTR_EMULATE_PREPARES = false`

## 7. PHP 5.4 相容規範

可以用：`array()` 與 `[]` 短陣列、closure、`http_response_code()`、`JSON_UNESCAPED_UNICODE`、`session_status()`。

不能用：

| 不能用 | 版本 | 替代寫法 |
|---|---|---|
| `password_hash()` / `password_verify()` | 5.5 | 已由 `core/password_compat.php` 補上，可直接使用 |
| `finally`、`yield`、`::class`、`array_column()`、`empty(函式())` | 5.5 | try/catch、迴圈、字串類別名稱、先存變數 |
| `hash_equals()`、`...$args`、`const` 運算式 | 5.6 | `Security::equals()` |
| `??`、`<=>`、純量 type hint、回傳型別、`random_bytes()` | 7.0 | `array_get()`、`Security::randomBytes()` |
| `?->`、`match`、`fn() =>` | 8.0 | 一般寫法 |

## 10. 圖表（charts）

多張圖表（BSLr、M1BF、CDM、BMMF…）共用同一個模組 `modules/charts`，每張圖表是選單「圖表 // CHARTS」底下的一頁。圖表使用 ECharts 5.4.3（`public/assets/vendor/` 有檔案時用本機的，否則走 jsDelivr CDN）。

每張圖表只由兩個同名檔案定義，新增圖表不需要改任何程式：

| 檔案 | 內容 |
|---|---|
| `charts/<名稱>.ini` | 畫什麼、怎麼畫：`[page]` 整頁設定、`[plot.<代號>]` 每組圖 |
| `charts/<名稱>.php` | 部署者寫 SQL，整理成資料格式（`class <名稱>Chart extends ChartSource`） |
| `config/config.ini` | `[page.<小寫名稱>]`，`route = "module:charts"`、`group = "charts"`；哪些身份看得到寫在 `[access]` |

頁面代號 = 圖表名稱轉小寫：`[page.bslr]` → `charts/BSLr.ini`、`charts/BSLr.php`，網址 `index.php?m=bslr`。

| 區塊 | 內容 |
|---|---|
| 全域選擇器 | 起訖日期（快捷按鈕由 `quick_days` 設定）、單台機台 |
| single 單台機台趨勢 | 所選機台，每組一張圖，組內每個參數一條線；X 軸時間 |
| Newest_TBT 最新值排排站 | 每組一張長條圖，X 軸機台、每個參數一根長條，取每台在區間內的最後一個值；機型篩選（`model.<機型>`）；點長條會切換上方的單台機台 |
| TBT 歷史趨勢排排站 | 每組一張圖，每台一個區段（依機台名稱排序），區段內依時間排序；圖例可開關機台，下方可拖曳縮放 |

### 新增一張圖表

```bash
bash scripts/shell/new_chart.sh CDM      # 建立 charts/CDM.ini、charts/CDM.php，並印出 config.ini 要貼的區段
```

1. 編輯 `charts/CDM.ini` 的 `[plot.xxx]`；此時 `source = sample`，用範例資料就能看到完整畫面
2. 編輯 `charts/CDM.php` 寫 `tools()`、`series()` 的 SQL，寫好把 ini 改成 `source = php`
3. 把腳本印出的 `[page.cdm]` 貼進 `config/config.ini`，並把 `cdm` 加到 `[access]` 要看得到的身份
4. `python scripts/python/check_config.py` 檢查

### 設定檔：`charts/<名稱>.ini`

```ini
[page]
source       = php          ; php = 用 <名稱>.php 查資料庫；sample = 內建範例資料
default_days = 60           ; 預設顯示最近幾天
max_days     = 366          ; 一次最多查幾天
quick_days   = "7, 30, 90"  ; 快速區間按鈕
model.1980   = "PAN"        ; 機台代號含 PAN → 機型 1980（不設定就沒有機型下拉選單）
model.2000   = "PAP"

[db]                        ; 這張圖表的資料庫連線；ip 留空 = 使用 AISLE 自己的資料庫
ip       = "10.x.x.x"       ; 帳號密碼只填在主機上，repo 裡一律留空
port     = 3306
name     = "資料庫名稱"
user     = "唯讀帳號"
password = "密碼"
charset  = "utf8mb4"

[plot.m1bf_z]
title  = "M1BF_Z"
params = "M1BF_Z_C1, M1BF_Z_C2"   ; 畫在同一張圖的參數
single = On                        ; 是否畫單台機台趨勢
newest = On                        ; 是否畫最新值排排站
tbt    = On                        ; 是否畫歷史趨勢排排站
ymin   = 0                         ; Y 軸下限（三張圖共用）
ymax   = 6                         ; Y 軸上限（三張圖共用）
newest_ymax = 5                    ; 只改最新值排排站的上限
upper_oos = 5                      ; spec 線（可留空 = 不畫）
upper_ooc = 4.5
lower_ooc = 1
lower_oos = 0.5

[plot.m1bf_ry]
title  = "M1BF_Ry"
params = "M1BF_Ry_C1, M1BF_Ry_C2"
newest = Off                       ; 這組不顯示最新值排排站
tbt_ymin = 0                       ; 只設歷史趨勢排排站的上下限，單台趨勢維持自動
tbt_ymax = 6
```

- 每個 `[plot.<代號>]` 是一組，頁面依檔案順序畫圖；`single` / `newest` / `tbt` 省略時為 On
- 某區塊沒有任何一組開啟時，整個區塊不顯示
- 可選 `unit` 設定 Y 軸名稱（預設 `Data`）；`connect = On` 讓線跨過空值連起來（參數來自取樣時間不同的 table 時使用）
- Y 軸上下限：`ymin` / `ymax` 套用到該組三張圖；`single_ymin`、`newest_ymax`、`tbt_ymin` 等只套用到該區塊並優先；不設或留空為自動，超出範圍的資料會被裁切
- spec 線：`upper_oos` / `upper_ooc` / `lower_ooc` / `lower_oos`，可省略或留空（不畫）。三個區塊都畫成水平線，OOS 紅色實線、OOC 橘色虛線；有填的值須符合 `lower_oos <= lower_ooc < upper_ooc <= upper_oos`。Y 軸自動時會把 spec 線納入範圍
- 存檔後重新整理頁面即生效；格式錯誤時頁面會顯示錯誤（`modules/charts/ChartConfig.php` 檢查）

### 資料來源：`charts/<名稱>.php`

```php
<?php
class BSLrChart extends ChartSource
{
    public function tools()
    {
        $rows = $this->fetchAll('SELECT DISTINCT tool_id FROM bslr_x_data');
        $tools = array();
        foreach ($rows as $r) {
            $tools[] = $r['tool_id'];
        }
        return $tools;
    }

    public function series($tools, $params, $start, $end)
    {
        $where = 'tool_id IN (' . $this->in($tools) . ')
                  AND data_time >= ? AND data_time < DATE_ADD(?, INTERVAL 1 DAY)';
        $bind  = array_merge($tools, array($start, $end));

        // 長表（tool_id, data_time, param, value）
        $a = self::pivot($this->fetchAll(
            'SELECT tool_id, DATE_FORMAT(data_time, \'%Y-%m-%d %H:%i:%s\') AS d, param, value
               FROM bslr_x_data WHERE ' . $where, $bind), 'tool_id', 'd', 'param', 'value');

        // 寬表，欄位 c1 / c2 對應參數 BSLr_Y_C1 / BSLr_Y_C2
        $b = self::wide($this->fetchAll(
            'SELECT tool_id, DATE_FORMAT(data_time, \'%Y-%m-%d %H:%i:%s\') AS d, c1, c2
               FROM bslr_y_summary WHERE ' . $where, $bind),
            'tool_id', 'd', array('BSLr_Y_C1' => 'c1', 'BSLr_Y_C2' => 'c2'));

        return self::merge($a, $b);   // 不同 table 的結果依機台 + 時間合併
    }
}
```

| 工具（`modules/charts/ChartSource.php`） | 用途 |
|---|---|
| `$this->fetchAll($sql, $bind)` | prepared statement 查詢，值一律用 `?` 綁定 |
| `$this->in($list)` | 產生 `IN (...)` 用的 `?,?,?` |
| `self::pivot($rows, 機台欄, 時間欄, 參數欄, 值欄)` | 長表（一列一個參數值）→ 資料格式 |
| `self::wide($rows, 機台欄, 時間欄, 參數 => 欄位)` | 寬表（每個參數一個欄位）→ 資料格式 |
| `self::merge($a, $b, ...)` | 多個 table 的結果合併，對不到的位置補 null |
| `$this->machineOf($tool)` / `$this->machinesOf($tools)` / `$this->toolOf($machine)` | tool_id 與 machine_id 互換（要先實作 `machines()`） |
| `self::table($name)` | 組出來的 table 名稱（例 `'M1BF_' . $machineId`）檢查後加反引號；table 名稱不能用 `?` 綁定，一定要經過它 |

**table 用 machine_id 時**（例 table `M1BF_HP23`，`HP23` 是 `APAN01` 的 machine_id）：在 `<名稱>.php` 實作 `machines()`，回傳 `array('APAN01' => 'HP23', ...)`（可寫死或從對照表查）。實作後 `tools()` 可以省略（預設用 `machines()` 的 tool_id），`series()` 回傳的 key 也可以直接是 machine_id，controller 會自動換成 tool_id；網頁上的機台名稱一律是 tool_id。範例見 `charts/_template.php` 的寫法 4（每台一個 table）、寫法 5（machine_id 欄位）。

資料庫連線在各圖表自己的 `charts/<名稱>.ini` 的 `[db]`（ip / port / name / user / password / charset）；`ip` 留空時使用 AISLE 自己的 `[database]`。帳號密碼只在主機上的檔案填寫，**不要 commit 到 GitHub**（repo 裡一律留空）。`charts/` 從網址讀不到（根目錄 `.htaccess`），`[db]` 也不會送到瀏覽器。

### 資料格式與載入

後端 `index.php?m=<頁面代號>&a=tbt&start=&end=` 回傳區間內全部機台、ini 用到的全部參數：

```json
{
  "APAN01": { "Date": ["2026-01-01", "2026-01-02"],
              "Data": { "M1BF_Z_C1": [1.0, 2.0], "M1BF_Z_C2": [1.1, 2.1], "M1BF_Ry_C1": [1.0, 2.0], "M1BF_Ry_C2": [1.1, 2.1] } }
}
```

- 選用 `"Url": [...]`（與 `Date` 等長）：單台機台趨勢圖點擊數據點會在瀏覽器新分頁開啟該時間點的網址，tooltip 會提示「點擊數據點開啟連結」，資料表多一欄 URL。只接受 `http://`、`https://` 或 `/` 開頭的網址（其他如 `javascript:` 一律忽略）；`pivot()` / `wide()` 最後多給網址欄位名稱即可產生，`merge()` 會保留。沒有 `Url` 時與原本相同
- 每個參數陣列與 `Date` 等長，沒有值的位置是 `null`；排序、型別、補 null、只留 ini 用到的參數由 controller 統一處理，`<名稱>.php` 不需要先排好
- 進入頁面時只呼叫一次，所有圖都從這份資料取得。切換機台、切換機型只在瀏覽器端重畫，不再向後端要資料；只有改日期區間（查詢 / 快速區間）才重新取
- 編碼：**顏色 = 機台**（同機型內依序取色，跟著機台走，篩選後不變）、**線型 / 長條紋理 = 參數**（組內第 1 個參數實線，第 2 個虛線、斜線紋理…）
- 每張圖都有「資料表」按鈕可切換成表格檢視
- 錯誤處理：設定錯誤直接顯示在頁面上；資料庫 / SQL 錯誤只在 `debug = 1` 時顯示內容，否則寫到 PHP error log

## 11. Pending Issue Control Table（`?m=pending_issue`）

追蹤各機台的 pending issue。只有 **EE** 能使用（查詢、新增、編輯、匯出，**不能刪除**），**ADMIN** 全部可以（含刪除、看已刪除、還原），PE 看不到選單、直接開網址會 403。

| 檔案 | 用途 |
|---|---|
| `config/config.ini` `[page.pending_issue]` | 頁面登記；`action.delete` / `action.trash` / `action.restore` = `"ADMIN"`（刪除、看已刪除、還原） |
| `config/pending_issue.ini` | 機型、分類、狀態名稱、Sponsor 身份、匯出開關、圖片上限、輪詢 / 閒置秒數 |
| `modules/pending_issue/` | controller + view |
| `public/assets/js/pending_issue.js` | 表格、篩選、Sponsor 元件、貼圖、輪詢、衝突視窗 |
| `sql/migrations/20261110_pending_issue.sql` | 建表（`pending_issues`、`pending_issue_status_logs`、`pending_issue_images`、`pending_issue_presence`） |
| `storage/uploads/pending_issue/<年月>/` | 圖片檔（網址無法直接讀取） |

**欄位**：機台（必填，機型依代號自動判定，例 `APAN01` → 1980 (PAN)）、機型、分類（PE/YED HL / 選機表 / Aging parts / Others）、Issue 描述（必填）、Initial date、狀態（Open / Monitor / Close）、Sponsor（AISLE 使用者）、Check point date、Remark、圖片。

**畫面**

- 上方機型頁籤（括號內是未結案筆數），下方是分類 × 狀態統計，點數字直接套用篩選
- 篩選：Issue 狀態（多選，預設 Open + Monitor）、分類（多選）、機台、Sponsor、關鍵字、只看 Check point 逾期；條件寫在網址上，重新整理或分享網址都會保留
- 點欄位標題排序（第三次點回預設：Open → Monitor → Close、Check point 早的在前）；Check point 已過且未 Close 顯示紅字「逾期 N 天」
- **Sponsor**：點 ▼ 展開清單，或直接打字篩選（比對帳號與顯示名稱、不分大小寫），↑↓ / Enter / Esc 操作；只能選清單裡的人（`[sponsor] roles` 的啟用帳號）
- **狀態紀錄**：每次狀態改變都寫進 `pending_issue_status_logs`（誰、何時、從哪個狀態），表格顯示最後改狀態的人，編輯視窗有完整歷程
- **圖片**：編輯視窗中 Ctrl+V 貼上截圖、拖曳或選檔；只收 PNG / JPG / GIF（以檔案內容判斷）。圖片經 `?a=image` 檢查權限後才輸出：未存檔的暫存圖只有上傳者、已刪除 issue 的圖只有 ADMIN 看得到
- **軟刪除（只有 ADMIN）**：刪除只標記 `deleted_at`；EE 的編輯視窗沒有刪除按鈕，直接呼叫也會 403。ADMIN 勾「顯示已刪除」後可以還原
- **匯出 CSV**：匯出目前篩選與排序的結果（UTF-8 BOM，Excel 直接開）；`[export] enabled = Off` 時按鈕隱藏、網址回 404
- **IE11**：開啟頁面時跳出警告視窗（IE11 無法貼上截圖，拖曳與選檔可用）

**多人同時操作**

- 樂觀鎖：每筆有 `version`，存檔時比對。別人先存過 → 回 409，視窗列出「你的版本 / 最新版本」不同的欄位，可選 **覆蓋（用我的版本）**、**載入最新** 或取消。覆蓋時仍會比對版本，不會蓋掉自己沒看過的第三人修改
- 每 `poll_seconds`（預設 10）秒輪詢一次，同步別人的新增 / 修改 / 刪除，並顯示「某某 編輯中」；別人改了你正在編輯的那筆，視窗上方會立刻提示
- 閒置 `idle_seconds`（預設 300）秒沒操作，或分頁切到背景，就暫停輪詢（右上角顯示「⏸ 已暫停同步」），讓登入依 `session_idle` 照常逾時；有操作時立即恢復。不設人數上限

<?php
/**
 * Pending Issue Control Table（config.ini：EE 與 ADMIN；刪除 / 看已刪除 / 還原只有 ADMIN）
 * 機型 / 分類 / 狀態 / Sponsor 等設定在 config/pending_issue.ini
 *
 *   index    頁面（表格、篩選、編輯視窗都由 pending_issue.js 呼叫下列 JSON 動作）
 *   list     GET  全部未刪除的 issue（trash=1 且有 action.trash 權限時含已刪除），篩選在前端做
 *   get      GET  單筆完整資料（含圖片、狀態歷程）
 *   save     POST 新增 / 修改；以 version 做樂觀鎖，別人先改過時回 409，不覆蓋
 *   delete   POST 軟刪除（同樣檢查 version；action.delete，預設只有 ADMIN）
 *   restore  POST 還原軟刪除（action.restore，預設只有 ADMIN）
 *   upload   POST 上傳一張圖片（貼上 / 拖曳 / 選檔），存到 storage/uploads/pending_issue/<年月>/
 *   image    GET  輸出圖片（storage 無法從網址直接讀取，一律經過這裡檢查權限）
 *   poll     GET  輪詢：游標之後有變動的資料、誰正在編輯哪一筆
 *   release  POST 關閉編輯視窗時清除自己的「編輯中」
 *   export   GET  依目前篩選匯出 CSV（pending_issue.ini [export] enabled = Off 時 404）
 */
class PendingIssueController extends Controller
{
    const POLL_OVERLAP = 5;   // 輪詢游標往前重疊的秒數，避免交易較晚提交的修改被漏掉（前端用 version 去重）

    private static $cfg = null;

    // ==================================================================
    // 頁面
    // ==================================================================

    public function indexAction()
    {
        $cfg = self::cfg();
        $urls = array();
        foreach (array('list', 'get', 'save', 'delete', 'restore', 'upload', 'image', 'poll', 'release', 'export') as $a) {
            $urls[$a] = url($this->module, $a);
        }
        $this->render('index', array(
            'cfg'    => $cfg,
            'canTrash' => $this->can('trash'),
            'export' => $cfg['export'],
            'config' => array(
                'urls'            => $urls,
                'models'          => $cfg['models'],
                'categories'      => $cfg['categories'],
                'statuses'        => $cfg['statuses'],
                'sponsors'        => $this->sponsorList(),
                'me'              => array('id' => (int) $this->user['id'], 'name' => $this->user['display_name']),
                'canDelete'       => $this->can('delete'),
                'canTrash'        => $this->can('trash'),
                'canRestore'      => $this->can('restore'),
                'exportEnabled'   => $cfg['export'],
                'maxImageMb'      => $cfg['max_mb'],
                'maxImages'       => $cfg['max_per_item'],
                'pollSeconds'     => $cfg['poll_seconds'],
                'idleSeconds'     => $cfg['idle_seconds'],
                'csrfToken'       => Security::csrfToken(),
            ),
        ));
    }

    // ==================================================================
    // 讀取
    // ==================================================================

    public function listAction()
    {
        $trash = $this->query('trash') === '1' && $this->can('trash');
        $rows = Database::fetchAll(
            self::rowSelect() . ($trash ? '' : ' WHERE i.deleted_at IS NULL') . ' ORDER BY i.id DESC'
        );
        foreach ($rows as $k => $r) {
            $rows[$k] = $this->castRow($r);
        }
        $this->json(array(
            'ok'     => true,
            'rows'   => $rows,
            'cursor' => $this->cursor(),
            'trash'  => $trash,
        ));
    }

    public function getAction()
    {
        $issue = $this->findIssue((int) $this->query('id'), $this->can('trash'));
        if (!$issue) {
            return $this->json(array('ok' => false, 'error' => '找不到這筆 issue，可能已被刪除'), 404);
        }
        $this->json(array('ok' => true, 'issue' => $issue));
    }

    public function pollAction()
    {
        $cfg = self::cfg();
        $uid = (int) $this->user['id'];
        $editing = (int) $this->query('editing');
        $now = now();

        // 自己的「編輯中」：只保留正在編輯的那一筆
        Database::execute('DELETE FROM pending_issue_presence WHERE user_id = ? AND issue_id <> ?', array($uid, $editing));
        if ($editing > 0) {
            Database::execute('REPLACE INTO pending_issue_presence (issue_id, user_id, seen_at) VALUES (?, ?, ?)', array($editing, $uid, $now));
        }
        Database::execute('DELETE FROM pending_issue_presence WHERE seen_at < ?', array(date('Y-m-d H:i:s', time() - 3600)));

        // 游標之後有變動的資料（含被刪除 / 還原的）
        $cursor = $this->cursor();
        $since = $this->query('since');
        $changed = array();
        $deleted = array();
        if (preg_match('/^\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}$/', $since)) {
            $trash = $this->query('trash') === '1' && $this->can('trash');
            foreach (Database::fetchAll(self::rowSelect() . ' WHERE i.updated_at >= ? ORDER BY i.id', array($since)) as $r) {
                $r = $this->castRow($r);
                if ($r['deleted'] && !$trash) {
                    $deleted[] = $r['id'];
                } else {
                    $changed[] = $r;
                }
            }
        }

        $this->json(array(
            'ok'      => true,
            'cursor'  => $cursor,
            'changed' => $changed,
            'deleted' => $deleted,
            'editors' => (object) $this->editors($cfg['presence_seconds']),
        ));
    }

    public function saveAction()
    {
        if (!$this->isPost()) {
            return $this->json(array('ok' => false, 'error' => 'POST only'), 405);
        }
        $cfg = self::cfg();
        $id = (int) $this->input('id');
        $version = (int) $this->input('version');
        $overwrite = $this->input('overwrite') === '1';
        $data = array(
            'tool_id'         => strtoupper($this->input('tool_id')),
            'model'           => strtoupper($this->input('model')),
            'category'        => $this->input('category'),
            'issue'           => $this->input('issue'),
            'initial_date'    => $this->input('initial_date'),
            'status'          => $this->input('status', 'open'),
            'sponsor_id'      => (int) $this->input('sponsor_id'),
            'checkpoint_date' => $this->input('checkpoint_date'),
            'remark'          => $this->input('remark'),
        );
        $imageIds = $this->idList($this->input('image_ids'));

        $now = now();
        $uid = (int) $this->user['id'];
        $pdo = Database::pdo();
        $pdo->beginTransaction();
        try {
            $old = null;
            if ($id > 0) {
                // 鎖住這一筆再比對 version，避免兩個人同時通過檢查
                $old = Database::fetchOne(
                    'SELECT id, version, status, sponsor_id, deleted_at FROM pending_issues WHERE id = ? FOR UPDATE',
                    array($id)
                );
                if (!$old || $old['deleted_at'] !== null || (int) $old['version'] !== $version) {
                    $pdo->rollBack();
                    return $this->conflict($id);
                }
            }

            $error = $this->validate($data, $old);
            if ($error === '' && count($imageIds) > $cfg['max_per_item']) {
                $error = '每筆 issue 最多 ' . $cfg['max_per_item'] . ' 張圖片';
            }
            if ($error !== '') {
                $pdo->rollBack();
                return $this->json(array('ok' => false, 'error' => $error), 422);
            }

            $checkpoint = $data['checkpoint_date'] !== '' ? $data['checkpoint_date'] : null;
            $removed = array();
            if (!$old) {
                Database::execute(
                    'INSERT INTO pending_issues (tool_id, model, category, issue, initial_date, status, status_changed_by,
                        status_changed_at, sponsor_id, checkpoint_date, remark, closed_at, version,
                        created_by, updated_by, created_at, updated_at)
                     VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, 1, ?, ?, ?, ?)',
                    array(
                        $data['tool_id'], $data['model'], $data['category'], $data['issue'], $data['initial_date'],
                        $data['status'], $uid, $now, $data['sponsor_id'], $checkpoint, $data['remark'],
                        $data['status'] === 'close' ? $now : null,
                        $uid, $uid, $now, $now,
                    )
                );
                $id = (int) Database::lastInsertId();
                $this->logStatus($id, null, $data['status'], $uid, $now);
            } else {
                $statusChanged = $old['status'] !== $data['status'];
                Database::execute(
                    'UPDATE pending_issues SET tool_id = ?, model = ?, category = ?, issue = ?, initial_date = ?, status = ?,
                        status_changed_by = ' . ($statusChanged ? '?' : 'status_changed_by') . ',
                        status_changed_at = ' . ($statusChanged ? '?' : 'status_changed_at') . ",
                        sponsor_id = ?, checkpoint_date = ?, remark = ?,
                        closed_at = CASE WHEN ? = 'close' THEN IFNULL(closed_at, ?) ELSE NULL END,
                        version = version + 1, updated_by = ?, updated_at = ?
                     WHERE id = ?",
                    array_merge(
                        array($data['tool_id'], $data['model'], $data['category'], $data['issue'], $data['initial_date'], $data['status']),
                        $statusChanged ? array($uid, $now) : array(),
                        array($data['sponsor_id'], $checkpoint, $data['remark'], $data['status'], $now, $uid, $now, $id)
                    )
                );
                if ($statusChanged) {
                    // from 一律用資料庫當下的狀態，覆蓋別人的修改時也不會漏記
                    $this->logStatus($id, $old['status'], $data['status'], $uid, $now);
                }
                $removed = $this->detachImages($id, $imageIds);
            }
            $this->attachImages($id, $imageIds);
            $pdo->commit();
        } catch (Exception $e) {
            if ($pdo->inTransaction()) {
                $pdo->rollBack();
            }
            throw $e;
        }
        // 檔案在交易成功後才刪，避免回滾後資料還在但檔案已不見
        foreach ($removed as $path) {
            $this->unlinkUpload($path);
        }

        $action = !$old ? 'create' : ($overwrite ? 'overwrite' : 'update');
        audit($this->module, $action, array(
            'id' => $id, 'tool_id' => $data['tool_id'], 'status' => $data['status'],
            'from_status' => $old ? $old['status'] : null,
        ));
        $this->json(array('ok' => true, 'issue' => $this->findIssue($id, false)));
    }

    public function deleteAction()
    {
        if (!$this->isPost()) {
            return $this->json(array('ok' => false, 'error' => 'POST only'), 405);
        }
        $id = (int) $this->input('id');
        $now = now();
        $affected = Database::execute(
            'UPDATE pending_issues SET deleted_at = ?, deleted_by = ?, updated_by = ?, updated_at = ?, version = version + 1
             WHERE id = ? AND version = ? AND deleted_at IS NULL',
            array($now, $this->user['id'], $this->user['id'], $now, $id, (int) $this->input('version'))
        );
        if ($affected === 0) {
            return $this->conflict($id);
        }
        Database::execute('DELETE FROM pending_issue_presence WHERE issue_id = ?', array($id));
        audit($this->module, 'delete', array('id' => $id));
        $this->json(array('ok' => true));
    }

    public function restoreAction()
    {
        if (!$this->isPost()) {
            return $this->json(array('ok' => false, 'error' => 'POST only'), 405);
        }
        $id = (int) $this->input('id');
        $now = now();
        $affected = Database::execute(
            'UPDATE pending_issues SET deleted_at = NULL, deleted_by = NULL, updated_by = ?, updated_at = ?, version = version + 1
             WHERE id = ? AND version = ? AND deleted_at IS NOT NULL',
            array($this->user['id'], $now, $id, (int) $this->input('version'))
        );
        if ($affected === 0) {
            $row = $this->findIssue($id, true);
            return $this->json(array(
                'ok' => false, 'conflict' => true,
                'error' => $row ? '這筆資料剛被其他人變更，已重新載入' : '找不到這筆 issue',
                'issue' => $row,
            ), 409);
        }
        audit($this->module, 'restore', array('id' => $id));
        $this->json(array('ok' => true, 'issue' => $this->findIssue($id, true)));
    }

    public function releaseAction()
    {
        Database::execute('DELETE FROM pending_issue_presence WHERE user_id = ?', array($this->user['id']));
        if (App::isAjax()) {
            $this->json(array('ok' => true));
        }
    }

    public function uploadAction()
    {
        if (!$this->isPost()) {
            return $this->json(array('ok' => false, 'error' => 'POST only'), 405);
        }
        $cfg = self::cfg();
        $maxBytes = (int) round($cfg['max_mb'] * 1048576);
        $file = isset($_FILES['image']) ? $_FILES['image'] : null;
        if (!$file || !is_array($file) || !isset($file['error']) || is_array($file['error'])) {
            return $this->json(array('ok' => false, 'error' => '沒有收到圖片（可能超過伺服器上傳上限）'), 400);
        }
        if ($file['error'] === UPLOAD_ERR_INI_SIZE || $file['error'] === UPLOAD_ERR_FORM_SIZE || $file['size'] > $maxBytes) {
            return $this->json(array('ok' => false, 'error' => '圖片超過 ' . $cfg['max_mb'] . ' MB'), 413);
        }
        if ($file['error'] !== UPLOAD_ERR_OK || !is_uploaded_file($file['tmp_name'])) {
            return $this->json(array('ok' => false, 'error' => '上傳失敗（錯誤碼 ' . (int) $file['error'] . '）'), 400);
        }
        // 用檔案內容判斷真實格式，不相信副檔名與瀏覽器給的 MIME
        $info = @getimagesize($file['tmp_name']);
        $types = array(IMAGETYPE_PNG => 'png', IMAGETYPE_JPEG => 'jpg', IMAGETYPE_GIF => 'gif');
        if ($info === false || !isset($types[$info[2]])) {
            return $this->json(array('ok' => false, 'error' => '只接受 PNG / JPG / GIF 圖片'), 415);
        }

        $this->cleanupOrphans();

        $dir = 'pending_issue/' . date('Ym');
        $abs = AISLE_STORAGE . '/uploads/' . $dir;
        if (!is_dir($abs) && !@mkdir($abs, 0775, true)) {
            throw new RuntimeException('無法建立上傳資料夾：storage/uploads/' . $dir . '（請確認 storage/ 可讓 Web Server 寫入）');
        }
        $path = $dir . '/' . bin2hex(Security::randomBytes(16)) . '.' . $types[$info[2]];
        if (!move_uploaded_file($file['tmp_name'], AISLE_STORAGE . '/uploads/' . $path)) {
            throw new RuntimeException('無法寫入上傳檔案，請確認 storage/uploads 可寫入');
        }
        @chmod(AISLE_STORAGE . '/uploads/' . $path, 0664);

        $name = preg_replace('/[\x00-\x1f"\/\\\\]/', '', (string) $file['name']);
        if ($name === '') {
            $name = 'image.' . $types[$info[2]];
        }
        Database::execute(
            'INSERT INTO pending_issue_images (issue_id, file_path, original_name, mime, size, width, height, uploaded_by, created_at)
             VALUES (NULL, ?, ?, ?, ?, ?, ?, ?, ?)',
            array($path, $this->usub($name, 150), $info['mime'], (int) $file['size'],
                min((int) $info[0], 65535), min((int) $info[1], 65535), $this->user['id'], now())
        );
        $id = (int) Database::lastInsertId();
        $this->json(array('ok' => true, 'image' => $this->imageInfo(array(
            'id' => $id, 'original_name' => $name, 'width' => $info[0], 'height' => $info[1],
        ))));
    }

    public function imageAction()
    {
        $img = Database::fetchOne(
            'SELECT m.id, m.issue_id, m.file_path, m.mime, m.original_name, m.uploaded_by, i.deleted_at
             FROM pending_issue_images m
             LEFT JOIN pending_issues i ON i.id = m.issue_id
             WHERE m.id = ?',
            array((int) $this->query('id'))
        );
        $allowed = $img && (
            ($img['issue_id'] === null && (int) $img['uploaded_by'] === (int) $this->user['id'])   // 尚未存檔的暫存圖：只有上傳者
            || ($img['issue_id'] !== null && ($img['deleted_at'] === null || $this->can('trash')))  // 已刪除 issue 的圖：只有 ADMIN
        );
        $base = realpath(AISLE_STORAGE . '/uploads/pending_issue');
        $file = $allowed ? realpath(AISLE_STORAGE . '/uploads/' . $img['file_path']) : false;
        if (!$allowed || $file === false || $base === false || strpos($file, $base . DIRECTORY_SEPARATOR) !== 0 || !is_file($file)) {
            http_response_code(404);
            header('Content-Type: text/plain; charset=utf-8');
            echo 'image not found';
            return;
        }

        // 檔名是亂數、內容不會變，可讓瀏覽器快取
        $etag = '"pi' . $img['id'] . '-' . filesize($file) . '"';
        header('Cache-Control: private, max-age=86400');
        header('ETag: ' . $etag);
        header('X-Content-Type-Options: nosniff');
        if (isset($_SERVER['HTTP_IF_NONE_MATCH']) && trim($_SERVER['HTTP_IF_NONE_MATCH']) === $etag) {
            http_response_code(304);
            return;
        }
        $name = $img['original_name'] !== '' ? $img['original_name'] : basename($file);
        header('Content-Type: ' . $img['mime']);
        header('Content-Length: ' . filesize($file));
        header("Content-Disposition: inline; filename*=UTF-8''" . rawurlencode($name));
        readfile($file);
    }

    public function exportAction()
    {
        $cfg = self::cfg();
        if (!$cfg['export']) {
            return App::error(404, '匯出功能未開啟');
        }
        $trash = $this->query('trash') === '1' && $this->can('trash');
        $where = array();
        $params = array();
        if (!$trash) {
            $where[] = 'i.deleted_at IS NULL';
        }
        $model = strtoupper($this->query('model'));
        if (isset($cfg['models'][$model])) {
            $where[] = 'i.model = ?';
            $params[] = $model;
        }
        foreach (array('status' => 'statuses', 'cat' => 'categories') as $param => $key) {
            $vals = array();
            foreach (explode(',', $this->query($param)) as $v) {
                if (isset($cfg[$key][$v])) {
                    $vals[] = $v;
                }
            }
            if ($vals) {
                $where[] = 'i.' . ($param === 'cat' ? 'category' : 'status') . ' IN (' . implode(',', array_fill(0, count($vals), '?')) . ')';
                $params = array_merge($params, $vals);
            }
        }
        $tool = $this->query('tool');
        if ($tool !== '') {
            $where[] = 'i.tool_id LIKE ?';
            $params[] = '%' . addcslashes(strtoupper($tool), '%_\\') . '%';
        }
        $sponsor = (int) $this->query('sponsor');
        if ($sponsor > 0) {
            $where[] = 'i.sponsor_id = ?';
            $params[] = $sponsor;
        }
        $q = $this->query('q');
        if ($q !== '') {
            $like = '%' . addcslashes($q, '%_\\') . '%';
            $where[] = '(i.issue LIKE ? OR i.remark LIKE ? OR i.tool_id LIKE ?)';
            $params = array_merge($params, array($like, $like, $like));
        }
        if ($this->query('overdue') === '1') {
            $where[] = "i.checkpoint_date < CURDATE() AND i.status <> 'close'";
        }

        $sorts = array(
            'id' => 'i.id', 'model' => 'i.model', 'tool_id' => 'i.tool_id', 'category' => 'i.category',
            'issue' => 'i.issue', 'initial_date' => 'i.initial_date', 'sponsor' => 'sponsor_name',
            'checkpoint_date' => 'i.checkpoint_date', 'remark' => 'i.remark', 'updated_at' => 'i.updated_at',
            'status' => "FIELD(i.status, 'open', 'monitor', 'close')",
        );
        $sort = $this->query('sort');
        $dir = $this->query('dir') === 'desc' ? 'DESC' : 'ASC';
        $order = isset($sorts[$sort])
            ? $sorts[$sort] . ' ' . $dir . ', i.id DESC'
            : "FIELD(i.status, 'open', 'monitor', 'close'), i.checkpoint_date IS NULL, i.checkpoint_date, i.id DESC";

        $rows = Database::fetchAll(
            self::rowSelect() . ($where ? ' WHERE ' . implode(' AND ', $where) : '') . ' ORDER BY ' . $order,
            $params
        );

        $label = isset($cfg['models'][$model]) ? $model : 'ALL';
        $filename = 'pending_issue_' . $label . '_' . date('Ymd_Hi') . '.csv';
        header('Content-Type: text/csv; charset=utf-8');
        header('Content-Disposition: attachment; filename="' . $filename . '"');
        header('Cache-Control: private, no-store');
        $out = fopen('php://output', 'w');
        fwrite($out, "\xEF\xBB\xBF"); // UTF-8 BOM，Excel 直接開不會亂碼
        $head = array('ID', '機型', '機台', '分類', 'Issue', 'Initial date', 'Status', '最後改狀態者', '改狀態時間',
            'Sponsor', 'Check point', '逾期天數', 'Remark', '圖片張數', '建立者', '建立時間', '最後更新者', '最後更新時間');
        if ($trash) {
            $head[] = '已刪除';
        }
        fputcsv($out, $head);
        $today = strtotime(date('Y-m-d'));
        foreach ($rows as $r) {
            $overdue = '';
            if ($r['checkpoint_date'] !== null && $r['status'] !== 'close') {
                $days = (int) floor(($today - strtotime($r['checkpoint_date'])) / 86400);
                $overdue = $days > 0 ? $days : '';
            }
            $line = array(
                $r['id'],
                array_get($cfg['models'], $r['model'], $r['model']),
                $r['tool_id'],
                array_get($cfg['categories'], $r['category'], $r['category']),
                $r['issue'],
                $r['initial_date'],
                array_get($cfg['statuses'], $r['status'], $r['status']),
                $r['status_changed_by_name'],
                $r['status_changed_at'],
                $r['sponsor_name'],
                $r['checkpoint_date'],
                $overdue,
                $r['remark'],
                $r['image_count'],
                $r['created_by_name'],
                $r['created_at'],
                $r['updated_by_name'],
                $r['updated_at'],
            );
            if ($trash) {
                $line[] = $r['deleted_at'] !== null ? $r['deleted_at'] : '';
            }
            fputcsv($out, array_map(array($this, 'csvCell'), $line));
        }
        fclose($out);
        audit($this->module, 'export', array('rows' => count($rows), 'model' => $label));
    }

    /** 防 CSV 公式注入：= + - @ 開頭的內容前面加單引號 */
    public function csvCell($v)
    {
        $v = $v === null ? '' : (string) $v;
        if ($v !== '' && strpos('=+-@', $v[0]) !== false && !preg_match('/^-?\d+(\.\d+)?$/', $v)) {
            $v = "'" . $v;
        }
        return $v;
    }

    /** 列表、輪詢、匯出共用的查詢 */
    private static function rowSelect()
    {
        return 'SELECT i.id, i.tool_id, i.model, i.category, i.issue, i.initial_date, i.status,
                    i.status_changed_at, i.sponsor_id, i.checkpoint_date, i.remark, i.closed_at, i.version,
                    i.created_at, i.updated_at, i.deleted_at,
                    COALESCE(NULLIF(sp.display_name, \'\'), sp.account) AS sponsor_name, sp.is_active AS sponsor_active,
                    COALESCE(NULLIF(sc.display_name, \'\'), sc.account) AS status_changed_by_name,
                    COALESCE(NULLIF(cu.display_name, \'\'), cu.account) AS created_by_name,
                    COALESCE(NULLIF(uu.display_name, \'\'), uu.account) AS updated_by_name,
                    COALESCE(NULLIF(du.display_name, \'\'), du.account) AS deleted_by_name,
                    (SELECT COUNT(*) FROM pending_issue_images m WHERE m.issue_id = i.id) AS image_count
             FROM pending_issues i
             LEFT JOIN users sp ON sp.id = i.sponsor_id
             LEFT JOIN users sc ON sc.id = i.status_changed_by
             LEFT JOIN users cu ON cu.id = i.created_by
             LEFT JOIN users uu ON uu.id = i.updated_by
             LEFT JOIN users du ON du.id = i.deleted_by';
    }

    private function castRow($r)
    {
        foreach (array('id', 'version', 'image_count', 'sponsor_id') as $k) {
            if (isset($r[$k])) {
                $r[$k] = (int) $r[$k];
            }
        }
        $r['sponsor_active'] = (bool) $r['sponsor_active'];
        $r['deleted'] = $r['deleted_at'] !== null;
        foreach (array('sponsor_name', 'status_changed_by_name', 'created_by_name', 'updated_by_name', 'deleted_by_name') as $k) {
            if ($r[$k] === null) {
                $r[$k] = '-';
            }
        }
        foreach (array('remark', 'checkpoint_date') as $k) {
            if ($r[$k] === null) {
                $r[$k] = '';
            }
        }
        return $r;
    }

    /** 單筆完整資料（含圖片、狀態歷程） */
    private function findIssue($id, $withDeleted)
    {
        $row = Database::fetchOne(self::rowSelect() . ' WHERE i.id = ?' . ($withDeleted ? '' : ' AND i.deleted_at IS NULL'), array($id));
        if (!$row) {
            return null;
        }
        $issue = $this->castRow($row);
        $issue['images'] = array();
        foreach (Database::fetchAll(
            'SELECT id, original_name, width, height FROM pending_issue_images WHERE issue_id = ? ORDER BY id',
            array($id)
        ) as $img) {
            $issue['images'][] = $this->imageInfo($img);
        }
        $issue['status_logs'] = array();
        foreach (Database::fetchAll(
            'SELECT l.from_status, l.to_status, l.changed_at, COALESCE(NULLIF(u.display_name, \'\'), u.account) AS by_name
             FROM pending_issue_status_logs l LEFT JOIN users u ON u.id = l.changed_by
             WHERE l.issue_id = ? ORDER BY l.id',
            array($id)
        ) as $log) {
            if ($log['by_name'] === null) {
                $log['by_name'] = '-';
            }
            $issue['status_logs'][] = $log;
        }
        return $issue;
    }

    private function imageInfo($img)
    {
        return array(
            'id'     => (int) $img['id'],
            'name'   => $img['original_name'],
            'width'  => (int) $img['width'],
            'height' => (int) $img['height'],
            'url'    => url($this->module, 'image', array('id' => (int) $img['id'])),
        );
    }

    /**
     * 欄位檢查，會正規化 $d（機型由機台代號自動判定）
     * @param array|null $old 修改時的原資料（Sponsor 沒改時，允許保留已停用的帳號）
     */
    private function validate(&$d, $old)
    {
        $cfg = self::cfg();
        if (!preg_match('/^[A-Z0-9][A-Z0-9_.\-]{0,63}$/', $d['tool_id'])) {
            return '機台代號必填，只能使用英數字、底線、點、減號（最多 64 字）';
        }
        $detected = $this->detectModel($d['tool_id']);
        if ($detected !== '') {
            $d['model'] = $detected;
        }
        if (!isset($cfg['models'][$d['model']])) {
            return '無法由機台代號判定機型，請選擇機型';
        }
        if (!isset($cfg['categories'][$d['category']])) {
            return '請選擇分類';
        }
        if ($d['issue'] === '') {
            return 'Issue 描述必填';
        }
        if (strlen($d['issue']) > 60000 || strlen($d['remark']) > 60000) {
            return '內容過長';
        }
        if (!isset($cfg['statuses'][$d['status']])) {
            return '狀態不正確';
        }
        if (!$this->validDate($d['initial_date'])) {
            return 'Initial date 格式需為 YYYY-MM-DD';
        }
        if ($d['checkpoint_date'] !== '' && !$this->validDate($d['checkpoint_date'])) {
            return 'Check point date 格式需為 YYYY-MM-DD';
        }
        $keepOld = $old && (int) $old['sponsor_id'] === $d['sponsor_id'];
        if (!$keepOld && !$this->isSponsorCandidate($d['sponsor_id'])) {
            return 'Sponsor 必須是 AISLE 使用者（請從清單中選擇）';
        }
        return '';
    }

    /** 機台代號包含機型代碼（不分大小寫）→ 該機型；較長的代碼優先 */
    private function detectModel($toolId)
    {
        $keys = array_keys(self::cfg()['models']);
        usort($keys, function ($a, $b) {
            return strlen($b) - strlen($a);
        });
        foreach ($keys as $k) {
            if ($k !== '' && stripos($toolId, $k) !== false) {
                return $k;
            }
        }
        return '';
    }

    /** 可選為 Sponsor 的使用者：啟用中、身份在 [sponsor] roles */
    private function sponsorList()
    {
        $roles = self::cfg()['sponsor_roles'];
        if (!$roles) {
            return array();
        }
        $list = array();
        foreach (Database::fetchAll(
            'SELECT id, account, display_name FROM users
             WHERE is_active = 1 AND role IN (' . implode(',', array_fill(0, count($roles), '?')) . ')
             ORDER BY display_name, account',
            $roles
        ) as $u) {
            $list[] = array(
                'id'      => (int) $u['id'],
                'account' => $u['account'],
                'name'    => $u['display_name'] !== '' ? $u['display_name'] : $u['account'],
            );
        }
        return $list;
    }

    private function isSponsorCandidate($id)
    {
        foreach ($this->sponsorList() as $u) {
            if ($u['id'] === $id) {
                return true;
            }
        }
        return false;
    }

    private function logStatus($issueId, $from, $to, $uid, $now)
    {
        Database::execute(
            'INSERT INTO pending_issue_status_logs (issue_id, from_status, to_status, changed_by, changed_at) VALUES (?, ?, ?, ?, ?)',
            array($issueId, $from, $to, $uid, $now)
        );
    }

    /** 存檔 / 刪除時 version 不符或已被刪除：回 409 並附上最新資料，讓前端選擇覆蓋或載入最新 */
    private function conflict($id)
    {
        $current = $this->findIssue($id, true);
        if (!$current) {
            return $this->json(array('ok' => false, 'conflict' => true, 'reason' => 'gone', 'error' => '找不到這筆 issue'), 409);
        }
        if ($current['deleted']) {
            return $this->json(array(
                'ok' => false, 'conflict' => true, 'reason' => 'deleted',
                'error' => '這筆 issue 已被 ' . $current['deleted_by_name'] . ' 於 ' . $current['deleted_at'] . ' 刪除',
            ), 409);
        }
        return $this->json(array(
            'ok'       => false,
            'conflict' => true,
            'reason'   => 'modified',
            'error'    => '這筆 issue 在你編輯期間已被 ' . $current['updated_by_name'] . ' 於 ' . $current['updated_at'] . ' 修改',
            'issue'    => $current,
        ), 409);
    }

    /** 其他人正在編輯哪幾筆：issue_id => [名字] */
    private function editors($seconds)
    {
        $out = array();
        foreach (Database::fetchAll(
            'SELECT p.issue_id, COALESCE(NULLIF(u.display_name, \'\'), u.account) AS name
             FROM pending_issue_presence p JOIN users u ON u.id = p.user_id
             WHERE p.seen_at >= ? AND p.user_id <> ? ORDER BY p.seen_at',
            array(date('Y-m-d H:i:s', time() - $seconds), $this->user['id'])
        ) as $r) {
            $out[$r['issue_id']][] = $r['name'];
        }
        return $out;
    }

    /** 輪詢游標：伺服器時間往前重疊幾秒 */
    private function cursor()
    {
        return date('Y-m-d H:i:s', time() - self::POLL_OVERLAP);
    }

    private function usub($s, $length)
    {
        return preg_match('/^.{0,' . (int) $length . '}/us', $s, $m) ? $m[0] : '';
    }

    private function validDate($s)
    {
        if (!preg_match('/^(\d{4})-(\d{2})-(\d{2})$/', $s, $m)) {
            return false;
        }
        return checkdate((int) $m[2], (int) $m[3], (int) $m[1]);
    }

    private function idList($csv)
    {
        $ids = array();
        foreach (explode(',', $csv) as $v) {
            $v = (int) $v;
            if ($v > 0) {
                $ids[$v] = $v;
            }
        }
        return array_values($ids);
    }

    /** 把自己剛上傳、尚未綁定的圖片綁到這筆 issue */
    private function attachImages($issueId, $ids)
    {
        if (!$ids) {
            return;
        }
        Database::execute(
            'UPDATE pending_issue_images SET issue_id = ?
             WHERE issue_id IS NULL AND uploaded_by = ? AND id IN (' . implode(',', array_fill(0, count($ids), '?')) . ')',
            array_merge(array($issueId, $this->user['id']), $ids)
        );
    }

    /** 移除這筆 issue 上不在保留清單內的圖片，回傳要刪的檔案路徑 */
    private function detachImages($issueId, $keepIds)
    {
        $paths = array();
        foreach (Database::fetchAll('SELECT id, file_path FROM pending_issue_images WHERE issue_id = ?', array($issueId)) as $img) {
            if (!in_array((int) $img['id'], $keepIds, true)) {
                Database::execute('DELETE FROM pending_issue_images WHERE id = ?', array($img['id']));
                $paths[] = $img['file_path'];
            }
        }
        return $paths;
    }

    /** 清除超過一天仍未綁定 issue 的暫存圖片（貼上後沒按儲存） */
    private function cleanupOrphans()
    {
        $old = Database::fetchAll(
            'SELECT id, file_path FROM pending_issue_images WHERE issue_id IS NULL AND created_at < ? LIMIT 50',
            array(date('Y-m-d H:i:s', time() - 86400))
        );
        foreach ($old as $img) {
            Database::execute('DELETE FROM pending_issue_images WHERE id = ?', array($img['id']));
            $this->unlinkUpload($img['file_path']);
        }
    }

    private function unlinkUpload($path)
    {
        $file = AISLE_STORAGE . '/uploads/' . $path;
        if (strpos($path, '..') === false && strpos($path, 'pending_issue/') === 0 && is_file($file)) {
            @unlink($file);
        }
    }

 *   - 每 N 秒輪詢同步別人的修改與「某某 編輯中」；閒置或分頁在背景時暫停，讓登入照常逾時
 *   - 存檔以 version 做樂觀鎖，衝突（409）時可選「覆蓋」或「載入最新」
 *   - 編輯視窗可 Ctrl+V 貼上截圖、拖曳或選檔上傳圖片
 * 設定由 view 放在 window.PENDING_ISSUE
 */
(function ($) {
    if (!$ || !window.PENDING_ISSUE) {
        return;
    }
    var CFG = window.PENDING_ISSUE;
    var STATUS_ORDER = { open: 0, monitor: 1, close: 2 };
    var DEFAULT_STATUS = ['open', 'monitor'];
    var IS_IE = /Trident\/|MSIE /.test(window.navigator.userAgent);

    // ==================================================================
    // 小工具
    // ==================================================================
    function esc(s) {
        return String(s === null || s === undefined ? '' : s)
            .replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;')
            .replace(/"/g, '&quot;').replace(/'/g, '&#39;');
    }
    function nl2br(s) { return esc(s).replace(/\r?\n/g, '<br>'); }
    function pad(n) { return n < 10 ? '0' + n : String(n); }
    function today() {
        var d = new Date();
        return d.getFullYear() + '-' + pad(d.getMonth() + 1) + '-' + pad(d.getDate());
    }
    function nowMs() { return new Date().getTime(); }
    function daysBetween(a, b) {
        // a、b 為 YYYY-MM-DD，回傳 b - a 的天數
        var pa = a.split('-'), pb = b.split('-');
        var ta = Date.UTC(+pa[0], +pa[1] - 1, +pa[2]), tb = Date.UTC(+pb[0], +pb[1] - 1, +pb[2]);
        return Math.round((tb - ta) / 86400000);
    }
    function errorText(xhr, fallback) {
        var r = xhr && xhr.responseJSON;
        return (r && r.error) || fallback || '連線失敗，請稍後再試';
    }
    function store(kind, key, value) {
        try {
            var s = window[kind];
            if (value === undefined) {
                return s.getItem(key);
            }
            s.setItem(key, value);
        } catch (e) {
            // 瀏覽器停用 storage 時只是不記憶
        }
        return null;
    }
    /** 把符合的字標亮（不分大小寫） */
    function highlight(text, q) {
        text = String(text);
        if (!q) {
            return esc(text);
        }
        var i = text.toLowerCase().indexOf(q.toLowerCase());
        if (i < 0) {
            return esc(text);
        }
        return esc(text.substring(0, i)) + '<mark>' + esc(text.substring(i, i + q.length)) + '</mark>' + esc(text.substring(i + q.length));
    }
    function shortTime(dt) { return dt ? String(dt).substring(5, 16) : ''; }
    function shortDate(dt) { return dt ? String(dt).substring(5, 10).replace('-', '/') : ''; }

    // ==================================================================
    // Sponsor 元件：下拉選單 + 直接輸入篩選（只能選清單裡的人）
    // ==================================================================
    function Combo($wrap, opts) {
        var self = this;
        this.opts = opts;
        this.items = opts.items.slice(0);
        this.extra = null;        // 不在清單內的目前值（例如已停用的帳號）
        this.value = '';
        this.active = -1;
        this.shown = [];
        $wrap.html(
            '<input type="text" class="pi-combo-input" id="' + esc(opts.inputId) + '" placeholder="' + esc(opts.placeholder || '') + '" autocomplete="off">' +
            '<button type="button" class="pi-combo-btn" tabindex="-1" title="展開清單">▼</button>' +
            '<ul class="pi-combo-list" style="display:none"></ul>'
        );
        this.$input = $wrap.find('.pi-combo-input');
        this.$list = $wrap.find('.pi-combo-list');

        this.$input.on('focus click', function () {
            self.open(self.$input.val() === self.labelOf(self.value) ? '' : self.$input.val());
        }).on('input', function () {
            self.open(self.$input.val());
        }).on('keydown', function (e) {
            var k = e.keyCode;
            if (k === 40 || k === 38) {
                e.preventDefault();
                if (!self.$list.is(':visible')) {
                    self.open('');
                    return;
                }
                self.move(k === 40 ? 1 : -1);
            } else if (k === 13) {
                e.preventDefault();
                if (self.$list.is(':visible') && self.active >= 0 && self.shown[self.active]) {
                    self.choose(self.shown[self.active].id);
                }
            } else if (k === 27) {
                if (self.$list.is(':visible')) {
                    e.preventDefault();
                    e.stopPropagation();
                    self.close();
                    self.$input.val(self.labelOf(self.value));
                }
            }
        }).on('blur', function () {
            setTimeout(function () { self.commit(); }, 150);
        });
        $wrap.find('.pi-combo-btn').on('mousedown', function (e) {
            e.preventDefault();
        }).on('click', function () {
            if (self.$list.is(':visible')) {
                self.close();
            } else {
                self.$input.focus();
                self.open('');
            }
        });
        this.$list.on('mousedown', 'li', function (e) {
            e.preventDefault();
            var id = $(this).data('id');
            self.choose(id === undefined || id === '' ? '' : String(id));
        });
    }
    Combo.prototype.all = function () {
        var list = [];
        if (this.opts.allowAll) {
            list.push({ id: '', name: this.opts.allLabel || '全部', account: '' });
        }
        list = list.concat(this.items);
        if (this.extra) {
            list.push(this.extra);
        }
        return list;
    };
    Combo.prototype.labelOf = function (id) {
        var list = this.all();
        for (var i = 0; i < list.length; i++) {
            if (String(list[i].id) === String(id)) {
                return list[i].id === '' ? '' : list[i].name;
            }
        }
        return '';
    };
    Combo.prototype.open = function (q) {
        q = $.trim(q || '').toLowerCase();
        var list = this.all(), html = '', self = this;
        this.shown = [];
        $.each(list, function (i, it) {
            if (q && it.id !== '' && it.name.toLowerCase().indexOf(q) < 0 && it.account.toLowerCase().indexOf(q) < 0) {
                return;
            }
            if (q && it.id === '') {
                return;
            }
            self.shown.push(it);
        });
        $.each(this.shown, function (i, it) {
            var sel = String(it.id) === String(self.value);
            html += '<li data-id="' + esc(it.id) + '" class="' + (sel ? 'is-selected' : '') + (it.inactive ? ' is-inactive' : '') + '">' +
                (it.id === '' ? esc(it.name) : highlight(it.name, q) +
                    (it.account && it.account !== it.name ? ' <span class="dim">' + highlight(it.account, q) + '</span>' : '') +
                    (it.inactive ? ' <span class="dim">（已停用）</span>' : '')) +
                '</li>';
        });
        if (!this.shown.length) {
            html = '<li class="pi-combo-empty dim">&gt; 沒有符合的 AISLE 使用者</li>';
        }
        this.$list.html(html).show();
        this.active = -1;
        for (var i = 0; i < this.shown.length; i++) {
            if (String(this.shown[i].id) === String(this.value)) {
                this.active = i;
            }
        }
        if (this.active < 0 && this.shown.length && q) {
            this.active = 0;
        }
        this.paintActive();
    };
    Combo.prototype.move = function (d) {
        if (!this.shown.length) {
            return;
        }
        this.active = (this.active + d + this.shown.length) % this.shown.length;
        this.paintActive();
    };
    Combo.prototype.paintActive = function () {
        var $li = this.$list.children('li').removeClass('is-active');
        if (this.active >= 0) {
            var el = $li.eq(this.active).addClass('is-active')[0];
            if (el && el.offsetTop !== undefined) {
                var list = this.$list[0];
                if (el.offsetTop < list.scrollTop) {
                    list.scrollTop = el.offsetTop;
                } else if (el.offsetTop + el.offsetHeight > list.scrollTop + list.clientHeight) {
                    list.scrollTop = el.offsetTop + el.offsetHeight - list.clientHeight;
                }
            }
        }
    };
    Combo.prototype.close = function () {
        this.$list.hide();
    };
    Combo.prototype.choose = function (id) {
        var changed = String(id) !== String(this.value);
        this.value = String(id);
        this.$input.val(this.labelOf(id)).removeClass('is-invalid');
        this.close();
        if (changed && this.opts.onChange) {
            this.opts.onChange(this.value);
        }
    };
    /** 離開欄位：打了字卻沒選 → 完全符合一人就選他，否則還原 */
    Combo.prototype.commit = function () {
        if (this.$input.is(':focus')) {
            return;
        }
        this.close();
        var text = $.trim(this.$input.val());
        if (text === this.labelOf(this.value)) {
            return;
        }
        if (text === '' && this.opts.allowAll) {
            this.choose('');
            return;
        }
        var list = this.all(), hit = null, lower = text.toLowerCase();
        for (var i = 0; i < list.length; i++) {
            if (list[i].id !== '' && (list[i].name.toLowerCase() === lower || list[i].account.toLowerCase() === lower)) {
                hit = list[i];
                break;
            }
        }
        if (hit) {
            this.choose(String(hit.id));
            return;
        }
        this.$input.val(this.labelOf(this.value));
        if (this.opts.onInvalid) {
            this.opts.onInvalid();
        }
    };
    /** 設定目前值；不在清單內（已停用）的帳號用 name 顯示 */
    Combo.prototype.set = function (id, name) {
        id = id === null || id === undefined ? '' : String(id);
        this.extra = null;
        var found = false;
        for (var i = 0; i < this.items.length; i++) {
            if (String(this.items[i].id) === id) {
                found = true;
            }
        }
        if (!found && id !== '') {
            this.extra = { id: id, name: name || ('#' + id), account: '', inactive: true };
        }
        this.value = id;
        this.$input.val(this.labelOf(id)).removeClass('is-invalid');
    };

    $(function () {
        var $rows = $('#pi-rows');
        var $modal = $('#pi-modal');
        var $form = $('#pi-form');
        var $error = $('#pi-error');
        var $images = $('#pi-images');
        var $conflict = $('#pi-conflict');
        var $live = $('#pi-live');

        var sponsorItems = $.map(CFG.sponsors, function (u) {
            return { id: String(u.id), name: u.name, account: u.account };
        });
        var sponsorName = {};
        $.each(CFG.sponsors, function (i, u) { sponsorName[u.id] = u.name; });

        var state = {
            rows: {},            // id => row
            cursor: '',
            trash: false,
            loaded: false,
            filter: { model: '', status: DEFAULT_STATUS.slice(0), cat: [], tool: '', sponsor: '', q: '', overdue: false },
            sort: { key: '', dir: 'asc' },
            editors: {},         // issue_id => [名字]
            editing: null,       // 編輯中的 issue（新增時為 null）
            editingId: 0,
            original: null,      // 開啟編輯視窗當下的表單值，衝突比對用
            images: [],
            uploading: 0,
            dirty: false,
            conflictIssue: null,
            lastActivity: nowMs(),
            paused: false,
            pollXhr: null
        };

        // ---------------- 網址參數 ----------------
        function getParam(name) {
            var m = new RegExp('[?&]' + name + '=([^&#]*)').exec(window.location.search);
            return m ? decodeURIComponent(m[1].replace(/\+/g, ' ')) : null;
        }
        function splitList(v, allowed) {
            var out = [];
            $.each(String(v || '').split(','), function (i, s) {
                if (s && allowed[s] !== undefined) {
                    out.push(s);
                }
            });
            return out;
        }
        function readUrl() {
            var f = state.filter, v;
            v = getParam('model');
            f.model = v && CFG.models[v] !== undefined ? v : '';
            v = getParam('status');
            f.status = v === null ? DEFAULT_STATUS.slice(0) : splitList(v, CFG.statuses);
            f.cat = splitList(getParam('cat'), CFG.categories);
            f.tool = getParam('tool') || '';
            f.sponsor = getParam('sponsor') || '';
            f.q = getParam('q') || '';
            f.overdue = getParam('overdue') === '1';
            v = getParam('sort');
            state.sort.key = v || '';
            state.sort.dir = getParam('dir') === 'desc' ? 'desc' : 'asc';
        }
        function filterParams() {
            var f = state.filter, p = {};
            if (f.model) { p.model = f.model; }
            p.status = f.status.join(',');
            if (f.cat.length) { p.cat = f.cat.join(','); }
            if (f.tool) { p.tool = f.tool; }
            if (f.sponsor) { p.sponsor = f.sponsor; }
            if (f.q) { p.q = f.q; }
            if (f.overdue) { p.overdue = 1; }
            if (state.sort.key) {
                p.sort = state.sort.key;
                p.dir = state.sort.dir;
            }
            return p;
        }
        function writeUrl() {
            if (!window.history || !window.history.replaceState) {
                return;
            }
            var p = $.extend({ m: getParam('m') || 'pending_issue' }, filterParams());
            window.history.replaceState(null, '', window.location.pathname + '?' + $.param(p));
        }

        // ---------------- 篩選與排序 ----------------
        function isOverdue(r) {
            return r.checkpoint_date && r.status !== 'close' && !r.deleted && r.checkpoint_date < today();
        }
        function matches(r, ignoreModel) {
            var f = state.filter;
            if (!ignoreModel && f.model && r.model !== f.model) { return false; }
            if (f.status.length && $.inArray(r.status, f.status) < 0) { return false; }
            if (f.cat.length && $.inArray(r.category, f.cat) < 0) { return false; }
            if (f.tool && r.tool_id.indexOf(f.tool.toUpperCase()) < 0) { return false; }
            if (f.sponsor && String(r.sponsor_id) !== String(f.sponsor)) { return false; }
            if (f.q) {
                var q = f.q.toLowerCase();
                if ((r.issue + '\n' + r.remark + '\n' + r.tool_id).toLowerCase().indexOf(q) < 0) { return false; }
            }
            if (f.overdue && !isOverdue(r)) { return false; }
            return true;
        }
        function sortValue(r, key) {
            switch (key) {
            case 'id': return r.id;
            case 'status': return STATUS_ORDER[r.status];
            case 'sponsor': return String(r.sponsor_name).toLowerCase();
            case 'model': return String(CFG.models[r.model] || r.model).toLowerCase();
            case 'category': return String(CFG.categories[r.category] || r.category).toLowerCase();
            default: return String(r[key] === null || r[key] === undefined ? '' : r[key]).toLowerCase();
            }
        }
        function compare(a, b) {
            var key = state.sort.key, va, vb;
            if (key) {
                va = sortValue(a, key);
                vb = sortValue(b, key);
                // 空值一律排最後
                if (va === '' && vb !== '') { return 1; }
                if (vb === '' && va !== '') { return -1; }
                if (va < vb) { return state.sort.dir === 'asc' ? -1 : 1; }
                if (va > vb) { return state.sort.dir === 'asc' ? 1 : -1; }
                return b.id - a.id;
            }
            // 預設：Open → Monitor → Close，Check point 早的在前（沒填的最後），再依新到舊
            if (a.status !== b.status) { return STATUS_ORDER[a.status] - STATUS_ORDER[b.status]; }
            if (a.checkpoint_date !== b.checkpoint_date) {
                if (!a.checkpoint_date) { return 1; }
                if (!b.checkpoint_date) { return -1; }
                return a.checkpoint_date < b.checkpoint_date ? -1 : 1;
            }
            return b.id - a.id;
        }

        // ---------------- 畫面 ----------------
        function statusTag(s) {
            return '<span class="pi-tag pi-tag-' + esc(s) + '">' + esc(CFG.statuses[s] || s) + '</span>';
        }
        function render() {
            var list = [], all = [];
            $.each(state.rows, function (id, r) {
                all.push(r);
                if (matches(r, false)) {
                    list.push(r);
                }
            });
            list.sort(compare);

            var html = '';
            $.each(list, function (i, r) {
                var od = isOverdue(r) ? daysBetween(r.checkpoint_date, today()) : 0;
                html += '<tr class="pi-row pi-row-' + esc(r.status) + (r.deleted ? ' pi-row-deleted' : '') + '" data-id="' + r.id + '">' +
                    '<td class="dim">' + r.id + '</td>' +
                    '<td class="pi-nowrap">' + esc(CFG.models[r.model] || r.model) + '</td>' +
                    '<td class="pi-tool">' + esc(r.tool_id) + '</td>' +
                    '<td>' + esc(CFG.categories[r.category] || r.category) + '</td>' +
                    '<td class="pi-issue"><div class="pi-clip">' + nl2br(r.issue) + '</div>' +
                        (r.image_count ? '<span class="pi-imgcount" title="圖片">[IMG×' + r.image_count + ']</span>' : '') +
                        '<span class="pi-editing" data-editing="' + r.id + '"></span></td>' +
                    '<td class="pi-nowrap">' + esc(r.initial_date) + '</td>' +
                    '<td class="pi-nowrap">' + statusTag(r.status) +
                        '<small class="pi-by" title="最後改狀態：' + esc(r.status_changed_by_name + ' ' + (r.status_changed_at || '')) + '">' +
                        esc(r.status_changed_by_name) + ' ' + esc(shortDate(r.status_changed_at)) + '</small></td>' +
                    '<td class="pi-nowrap">' + esc(r.sponsor_name) + (r.sponsor_active ? '' : ' <span class="dim">(已停用)</span>') + '</td>' +
                    '<td class="pi-nowrap' + (od > 0 ? ' pi-overdue' : '') + '">' + esc(r.checkpoint_date) +
                        (od > 0 ? '<small>逾期 ' + od + ' 天</small>' : '') + '</td>' +
                    '<td class="pi-remark"><div class="pi-clip">' + nl2br(r.remark) + '</div></td>' +
                    '<td class="dim pi-nowrap" title="' + esc(r.updated_at) + '">' + esc(r.updated_by_name) + '<br>' + esc(shortTime(r.updated_at)) +
                        (r.deleted ? '<br><span class="text-red">已刪除</span>' +
                            (CFG.canRestore ? '<br><button type="button" class="btn btn-sm pi-restore" data-id="' + r.id + '">[ 還原 ]</button>' : '') : '') +
                    '</td></tr>';
            });
            if (!list.length) {
                html = '<tr><td colspan="11" class="dim">&gt; ' + (state.loaded ? '沒有符合條件的 issue' : 'LOADING...') + '</td></tr>';
            }
            $rows.html(html);
            $('#pi-count').text('(' + list.length + ' / ' + all.length + ')');
            renderSort();
            renderSummary(all);
            renderTools(all);
            renderEditors();
        }

        function renderSort() {
            $('.pi-table th[data-sort]').each(function () {
                var $th = $(this), on = $th.data('sort') === state.sort.key;
                $th.toggleClass('is-sorted', on).attr('data-dir', on ? state.sort.dir : null);
            });
        }

        function renderSummary(all) {
            var sum = {}, models = { '': 0 };
            $.each(CFG.categories, function (c) { sum[c] = { open: 0, monitor: 0, close: 0 }; });
            $.each(CFG.models, function (m) { models[m] = 0; });
            $.each(all, function (i, r) {
                if (r.deleted) {
                    return;
                }
                if (r.status !== 'close') {
                    models[''] += 1;
                    if (models[r.model] !== undefined) {
                        models[r.model] += 1;
                    }
                }
                if ((!state.filter.model || r.model === state.filter.model) && sum[r.category] && sum[r.category][r.status] !== undefined) {
                    sum[r.category][r.status] += 1;
                }
            });
            $('#pi-summary .pi-sum-card').each(function () {
                var $c = $(this), s = sum[$c.data('category')] || {};
                $c.find('[data-count]').each(function () {
                    $(this).text(s[$(this).data('count')] || 0);
                });
            });
            $('#pi-tabs [data-model-count]').each(function () {
                var n = models[$(this).attr('data-model-count')] || 0;
                $(this).text(n ? '(' + n + ')' : '').attr('title', '未結案 ' + n + ' 筆');
            });
            $('#pi-tabs .pi-tab').each(function () {
                $(this).toggleClass('active', String($(this).data('model')) === state.filter.model);
            });
        }

        function renderTools(all) {
            var seen = {}, html = '';
            $.each(all, function (i, r) {
                if (!seen[r.tool_id] && (!state.filter.model || r.model === state.filter.model)) {
                    seen[r.tool_id] = true;
                }
            });
            $.each($.map(seen, function (v, k) { return k; }).sort(), function (i, t) {
                html += '<option value="' + esc(t) + '">';
            });
            $('#pi-tools').html(html);
        }

        function renderEditors() {
            $rows.find('[data-editing]').each(function () {
                var names = state.editors[$(this).data('editing')];
                $(this).html(names ? '<span class="pi-who">✎ ' + esc(names.join(', ')) + ' 編輯中</span>' : '');
            });
            var others = state.editingId ? state.editors[state.editingId] : null;
            if (others && $modal.is(':visible')) {
                $('#pi-editors').html('&gt; ' + esc(others.join(', ')) + ' 也正在編輯這筆；誰先存檔，另一人存檔時會出現衝突提示').show();
            } else {
                $('#pi-editors').hide();
            }
        }

        function syncFilterInputs() {
            var f = state.filter;
            $('#f-status input').each(function () { this.checked = $.inArray(this.value, f.status) >= 0; });
            $('#f-cat input').each(function () { this.checked = $.inArray(this.value, f.cat) >= 0; });
            $('#f-tool').val(f.tool);
            $('#f-q').val(f.q);
            $('#f-overdue').prop('checked', f.overdue);
            filterSponsor.set(f.sponsor);
        }

        function setLive(mode, text) {
            $live.removeClass('is-paused is-error');
            if (mode === 'paused') {
                $live.addClass('is-paused').text('⏸ ' + text);
            } else if (mode === 'error') {
                $live.addClass('is-error').text('● OFFLINE');
            } else {
                $live.text('● LIVE');
            }
        }

        // ---------------- 載入與輪詢 ----------------
        function load() {
            return $.get(CFG.urls.list, { trash: state.trash ? 1 : 0 }).done(function (res) {
                state.rows = {};
                $.each(res.rows, function (i, r) { state.rows[r.id] = r; });
                state.cursor = res.cursor;
                state.loaded = true;
                render();
            }).fail(function (xhr) {

                    $rows.html('<tr><td colspan="11" class="text-red">&gt; ' + esc(errorText(xhr)) + '</td></tr>');
                }
            });

        function poll(force) {
            if ((state.paused && !force) || state.pollXhr || !state.loaded) {
                return;
            }
            state.pollXhr = $.get(CFG.urls.poll, {
                since: state.cursor,
                editing: state.editingId,
                trash: state.trash ? 1 : 0
            }).done(function (res) {
                var changed = false;
                state.cursor = res.cursor;
                state.editors = res.editors || {};
                $.each(res.changed || [], function (i, r) {
                    var cur = state.rows[r.id];
                    if (!cur || cur.version < r.version) {
                        state.rows[r.id] = r;
                        changed = true;
                        noteStale(r, false);
                    }
                });
                $.each(res.deleted || [], function (i, id) {
                    if (state.rows[id]) {
                        noteStale(state.rows[id], true);
                        delete state.rows[id];
                        changed = true;
                    }
                });
                if (changed) {
                    render();
                } else {
                    renderEditors();
                }
                if (!state.paused) {
                    setLive('live');
                }
            }).fail(function (xhr) {
                if (xhr.status !== 401) {
                    setLive('error');
                }
            }).always(function () {
                state.pollXhr = null;
            });
        }

        /** 別人改了我正在編輯的那一筆：立刻提示，不用等到存檔 */
        function noteStale(r, gone) {
            if (!$modal.is(':visible') || state.editingId !== r.id) {
                return;
            }
            var mine = +$form.find('[name=version]').val();
            if (!gone && r.version <= mine) {
                return;

            $('#pi-stale-text').text(gone
                ? '> 這筆已被刪除，存檔將會失敗'
                : '> 這筆已被 ' + r.updated_by_name + ' 於 ' + r.updated_at + ' 更新');
            $('#pi-stale-load').toggle(!gone);
            $('#pi-stale').show();
        }

        // 閒置偵測：超過 idleSeconds 沒操作，或分頁在背景，就暫停輪詢，讓 session 照常逾時
        function isHidden() { return document.hidden === true || document.msHidden === true; }
        function pause(reason) {
            if (!state.paused) {
                state.paused = true;
            }
            setLive('paused', reason);
        }
        function resume() {
            state.paused = false;
            setLive('live');
            poll(true);
        }
        function tick() {
            if (isHidden()) {
                pause('已暫停同步（分頁在背景）');
            } else if (nowMs() - state.lastActivity > CFG.idleSeconds * 1000) {
                pause('已暫停同步（閒置）');
            } else {
                poll(false);
            }
        }
        $(document).on('mousemove keydown mousedown wheel touchstart paste', function () {
            state.lastActivity = nowMs();
            if (state.paused && !isHidden()) {

        });

                pause('已暫停同步（分頁在背景）');
            } else if (nowMs() - state.lastActivity <= CFG.idleSeconds * 1000) {
                resume();
            }
        });

        function displayValue(k, v, issue) {
            if (k === 'model') { return CFG.models[v] || v; }

        function detectModel(tool) {
            var keys = $.map(CFG.models, function (v, k) { return k; });
            keys.sort(function (a, b) { return b.length - a.length; });
            tool = tool.toUpperCase();
            for (var i = 0; i < keys.length; i++) {
                if (tool.indexOf(keys[i]) >= 0) {
                    return keys[i];
                }
            }
            return '';
        }

        function submit(overwrite) {
            if (state.uploading > 0) {
                showError('圖片還在上傳中，請稍候');
                return;
            }
            var v = formValues();
            if (!v.tool_id) { showError('機台必填'); return; }
            if (!v.issue) { showError('Issue 描述必填'); return; }
            if (!v.sponsor_id) { showError('請選擇 Sponsor'); return; }
            var data = {
                id: $form.find('[name=id]').val(),
                version: $form.find('[name=version]').val(),
                sponsor_id: v.sponsor_id,
                image_ids: v.images

                data.version = state.conflictIssue.version;
                data.overwrite = 1;

                state.rows[res.issue.id] = res.issue;
                state.conflictIssue = null;
                closeEditor(true);
                render();
            }).fail(function (xhr) {
                var r = xhr.responseJSON || {};
                if (xhr.status === 409 && r.reason === 'modified' && r.issue) {
                    showConflict(r);
                } else if (xhr.status === 409) {
                    $conflict.hide();
                    window.alert(r.error || '這筆 issue 已不存在');
                    if (state.editingId) {
                        delete state.rows[state.editingId];
                    }
                    closeEditor(true);
                    render();
                } else if (xhr.status !== 401) {
                    $conflict.hide();
                    showError(errorText(xhr));
                }
            }).always(function () {
                $btn.prop('disabled', false);
            });
        }

        /** 409：列出你的版本與最新版本不同的欄位，讓使用者選覆蓋 / 載入最新 / 取消 */
        function showConflict(r) {
            state.conflictIssue = r.issue;
            state.rows[r.issue.id] = r.issue;
            render();
            var mine = formValues(), latest = issueValues(r.issue), html = '';
            $.each(FIELDS.concat(['sponsor_id', 'images']), function (i, k) {
                if (mine[k] !== latest[k]) {
                    var changedByOther = state.original && state.original[k] !== latest[k];
                    html += '<tr' + (changedByOther ? ' class="pi-diff-hot"' : '') + '><td>' + esc(FIELD_LABEL[k]) + '</td>' +
                        '<td>' + nl2br(displayValue(k, mine[k], state.editing)) + '</td>' +
                        '<td>' + nl2br(displayValue(k, latest[k], r.issue)) + '</td></tr>';
                }
            });
            if (!html) {
                html = '<tr><td colspan="3" class="dim">&gt; 內容與最新版本相同（對方可能只改了你沒改的地方又改回來）</td></tr>';
            }
            $('#pi-conflict-msg').text('⚠ ' + r.error);
            $('#pi-conflict-rows').html(html);
            $conflict.show();
        }

        function upload(file) {
            if (!/^image\/(png|jpeg|gif)$/.test(file.type)) {
                showError('只接受 PNG / JPG / GIF 圖片');
                return;
            }
            if (file.size > CFG.maxImageMb * 1048576) {
                showError('圖片超過 ' + CFG.maxImageMb + ' MB');
                return;
            }
            if (state.images.length + state.uploading >= CFG.maxImages) {
                showError('每筆 issue 最多 ' + CFG.maxImages + ' 張圖片');
                return;
            }
            var fd = new window.FormData();
            var d = new Date();
            var ext = file.type === 'image/jpeg' ? 'jpg' : file.type.split('/')[1];
            var name = file.name || ('paste_' + d.getFullYear() + pad(d.getMonth() + 1) + pad(d.getDate()) + '_' +
                pad(d.getHours()) + pad(d.getMinutes()) + pad(d.getSeconds()) + '.' + ext);
            if (file.name) {
                fd.append('image', file);
            } else {
                fd.append('image', file, name);
            }
            state.uploading++;
            renderImages();
            $.ajax({
                url: CFG.urls.upload,
                type: 'POST',
                data: fd,
                processData: false,
                contentType: false
            }).done(function (res) {
                state.images.push(res.image);
                state.dirty = true;
            }).fail(function (xhr) {
                if (xhr.status !== 401) {
                    showError(errorText(xhr, '圖片上傳失敗'));
                }
            }).always(function () {
                state.uploading--;
                renderImages();
            });
        }

        function filesFrom(list) {
            var out = [];
            for (var i = 0; list && i < list.length; i++) {
                out.push(list[i]);
            }
            return out;
        }

        // 整個編輯視窗都能貼上（含文字欄），只攔截圖片，文字照常貼上
        $(document).on('paste', function (e) {
            if (!$modal.is(':visible') || $conflict.is(':visible')) {
                return;
            }
            var cd = e.originalEvent && e.originalEvent.clipboardData;
            if (!cd || !cd.items) {
                return;
            }
            var found = false;
            for (var i = 0; i < cd.items.length; i++) {
                if (cd.items[i].kind === 'file' && /^image\//.test(cd.items[i].type)) {
                    var f = cd.items[i].getAsFile();
                    if (f) {
                        upload(f);
                        found = true;
                    }
                }
            }
            if (found) {
                e.preventDefault();
            }
        });
