# AISLE 系統架構

多功能、模組化的內部網頁系統。依「身份」(EE / PE) 決定每位使用者能看到哪些功能頁面，介面採用駭客任務 (The Matrix) 綠色終端機風格。

| 層級 | 技術 | 備註 |
|---|---|---|
| 後端 | PHP 5.4 | 不使用 5.5+ 語法；資料庫一律 PDO prepared statement |
| 資料庫 | MariaDB 5.5 / 10.x | InnoDB、utf8mb4 |
| 輔助腳本 | Python 2.7、Bash | 權限檢查、建帳號、備份、產生模組 |
| 前端 | HTML5、jQuery 1.12.4、原生 Canvas | 不需要 Node / 建置工具 |

## 2. 資料庫

`sql/schema.sql` 建立三張表：

| 資料表 | 用途 |
|---|---|
| `users` | 帳號 `account`、密碼雜湊 `password_hash`、身份 `role`、啟用狀態、失敗次數與鎖定時間、強制改密碼旗標、最後登入時間與 IP |
| `login_logs` | 每次登入嘗試（成功或失敗原因），供稽核與暴力破解追查 |
| `audit_logs` | 模組操作紀錄，例如匯出報表、建立帳號、重設密碼 |

設計重點：

- **`role` 用 VARCHAR 而非 ENUM**：新增身份只要改 `config.ini`，不必 `ALTER TABLE`。
- **`password_hash` 留 255 長度**：目前 bcrypt 固定 60 字元，保留未來更換演算法的空間。
- **`created_at` 用 DATETIME 由程式寫入**：MariaDB 5.5 一張表只能有一個 TIMESTAMP 使用 `CURRENT_TIMESTAMP`，這個位置留給 `updated_at`。
- 有索引的 VARCHAR 欄位長度 ≤ 191，避免舊版 InnoDB 在 utf8mb4 下超過 767 bytes 索引上限。

### 密碼雜湊（PHP 5.4 的做法）

`password_hash()` / `password_verify()` 是 PHP 5.5 才有的函式。`core/password_compat.php` 在函式不存在時補上同名函式：以 `crypt()` 搭配 `$2y$` bcrypt（PHP ≥ 5.3.7 支援），鹽來自 `openssl_random_pseudo_bytes`，驗證時使用常數時間比較。因此程式碼照標準 API 寫 `password_hash($pw, PASSWORD_BCRYPT)`，在 PHP 5.4 與 5.5+ 都能執行，雜湊格式也完全相同；日後升級 PHP 只要刪掉這個檔案，舊密碼不需重設。

## 3. 身份 → 頁面權限與路由（`config/config.ini` + `core/auth_check.php`）

### config.ini

```ini
[roles]
EE    = "EE 工程師"
PE    = "PE 工程師"
ADMIN = "系統管理員"

; ★ 身份 → 可用頁面清單。同一頁面同時列在 EE 與 PE 就是兩者都能看；"*" = 全部
[access]
EE    = "dashboard, shared_report, report_daily, report_weekly, ee_equipment, ee_daily_check, profile"
PE    = "dashboard, shared_report, report_daily, report_weekly, pe_recipe, pe_notice, profile"
ADMIN = "*"

; ★ 選單分類（選用）：可收折，頁面寫 group = "report" 就收在這底下
[group.report]
title = "共用報表 // REPORTS"
order = 20
open  = Off                           ; 預設收起；瀏覽器會記住使用者的展開狀態

; ★ 頁面與路由
[page.shared_report]
title = "Report1 // 綜合報表"
route = "module:shared_report"        ; modules/shared_report/controller.php
group = "report"
order = 1                             ; 分類內的排序
action.export = "PE"                  ; EE、PE 都能看，只有 PE 能匯出

[page.report_daily]
title = "Report2 // 日報"
route = "pages/report_daily.php"
group = "report"
order = 2

[page.ee_daily_check]
title = "每日點檢 // DAILY CHECK"
route = "pages/ee_daily_check.php"    ; 一般 PHP 頁面

[page.pe_notice]
title = "製程公告 // NOTICE"
route = "public/legacy/pe_notice.php" ; 既有的獨立頁面
```

選單分類只影響顯示：權限仍由 `[access]` 決定，某身份在分類裡看不到任何頁面時整個分類不會出現；目前所在頁面的分類一律展開；沒寫 `group` 的頁面照舊單層顯示。

`route` 有三種寫法：

| route | 程式位置 | 網址 | 適合 |
|---|---|---|---|
| `module:<資料夾>` | `modules/<資料夾>/controller.php` | `index.php?m=<代號>&a=<動作>` | 有多個動作、AJAX 的功能 |
| `pages/xxx.php` | `pages/xxx.php` | `index.php?m=<代號>` | 單純頁面，不用寫 Controller，自動套用版面 |
| `public/xxx.php` | `public/xxx.php` | 直接開啟該檔案 | 既有網站的舊頁面，只需在第一行加一行 require |

### auth_check.php：所有頁面共用同一套檢查

```
使用者開啟頁面
  ├─ index.php?m=xxx  →  App 路由 ──────────┐
  └─ public/legacy/xxx.php（第一行 require）─┤
                                             ▼
                              core/auth_check.php
                    1. 未登入           → 導向 login.php（AJAX 回 401）
                    2. 頁面未登記在 config.ini → 403
                    3. 首次登入未改密碼 → 導向個人設定
                    4. 身份不在 [access] 清單、或不符 action.* → 403
                                             ▼
                          通過 → 依 route 載入頁面程式
```

既有頁面接上權限只要在第一行加入（依檔案位置調整 `../`）：

```php
<?php require_once dirname(__FILE__) . '/../../core/auth_check.php';
// 通過檢查後才會執行到這裡；可用 $AUTH_USER、$AUTH_PAGE
```

auth_check.php 用「目前執行的檔案」對照 config.ini 的 route 找出頁面代號，所以頁面本身不用寫自己的代號或身份。檔案若沒登記在 config.ini，即使加了 require 也一律拒絕，避免漏設權限的頁面被看到。獨立頁面送出 POST 時會檢查 CSRF，舊表單請加上 `<?php echo csrf_field(); ?>`；若一時無法修改，可把 `[settings] direct_page_csrf` 設為 `Off`。

權限一律在伺服器端檢查，隱藏選單只是介面效果；直接輸入網址也會得到 403。目前範例的結果：

| 頁面 | EE | PE | ADMIN |
|---|:-:|:-:|:-:|
| 主控台 dashboard | ✓ | ✓ | ✓ |
| 共用報表 › Report1 shared_report | ✓（不可匯出） | ✓ | ✓ |
| 共用報表 › Report2 report_daily、Report3 report_weekly（pages/） | ✓ | ✓ | ✓ |
| 個人設定 profile | ✓ | ✓ | ✓ |
| 設備狀態 ee_equipment | ✓ | | ✓ |
| 每日點檢 ee_daily_check（pages/） | ✓ | | ✓ |
| 製程配方 pe_recipe | | ✓ | ✓ |
| 製程公告 pe_notice（獨立頁面） | | ✓ | ✓ |
| 圖表 › M1BF m1bf（module:charts） | ✓ | ✓ | ✓ |
| 使用者管理 admin_users | | | ✓ |

修改 config.ini 後執行 `python scripts/python/check_config.py`，會列出每個身份可用的頁面，並檢查拼字、route 檔案是否存在、獨立頁面有沒有 require auth_check.php。

## 4. 註冊、登入、登出與權限檢查

### 流程

| 檔案 | 方法 | 行為 |
|---|---|---|
| `public/register.php` | GET | 註冊頁 |
| | GET `?check_account=xxx`（AJAX） | 回傳帳號是否可用 |
| | POST | 驗證 → 依 EE 名單判定身份 → 寫入 `users`，並在 `audit_logs` 記錄身份來源 |
| `public/login.php` | GET / POST | 驗證帳密，成功後 `session_regenerate_id()` 並把使用者與身份寫入 `$_SESSION['user']` |
| `public/logout.php` | POST（或 `?_csrf=`） | 清除 Session 與 Cookie，導回 `login.php?bye=1` |

登入與註冊表單由 `js/auth.js` 以 jQuery 做即時驗證，並用 `$.ajax` 非同步送出，伺服器回 JSON。瀏覽器關閉 JavaScript 時表單照常以一般 POST 送出，伺服器端也會做完整驗證。

### 註冊時的身份判定（`config.ini` 的 `[register]` 與 `[ee_accounts]`）

註冊表單只填帳號、顯示名稱與密碼。身份在註冊當下依 INI 名單判定，直接寫入 `users.role`：

```ini
[register]
enabled          = On
require_approval = Off     ; On = 註冊後需管理員啟用
listed_role      = "EE"    ; 名單上的帳號
unlisted_role    = "PE"    ; 名單外的帳號；設為 "" 則名單外不能註冊

[ee_accounts]              ; EE 正面表列，一行一個帳號，不分大小寫
account[] = "neo"
account[] = "trinity"
```

- 名單只在註冊時讀取。之後增減名單，不會改變已經註冊的人的身份，要調整請直接改資料庫的 `users.role`。
- ADMIN 永遠無法經由註冊取得；`listed_role`、`unlisted_role` 若設成 superuser 角色會被忽略。
- `audit_logs` 會記錄每個帳號的身份來源（`ee_accounts` 或 `unlisted_role`）。
- 改完名單可以執行 `python scripts/python/check_config.py`，它會列出名單內容，並檢查帳號格式與重複。

### 共用權限檢查函式（`core/guard.php`）

```php
require_login();                    // 未登入 → 導向 login.php；AJAX 回 401
require_role('PE');                 // 身份不符 → 403（ADMIN 一律通過）
require_role('EE,PE');              // 多個身份用逗號
if (has_role('EE,PE')) { ... }      // 只判斷、不中止
if (can_access('shared_report', 'export')) { ... }   // 依 [access] 與 [page.xxx] 判斷
echo csrf_field();                  // 表單的 CSRF 隱藏欄位
current_user();  current_role();  is_logged_in();
```

頁面層級的權限由 `auth_check.php` 處理；這些函式用在頁面內更細的判斷，例如只對某身份顯示某個按鈕。

## 5. 新增功能頁面

只需要改 config.ini，核心程式（`core/`）不用動：

1. 放好頁面程式（擇一）：`pages/xxx.php`、`public/xxx.php`（第一行 require auth_check.php），或建立模組
2. 在 `[access]` 把頁面代號加進能使用它的身份
3. 新增 `[page.xxx]`，寫上 `title` 與 `route`
4. （選用）要放進選單分類就加上 `group = "<分類代號>"`；新分類再加一段 `[group.<分類代號>]`

例：新增一個 EE、PE 都能看的聯絡人頁面

```ini
[access]
EE = "dashboard, ..., team_contacts"
PE = "dashboard, ..., team_contacts"

[page.team_contacts]
title = "聯絡人 // CONTACTS"
route = "pages/team_contacts.php"
order = 60
```

需要多個動作或 AJAX 時用模組，腳本會產生程式骨架並自動完成上面第 2、3 步：

```bash
# 產生 modules/ee_alarm/，加入 EE、PE 的 [access] 清單並新增 [page.ee_alarm]
bash scripts/shell/new_module.sh ee_alarm "EE,PE" "警報中心 // ALARMS" 35
```

產生的骨架：

```php
<?php
class EeAlarmController extends Controller
{
    public function indexAction()          // index.php?m=ee_alarm
    {
        $this->render('index', array('message' => '...'));
    }

    public function listAction()           // index.php?m=ee_alarm&a=list
    {
        $rows = Database::fetchAll('SELECT ... WHERE x = ?', array($x));
        $this->json(array('ok' => true, 'rows' => $rows));
    }
}
```

Controller 可用的方法：`render()`、`json()`、`redirect()`、`can('動作')`、`isPost()`、`input()`、`query()`、`flash()`。View 中輸出變數一律用 `e($var)`；要放進 `<script>` 用 `js($var)`。

## 6. 安全機制

- bcrypt 密碼雜湊，提高 `bcrypt_cost` 後使用者下次登入自動升級雜湊
- 連續失敗 5 次鎖定 15 分鐘（`app.ini` 可調），帳號不存在時也執行一次 bcrypt，避免從回應時間猜出帳號
- 登入成功 `session_regenerate_id()`，閒置 30 分鐘自動登出，Cookie 設 HttpOnly
- 所有 POST（含 jQuery AJAX，透過 `X-CSRF-Token` 標頭）都檢查 CSRF token；登出也需要 token，避免被外部連結強制登出
- 註冊無法取得 ADMIN 身份；可開啟 `require_approval` 讓新帳號需管理員啟用，或把 `unlisted_role` 設為空字串只開放名單內帳號註冊
- 首次登入或被管理員重設密碼後強制改密碼
- 所有 SQL 使用 PDO prepared statement，`ATTR_EMULATE_PREPARES = false`

## 7. PHP 5.4 相容規範

可以用：`array()` 與 `[]` 短陣列、closure、`http_response_code()`、`JSON_UNESCAPED_UNICODE`、`session_status()`。

不能用：

| 不能用 | 版本 | 替代寫法 |
|---|---|---|
| `password_hash()` / `password_verify()` | 5.5 | 已由 `core/password_compat.php` 補上，可直接使用 |
| `finally`、`yield`、`::class`、`array_column()`、`empty(函式())` | 5.5 | try/catch、迴圈、字串類別名稱、先存變數 |

## 10. 圖表（charts）

多張圖表（BSLr、M1BF、CDM、BMMF…）共用同一個模組 `modules/charts`，每張圖表是選單「圖表 // CHARTS」底下的一頁。圖表使用 ECharts 5.4.3（`public/assets/vendor/` 有檔案時用本機的，否則走 jsDelivr CDN）。

每張圖表只由兩個同名檔案定義，新增圖表不需要改任何程式：

| 檔案 | 內容 |
|---|---|
| `charts/<名稱>.ini` | 畫什麼、怎麼畫：`[page]` 整頁設定、`[plot.<代號>]` 每組圖 |
| `charts/<名稱>.php` | 部署者寫 SQL，整理成資料格式（`class <名稱>Chart extends ChartSource`） |
| `config/config.ini` | `[page.<小寫名稱>]`，`route = "module:charts"`、`group = "charts"`；哪些身份看得到寫在 `[access]` |

頁面代號 = 圖表名稱轉小寫：`[page.bslr]` → `charts/BSLr.ini`、`charts/BSLr.php`，網址 `index.php?m=bslr`。

| 區塊 | 內容 |
|---|---|
| 全域選擇器 | 起訖日期（快捷按鈕由 `quick_days` 設定）、單台機台 |
| single 單台機台趨勢 | 所選機台，每組一張圖，組內每個參數一條線；X 軸時間 |
| Newest_TBT 最新值排排站 | 每組一張長條圖，X 軸機台、每個參數一根長條，取每台在區間內的最後一個值；機型篩選（`model.<機型>`）；點長條會切換上方的單台機台 |
| TBT 歷史趨勢排排站 | 每組一張圖，每台一個區段（依機台名稱排序），區段內依時間排序；圖例可開關機台，下方可拖曳縮放 |

### 新增一張圖表

```bash
bash scripts/shell/new_chart.sh CDM      # 建立 charts/CDM.ini、charts/CDM.php，並印出 config.ini 要貼的區段
```

1. 編輯 `charts/CDM.ini` 的 `[plot.xxx]`；此時 `source = sample`，用範例資料就能看到完整畫面
2. 編輯 `charts/CDM.php` 寫 `tools()`、`series()` 的 SQL，寫好把 ini 改成 `source = php`
3. 把腳本印出的 `[page.cdm]` 貼進 `config/config.ini`，並把 `cdm` 加到 `[access]` 要看得到的身份
4. `python scripts/python/check_config.py` 檢查

### 設定檔：`charts/<名稱>.ini`

```ini
[page]
```

- 每個 `[plot.<代號>]` 是一組，頁面依檔案順序畫圖；`single` / `newest` / `tbt` 省略時為 On
- 某區塊沒有任何一組開啟時，整個區塊不顯示
- 可選 `unit` 設定 Y 軸名稱（預設 `Data`）；`connect = On` 讓線跨過空值連起來（參數來自取樣時間不同的 table 時使用）
- Y 軸上下限：`ymin` / `ymax` 套用到該組三張圖；`single_ymin`、`newest_ymax`、`tbt_ymin` 等只套用到該區塊並優先；不設或留空為自動，超出範圍的資料會被裁切
- 存檔後重新整理頁面即生效；格式錯誤時頁面會顯示錯誤（`modules/charts/ChartConfig.php` 檢查）

### 資料來源：`charts/<名稱>.php`

```php
<?php
class BSLrChart extends ChartSource
{
    public function tools()
    {
        $rows = $this->fetchAll('SELECT DISTINCT tool_id FROM bslr_x_data');
        $tools = array();
        foreach ($rows as $r) {
            $tools[] = $r['tool_id'];
        }
        return $tools;
    }

    public function series($tools, $params, $start, $end)
    {
        $where = 'tool_id IN (' . $this->in($tools) . ')
                  AND data_time >= ? AND data_time < DATE_ADD(?, INTERVAL 1 DAY)';
        $bind  = array_merge($tools, array($start, $end));

        // 長表（tool_id, data_time, param, value）
        $a = self::pivot($this->fetchAll(
            'SELECT tool_id, DATE_FORMAT(data_time, \'%Y-%m-%d %H:%i:%s\') AS d, param, value
               FROM bslr_x_data WHERE ' . $where, $bind), 'tool_id', 'd', 'param', 'value');

        // 寬表，欄位 c1 / c2 對應參數 BSLr_Y_C1 / BSLr_Y_C2
        $b = self::wide($this->fetchAll(
            'SELECT tool_id, DATE_FORMAT(data_time, \'%Y-%m-%d %H:%i:%s\') AS d, c1, c2
               FROM bslr_y_summary WHERE ' . $where, $bind),
            'tool_id', 'd', array('BSLr_Y_C1' => 'c1', 'BSLr_Y_C2' => 'c2'));

        return self::merge($a, $b);   // 不同 table 的結果依機台 + 時間合併
    }
}
```

| 工具（`modules/charts/ChartSource.php`） | 用途 |
|---|---|
| `$this->fetchAll($sql, $bind)` | prepared statement 查詢，值一律用 `?` 綁定 |
| `$this->in($list)` | 產生 `IN (...)` 用的 `?,?,?` |
| `self::pivot($rows, 機台欄, 時間欄, 參數欄, 值欄)` | 長表（一列一個參數值）→ 資料格式 |
| `self::wide($rows, 機台欄, 時間欄, 參數 => 欄位)` | 寬表（每個參數一個欄位）→ 資料格式 |
| `self::merge($a, $b, ...)` | 多個 table 的結果合併，對不到的位置補 null |

資料庫連線在 `config/app.ini` 的 `[charts_db]`（host / port / name / user / password，所有圖表共用）；`host` 留空時使用 AISLE 自己的 `[database]`。

### 資料格式與載入

後端 `index.php?m=<頁面代號>&a=tbt&start=&end=` 回傳區間內全部機台、ini 用到的全部參數：

```json
{
  "APAN01": { "Date": ["2026-01-01", "2026-01-02"],
              "Data": { "M1BF_Z_C1": [1.0, 2.0], "M1BF_Z_C2": [1.1, 2.1], "M1BF_Ry_C1": [1.0, 2.0], "M1BF_Ry_C2": [1.1, 2.1] } }
}
```

- 每個參數陣列與 `Date` 等長，沒有值的位置是 `null`；排序、型別、補 null、只留 ini 用到的參數由 controller 統一處理，`<名稱>.php` 不需要先排好
- 進入頁面時只呼叫一次，所有圖都從這份資料取得。切換機台、切換機型只在瀏覽器端重畫，不再向後端要資料；只有改日期區間（查詢 / 快速區間）才重新取
- 編碼：**顏色 = 機台**（同機型內依序取色，跟著機台走，篩選後不變）、**線型 / 長條紋理 = 參數**（組內第 1 個參數實線，第 2 個虛線、斜線紋理…）
- 每張圖都有「資料表」按鈕可切換成表格檢視
- 錯誤處理：設定錯誤直接顯示在頁面上；資料庫 / SQL 錯誤只在 `debug = 1` 時顯示內容，否則寫到 PHP error log

# AISLE 部署步驟

以下指令以實際環境為例：

| 項目 | 值 |
|---|---|
| 程式來源 | GitHub `bboysevenwu/AISLE` 的 `main` branch |
| 部署位置 | `/var/www/html/aisle/`（Apache DocumentRoot 為 `/var/www/html`） |
| 對外網址 | `http://sccproxyauth-a-dc1-38.scc.f18.tsmc.com/D1C1/aisle/`（proxy 前綴 `/D1C1/`） |
| Web Server 執行身份 | `apache`（Debian/Ubuntu 為 `www-data`） |

網址的對應關係：

```
瀏覽器  http://sccproxyauth-a-dc1-38.scc.f18.tsmc.com/D1C1/aisle/login.php
  │ proxy 去掉 /D1C1 前綴後轉給主機
主機    http://<主機>/aisle/login.php
  │ /var/www/html/aisle/.htaccess 在內部轉進 public/
檔案    /var/www/html/aisle/public/login.php
```

網址不會出現 `public/`；`config/`、`core/` 等目錄經由網址存取一律 404。

## 1. 確認主機環境

| 項目 | 需求 | 確認指令 |
|---|---|---|
| PHP | 5.4（至少 5.3.7，bcrypt 需要） | `php -v` |
| PHP 擴充 | `pdo_mysql`、`openssl`、`json`、`session` | `php -m` |
| MariaDB | 5.5 以上（utf8mb4 需 5.5.3+） | `mysql --version` |
| MariaDB 用戶端 | `mysql`、`mysqldump`（建帳號、備份腳本用） | `which mysql mysqldump` |
| Apache | 2.2 或 2.4，需要 `mod_rewrite`；`mod_headers` 選用 | `httpd -v`、`httpd -M` |
| Python | 2.7（設定檢查腳本） | `python -V` |
| 其他 | `bash`、`curl` 或可從外網複製檔案 | |

`php.ini` 確認：`date.timezone` 有設定、`session.save_path` 目錄可寫入、正式環境 `display_errors = Off`。

## 2. 放置程式

```bash
cd /var/www/html
git clone -b main https://github.com/bboysevenwu/AISLE.git aisle
cd /var/www/html/aisle
```

主機不能連 GitHub 時，在其他電腦 clone 或下載 ZIP 後整包複製到 `/var/www/html/aisle/`。腳本在 git 裡已設為可執行，若是用 ZIP 複製則補一行 `chmod +x scripts/shell/*.sh scripts/python/*.py`。

之後更新程式：

```bash
cd /var/www/html/aisle && git pull origin main
```

`config/app.ini` 不在版控內，`git pull` 不會覆蓋它。

主機不能 `git pull`、也不能下載壓縮檔時，改用單檔更新，見第 18 步。

## 3. 建立資料庫與資料表

```bash
mysql -u root -p < sql/schema.sql
```

建立 `aisle` 資料庫與 `users`、`login_logs`、`audit_logs` 三張表。MariaDB 低於 5.5.3 時，先把 schema.sql 裡的 `utf8mb4` 全部改成 `utf8`。

## 4. 建立應用程式專用的資料庫帳號

不要讓網站使用 root。以 root 登入 MariaDB 後執行（密碼自訂）：

```sql
CREATE USER 'aisle_app'@'localhost' IDENTIFIED BY '強密碼';
GRANT SELECT, INSERT, UPDATE, DELETE ON `aisle`.* TO 'aisle_app'@'localhost';
FLUSH PRIVILEGES;
```

## 5. 匯入初始管理員

```bash
mysql -u root -p < sql/seed.sql
```

建立帳號 `admin`，密碼 `Neo@Zion2026`（第 13 步首次登入時會被要求修改）。

```bash
cp config/app.ini.example config/app.ini
vi config/app.ini
```

| 區段 | 項目 | 填寫 |

## 11. 設定 Apache

程式放在 `/var/www/html/aisle/`，靠專案根目錄的 `.htaccess` 把請求轉進 `public/`，所以需要：

1. 開啟 `mod_rewrite`：
   ```bash
   httpd -M | grep rewrite        # Debian/Ubuntu：a2enmod rewrite
   ```
2. 允許 `/var/www/html/aisle` 使用 `.htaccess`（寫在 `httpd.conf` 或 `conf.d/aisle.conf`）：
   ```apache
   <Directory /var/www/html/aisle>
       AllowOverride All
   </Directory>
   ```
3. 套用設定：
   ```bash
   apachectl configtest && apachectl graceful
   ```

沒有 `mod_rewrite` 時，根目錄 `.htaccess` 會拒絕整個 `/aisle/`（避免設定檔外洩），網站會是 403。

> 另一種做法：若可以為 AISLE 開一個獨立的 VirtualHost，可把 `DocumentRoot` 直接指向 `/var/www/html/aisle/public`，此時根目錄 `.htaccess` 不會被讀到，`base_url` 依對外路徑調整。

## 18. 不能 git pull 時的更新方式（單檔更新）

公司內只能開 GitHub 網頁複製文字時使用。每次更新會在 repo 的 `updates/` 放一個純文字更新檔，裡面包含這次新增、修改、刪除的所有檔案；在主機上貼成一個檔案，執行一次 `apply_update.py` 就全部更新完。

### 18-1. 第一次：把 apply_update.py 放到主機上

在 GitHub 打開 `scripts/python/apply_update.py`，按 **Raw**，全選複製，然後在主機上：

```bash
cd /var/www/html/aisle
cat > scripts/python/apply_update.py     # 貼上內容，最後按 Enter 再按 Ctrl-D
chmod +x scripts/python/apply_update.py
python scripts/python/apply_update.py -h # 出現用法說明即可
```

之後的更新檔若包含新版的 `apply_update.py`，會自動一起更新，不需要再手動複製。

### 18-2. 每次更新

1. 在 GitHub 打開 `updates/` 底下這次的更新檔（例 `update_20261104_7d8729a_xxxxxxx.txt`），按 **Raw**，`Ctrl-A` 全選、`Ctrl-C` 複製
2. 貼到主機上，放在網站目錄以外（例 `~/`）：
   ```bash
   cat > ~/update.txt     # 貼上，最後按 Enter 再按 Ctrl-D
   ```
   用 `vi` 貼上時，先輸入 `:set paste` 再進入插入模式，否則 vi 會自動加縮排，內容會對不上
3. 先預覽（不會改任何檔案）：
   ```bash
   cd /var/www/html/aisle
   python scripts/python/apply_update.py ~/update.txt
   ```
   會列出每個檔案是 `[新增]`、`[覆蓋]`、`[刪除]` 還是 `[相同]`，以及備份檔名
4. 確認後實際套用：
   ```bash
   python scripts/python/apply_update.py ~/update.txt --apply
   ```
5. 新增了 config.ini 的頁面時，照第 8 步執行 `check_config.py`

### 腳本會做的檢查

| 狀況 | 結果 |
|---|---|
| 複製時漏了一段、貼了兩次、更新檔被截斷 | 每個檔案都有 sha1，結尾有項目數；任何一個對不上就整批不寫入 |
| vi 自動縮排、Windows 換行（CRLF）、UTF-8 BOM | 換行與 BOM 會自動處理；縮排被改會被 sha1 擋下 |
| 主機上的檔案被直接改過（和更新前的版本不同） | 列為「衝突」並停止。確認可以覆蓋後加 `--force`（仍會先備份） |
| 寫入到一半失敗（權限不足等） | 自動把已經改過的檔案還原 |
| 同一個更新檔執行兩次 | 第二次全部顯示 `[相同]`，不會再改 |

### 備份與還原

- 被覆蓋的檔案先複製一份在原位置，檔名後面加上 `_<日期>_<時間>`，例 `core/Auth.php_20261104_204500`；被刪除的檔案改名成同樣格式，不會真的刪掉
- 同一次執行共用同一個時間，紀錄寫在 `storage/logs/update_<時間>.json`
- 根目錄與 `public/` 的 `.htaccess` 會擋掉這種備份檔名（403），避免舊版程式碼被當純文字下載
- 查看紀錄與主機目前的版本：
  ```bash
  python scripts/python/apply_update.py --list
  ```
- 還原某次更新（先預覽，再加 `--apply`；`last` 代表最近一次）：
  ```bash
  python scripts/python/apply_update.py --rollback 20261104_204500
  python scripts/python/apply_update.py --rollback 20261104_204500 --apply
  ```
  還原會把備份檔改回原檔名，並移除那次新增的檔案
- 備份檔確認不需要後可以手動刪除，例 `find . -name '*_20261104_204500' -delete`

### 產生更新檔（開發端）

在有 git 的電腦上，指定主機目前的版本（`--list` 最後一筆的「版本 → 」右邊，或部署時的 commit）：

```bash
python scripts/python/make_update.py 7d8729a HEAD --note "這次更新的說明"
```

輸出到 `updates/update_<日期>_<舊>_<新>.txt`，commit 後即可在 GitHub 打開。預設不打包 `updates/` 與 `docs/screenshots/`；圖片等非文字檔會用 base64 存放。主機版本不明時可用 `--all` 打包全部檔案（不檢查衝突）。`config/app.ini` 不在 git 裡，不會被更新檔覆蓋。
#@@@ DELETE modules/chart_demo/ChartConfig.php base=068fa3ad8342e17594dc287a33a1d0c2afa1d944
#@@@ DELETE modules/chart_demo/ChartDataSource.php base=5e39507df2476becbd0f8ab2195f4ea7ab522c3a
#@@@ DELETE modules/chart_demo/controller.php base=10b686b1a1fda31e6b39632f0727db074c19429f
#@@@ DELETE modules/chart_demo/views/index.php base=159e69ed7f95f2d5cef3db05f462e63c8740558a
#@@@ FILE modules/charts/ChartConfig.php sha1=5bf46eb9b47f33da2dd9502606e1f9893d94b5d8 base=- mode=644 enc=text nl=1
<?php
/**
 * 讀取一張 chart 的設定檔 charts/<名稱>.ini
 *
 * 每張 chart（BSLr、M1BF、CDM…）在 charts/ 底下有兩個同名檔案：
 *   charts/<名稱>.ini   畫什麼、怎麼畫（本類別讀取）
 *   charts/<名稱>.php   部署者寫 SQL、整理成資料格式（見 ChartSource.php）
 *
 * config/config.ini 的頁面代號 = chart 名稱轉小寫：[page.bslr] → charts/BSLr.ini
 * 以 _ 開頭的檔案（_template.ini）是範本，不會被當成 chart。
 *
 * ini 格式：
 *   [page]          整頁設定：source、default_days、max_days、quick_days、model.<機型> = "<機台名稱包含的字>"
 *   [plot.<代號>]   一組圖：title、params、unit、single / newest / tbt、connect、ymin / ymax、<區塊>_ymin / <區塊>_ymax
 *
 * $cfg->plots() 回傳（依檔案順序）：
 *   array(
 *     array('id' => 'm1bf_z', 'title' => 'M1BF_Z', 'params' => array('M1BF_Z_C1', 'M1BF_Z_C2'),
 *           'unit' => 'Data', 'single' => true, 'newest' => true, 'tbt' => true, 'connect' => false,
 *           'limits' => array('single' => array('min' => 0, 'max' => 5), 'newest' => array(...), 'tbt' => array(...))),
 *     ...
 *   )
 *   min / max 為 null 表示自動
 */
class ChartConfig
{
    const NAME_PATTERN = '/^[A-Za-z][A-Za-z0-9_]{0,31}$/';

    /** chart 名稱，例 BSLr */
    public $name;
    /** charts/<名稱>.ini 的完整路徑 */
    public $file;

    private $page = array();
    private $plots = array();
    private $models = array();

    public static function dir()
    {
        return AISLE_ROOT . '/charts';
    }

    /** charts/ 底下所有 chart 名稱（不含 _ 開頭的範本） */
    public static function names()
    {
        $names = array();
        $files = glob(self::dir() . '/*.ini');
        foreach ($files ? $files : array() as $f) {
            $name = basename($f, '.ini');
            if (preg_match(self::NAME_PATTERN, $name)) {
                $names[] = $name;
            }
        }
        sort($names);
        return $names;
    }

    /** 頁面代號 → chart 名稱（不分大小寫比對檔名），找不到回傳 null */
    public static function nameForPage($pageKey)
    {
        foreach (self::names() as $name) {
            if (strtolower($name) === strtolower($pageKey)) {
                return $name;
            }
        }
        return null;
    }

    public function __construct($name)
    {
        if (!preg_match(self::NAME_PATTERN, $name)) {
            throw new RuntimeException('chart 名稱格式錯誤：' . $name);
        }
        $this->name = $name;
        $this->file = self::dir() . '/' . $name . '.ini';
        $label = 'charts/' . $name . '.ini';
        if (!is_file($this->file)) {
            throw new RuntimeException('找不到 ' . $label);
        }
        $ini = parse_ini_file($this->file, true);
        if ($ini === false) {
            throw new RuntimeException($label . ' 解析失敗，請檢查引號與語法');
        }

        foreach ($ini as $section => $conf) {
            if ($section === 'page') {
                $this->page = $conf;
                continue;
            }
            if (!preg_match('/^plot\.([a-z][a-z0-9_]{0,63})$/', $section, $m)) {
                throw new RuntimeException($label . ' 區段名稱錯誤：[' . $section . ']，應為 [page] 或 [plot.<小寫代號>]');
            }
            $this->plots[] = $this->plot($m[1], $conf, $label, $section);
        }
        if (!$this->plots) {
            throw new RuntimeException($label . ' 沒有任何 [plot.xxx] 圖');
        }

        foreach ($this->page as $k => $v) {
            if (strpos($k, 'model.') === 0 && substr($k, 6) !== '' && trim((string) $v) !== '') {
                $this->models[substr($k, 6)] = trim((string) $v);
            }
        }

        $this->checkPage($label);
    }

    // ------------------------------------------------------------------
    // [page]

    /** php = 用 charts/<名稱>.php 查資料庫；sample = 內建範例資料 */
    public function source()
    {
        $v = strtolower(trim((string) array_get($this->page, 'source', 'php')));
        return $v === 'sample' ? 'sample' : 'php';
    }

    public function defaultDays()
    {
        return (int) array_get($this->page, 'default_days', 60);
    }

    public function maxDays()
    {
        return (int) array_get($this->page, 'max_days', 366);
    }

    /** 快速區間按鈕的天數 */
    public function quickDays()
    {
        $out = array();
        foreach (explode(',', (string) array_get($this->page, 'quick_days', '7, 30, 90')) as $d) {
            $d = (int) trim($d);
            if ($d > 0) {
                $out[] = $d;
            }
        }
        return $out;
    }

    /** 機型 => 機台名稱包含的字，例 array('1980' => 'PAN', '2000' => 'PAP')；沒設定時為空陣列 */
    public function models()
    {
        return $this->models;
    }

    /** 機台屬於哪個機型：依 [page] 的順序，名稱包含該字（不分大小寫）的第一個機型；都不符合回傳 '' */
    public function modelOf($tool)
    {
        foreach ($this->models as $model => $needle) {
            if (stripos($tool, $needle) !== false) {
                return (string) $model;
            }
        }
        return '';
    }

    // ------------------------------------------------------------------
    // [plot.xxx]

    public function plots()
    {
        return $this->plots;
    }

    /** 所有圖用到的參數（不重複，依出現順序） */
    public function params()
    {
        $out = array();
        foreach ($this->plots as $g) {
            foreach ($g['params'] as $p) {
                if (!in_array($p, $out, true)) {
                    $out[] = $p;
                }
            }
        }
        return $out;
    }

    // ------------------------------------------------------------------

    private function checkPage($label)
    {
        $source = strtolower(trim((string) array_get($this->page, 'source', 'php')));
        if (!in_array($source, array('php', 'sample'), true)) {
            throw new RuntimeException($label . ' [page] source 只能是 php 或 sample');
        }
        foreach (array('default_days', 'max_days') as $k) {
            if (array_key_exists($k, $this->page) && (!ctype_digit(trim((string) $this->page[$k])) || (int) $this->page[$k] < 1)) {
                throw new RuntimeException($label . ' [page] ' . $k . ' 必須是正整數');

    private static function limits($conf, $kind, $label, $section)
    {

            $v = null;
            foreach (array($kind . '_y' . $k, 'y' . $k) as $key) {
                if (array_key_exists($key, $conf) && trim((string) $conf[$key]) !== '') {
                    $raw = trim((string) $conf[$key]);

                        throw new RuntimeException($label . ' [' . $section . '] ' . $key . ' 必須是數字：' . $raw);
                    }
                    $v = (float) $raw;
                    break;
                }
            }
            $out[$k] = $v;
        }
        if ($out['min'] !== null && $out['max'] !== null && $out['min'] >= $out['max']) {
            throw new RuntimeException($label . ' [' . $section . '] ' . $kind . ' 的 Y 軸下限必須小於上限');
        }
        return $out;
    }

    /** On / Off；未設定時為 $default。parse_ini_file 會把 On 轉成 "1"、Off 轉成 "" */
    private static function flag($conf, $key, $default = true)
    {

            return $default;
        }
        $v = strtolower(trim((string) $conf[$key]));
        return !($v === '' || $v === '0' || $v === 'off' || $v === 'false' || $v === 'no');
    }

    public static function pivot($rows, $toolCol, $dateCol, $paramCol, $valueCol)
    {

        $params = array();  // tool => param => true
        foreach ($rows as $r) {

class SampleChartSource extends ChartSource

    public function series($tools, $params, $start, $end)
    {
        $out = array();
        $from = strtotime($start);
        $to = strtotime($end);
        foreach ($tools as $tool) {
            $series = array('Date' => array(), 'Data' => array());
            foreach ($params as $p) {
                $series['Data'][$p] = array();
            }
            for ($t = $from; $t <= $to; $t += 86400) {
                $day = date('Y-m-d', $t);
                if (self::value($tool, '', $day) === null) {
                    continue; // 這天停機
                }
                $series['Date'][] = $day;
                foreach ($params as $p) {
                    $series['Data'][$p][] = self::value($tool, $p, $day);
                }
            }
            $out[$tool] = $series;
        }
        return $out;
    }

    /**
     * 每台、每個參數有自己的基準值與週期；約 1/9 的日子整台沒有資料（模擬停機）
     * $param = '' 時只用來判斷這天是否停機
     */
    private static function value($tool, $param, $day)
    {
        if ($param === '') {
            return abs(crc32($tool . '|' . $day)) % 9 === 0 ? null : 0;
        }
        $h = abs(crc32($tool . '|' . $param . '|' . $day));
        $seed = abs(crc32($tool));
        // 同一台的參數走勢相近，各參數再加一點固定偏移
        $base = 1.2 + ($seed % 300) / 100 + (abs(crc32($param)) % 60) / 100 - 0.3;
        $n = floor(strtotime($day) / 86400);               // 絕對天數
        $wave = 0.6 * sin($n / (5 + $seed % 7) + $seed % 10);
        $noise = (($h % 1000) / 1000 - 0.5) * 0.5;
        return round(max(0, $base + $wave + $noise), 3);
    }

     *   - 每台依 Date 排序；Data 只保留 $params，依 $params 的順序輸出，缺少的參數整列補 null
     *   - 數值轉成數字，不是數字的轉成 null；所有參數都是 null 的時間點丟掉
     */
    private function normalize($data, $tools, $params)
    {
        $out = array();
        foreach ($tools as $tool) {
            if (!isset($data[$tool]['Date'], $data[$tool]['Data'])
                || !is_array($data[$tool]['Date']) || !is_array($data[$tool]['Data'])) {
                continue;

            $dates = array_values($data[$tool]['Date']);
            $cols = array();
            foreach ($params as $p) {
                $cols[$p] = isset($data[$tool]['Data'][$p]) && is_array($data[$tool]['Data'][$p])
                    ? array_values($data[$tool]['Data'][$p]) : array();
            }
            $rows = array();  // array(date, array(param => value))
            foreach ($dates as $i => $date) {
                $values = array();
                $any = false;
                foreach ($params as $p) {
                    $v = null;
                    if (isset($cols[$p][$i]) && is_numeric($cols[$p][$i])) {
                        $v = (float) $cols[$p][$i];
                        $any = true;
                    }
                    $values[$p] = $v;
                }
                if ($any) {
                    $rows[] = array((string) $date, $values);
                }
            }
            if (!$rows) {
                continue;
            }
            usort($rows, array('ChartsController', 'cmpRow'));
            $series = array('Date' => array(), 'Data' => array());
            foreach ($params as $p) {
                $series['Data'][$p] = array();
            }
            foreach ($rows as $r) {
                $series['Date'][] = $r[0];
                foreach ($params as $p) {
                    $series['Data'][$p][] = $r[1][$p];
                }
            }
            $out[$tool] = $series;
        }
        return $out;

/*
 * charts 頁面 (jQuery 1.12 + ECharts 5)，所有 chart（BSLr、M1BF…）共用
 *
 * 三個區塊：single 單台趨勢 / newest 最新值排排站 / tbt 歷史趨勢排排站
 * 每個區塊依 charts/<名稱>.ini 的 [plot.xxx] 各畫一張圖（CFG.groups），
 * 同一組的參數（例 M1BF_Z_C1、M1BF_Z_C2）畫在同一張圖上。
 *
 * 後端回傳格式：
 *   { "APAN01": { "Date": [...], "Data": { "M1BF_Z_C1": [...], "M1BF_Z_C2": [...] } }, ... }
 *   每個參數陣列與 Date 等長，沒有值的位置是 null
 *
 * 資料載入方式：
 *   進入頁面時只呼叫一次 tbt，取回日期區間內「全部機台、全部參數」的資料存在 cache，所有圖都從這份資料取得：
 *     TBT 直接畫；single 取出所選機台；Newest_TBT 取每台每個參數在區間內的最後一個值（再依機型篩選）
 *   之後切換機台、切換機型只用 cache 重畫，不再發 request；
 *   只有改日期區間（查詢 / 快速區間）才會重新取 tbt。
 *
 * 編碼方式：顏色 = 機台，線型 / 長條紋理 = 參數（同組第 1 個參數實線無紋理，第 2 個虛線斜紋…）
 * 只用 ES5 語法，避免舊瀏覽器出錯
 */
(function ($, window) {
    'use strict';

    var CFG = window.AISLE_CHARTS;
    if (!$ || !CFG) {
        return;
    }

    // ---------- 主題 ----------
    // 機台顏色：8 色類別色盤（已用 dataviz validate_palette.js 檢查深色底 #001406：
    // 亮度、彩度、色盲區分、對比全部通過）。同機型內依序取色，APAN01 與 APAP01 同色，
    // 以 X 軸機台名稱區分。顏色跟著機台走，篩選後不會變色。
    var PALETTE = ['#3987e5', '#d95926', '#199e70', '#c98500', '#d55181', '#008300', '#9085e9', '#e66767'];
    // 參數：線型與長條紋理，依參數在組內的順序取用
    var LINE_TYPES = ['solid', 'dashed', 'dotted', [10, 4, 2, 4], [2, 6]];
    var LINE_NAMES = ['實線', '虛線', '點線', '點劃線', '稀點線'];
    var DECALS = [
        null,
        { symbol: 'rect', symbolSize: 1, dashArrayX: [1, 0], dashArrayY: [2, 4], rotation: Math.PI / 4, color: 'rgba(0,0,0,0.5)' },
        { symbol: 'circle', symbolSize: 0.6, dashArrayX: [[4, 4]], dashArrayY: [4, 0], color: 'rgba(0,0,0,0.5)' },
        { symbol: 'rect', symbolSize: 1, dashArrayX: [1, 0], dashArrayY: [2, 4], rotation: -Math.PI / 4, color: 'rgba(0,0,0,0.5)' },
        { symbol: 'rect', symbolSize: 1, dashArrayX: [1, 0], dashArrayY: [1, 3], rotation: 0, color: 'rgba(0,0,0,0.5)' }
    ];
    var INK = '#00ff41';       // 主要文字
    var INK_DIM = '#00b82e';   // 次要文字
    var GRID = '#0a2a12';      // 格線
    var AXIS = '#00661a';      // 軸線
    var NEUTRAL = '#7dffb0';   // 圖例中代表「參數」的中性色
    var BAND = 'rgba(0, 255, 65, 0.05)';  // TBT 交錯底色
    var FONT = '"Share Tech Mono", Consolas, "Courier New", "Microsoft JhengHei", monospace';

    var COLOR = {};
    (function assignColors() {
        var counter = {};
        $.each(CFG.tools, function (i, tool) {
            var model = CFG.models[tool] || '';
            counter[model] = counter[model] || 0;
            COLOR[tool] = PALETTE[counter[model] % PALETTE.length];
            counter[model]++;
        });
    })();

    var GROUPS = {};
    $.each(CFG.groups, function (i, g) { GROUPS[g.id] = g; });

    function colorOf(tool) { return COLOR[tool] || NEUTRAL; }
    function lineTypeOf(i) { return LINE_TYPES[i % LINE_TYPES.length]; }
    function decalOf(i) { return DECALS[i % DECALS.length]; }
    function shortName(param, group) {
        // 圖例只顯示參數名稱與組標題不同的部分，例 M1BF_Z 組內的 M1BF_Z_C1 → C1
        var prefix = group.title + '_';
        return param.indexOf(prefix) === 0 && param.length > prefix.length ? param.substring(prefix.length) : param;
    }

    function baseOption() {
        return {
            backgroundColor: 'transparent',
            textStyle: { color: INK, fontFamily: FONT },
            animationDuration: 400,
            tooltip: {
                backgroundColor: 'rgba(0, 10, 3, 0.95)',
                borderColor: INK_DIM,
                borderWidth: 1,
                textStyle: { color: INK, fontFamily: FONT, fontSize: 13 },
                extraCssText: 'box-shadow: 0 0 12px rgba(0,255,65,0.3);'
            },
            grid: { left: 50, right: 24, top: 40, bottom: 40, containLabel: false }
        };
    }

    /** Y 軸；config 有設上下限就固定，否則自動。kind = single / newest / tbt */
    function valueAxis(group, kind) {
        var lim = (group.limits && group.limits[kind]) || {};
        var axis = {
            type: 'value',
            name: group.unit || 'Data',
            nameTextStyle: { color: INK_DIM },
            axisLine: { show: false },
            axisTick: { show: false },
            axisLabel: { color: INK_DIM },
            splitLine: { lineStyle: { color: GRID } },
            scale: kind !== 'newest'
        };
        if (lim.min !== null && lim.min !== undefined) {
            axis.min = lim.min;
        }
        if (lim.max !== null && lim.max !== undefined) {
            axis.max = lim.max;
        }
        return axis;
    }

    function axisLine() {
        return { lineStyle: { color: AXIS } };
    }

    function legendBase(data) {
        return {
            type: 'scroll',
            top: 0,
            data: data,
            textStyle: { color: INK, fontFamily: FONT },
            pageTextStyle: { color: INK },
            pageIconColor: INK,
            pageIconInactiveColor: AXIS,
            inactiveColor: '#1f4a2a',
            itemWidth: 26,
            itemHeight: 10
        };
    }

    function fmt(v) {
        return v === null || v === undefined ? '-' : AISLE.escape(v);
    }

    // ---------- 圖表盒 ----------
    // boxes['tbt:m1bf_z'] = { kind, group, $el, chart, shown }
    var boxes = {};
    var cache = { tbt: null };
    var request = null;

    function eachBox(kind, fn) {
        $.each(boxes, function (key, box) {
            if (!kind || box.kind === kind) {
                fn(box);
            }
        });
    }

    function showMessage(chart, text) {
        chart.clear();
        chart.setOption({
            title: {
                text: text,
                left: 'center',
                top: 'middle',
                textStyle: { color: INK_DIM, fontSize: 14, fontWeight: 'normal', fontFamily: FONT }
            }
        });
    }

    function loadingOpts() {
        return { text: 'LOADING...', color: INK, textColor: INK, maskColor: 'rgba(0, 0, 0, 0.6)', fontFamily: FONT };
    }

    /** 把資料畫到圖表盒；沒有資料時顯示 NO DATA，並更新資料表 */
    function show(box, data, draw) {
        box.shown = data;
        if ($.isEmptyObject(data)) {
            showMessage(box.chart, '> 查無資料 // NO DATA');
        } else {
            draw(box, data);
        }
        renderTable(box);
    }

    /** 資料表檢視：機台 / 時間 / 該組每個參數一欄 */
    function renderTable(box) {
        var params = box.group.params;
        var head = '<tr><th>TOOL</th><th>DATE</th>';
        $.each(params, function (i, p) { head += '<th>' + AISLE.escape(p) + '</th>'; });
        head += '</tr>';
        var rows = [];
        $.each(box.shown, function (tool, s) {
            if (!$.isArray(s.Date)) {
                // newest：各參數的日期分開存，值後面附上日期
                var tr0 = '<tr><td>' + AISLE.escape(tool) + '</td><td>LATEST</td>';
                $.each(params, function (j, p) {
                    tr0 += '<td>' + fmt(s.Data[p][0]) + (s.Date[p][0] ? ' <span class="dim">(' + AISLE.escape(s.Date[p][0]) + ')</span>' : '') + '</td>';
                });
                rows.push(tr0 + '</tr>');
                return;
            }
            for (var i = 0; i < s.Date.length; i++) {
                var tr = '<tr><td>' + AISLE.escape(tool) + '</td><td>' + AISLE.escape(s.Date[i]) + '</td>';
                for (var j = 0; j < params.length; j++) {
                    tr += '<td>' + fmt(s.Data[params[j]] ? s.Data[params[j]][i] : null) + '</td>';
                }
                rows.push(tr + '</tr>');
            }
        });
        box.$el.find('.cd-table').html(rows.length
            ? '<table class="table"><thead>' + head + '</thead><tbody>' + rows.join('') + '</tbody></table>'
            : '<p class="dim">&gt; 查無資料</p>');
    }

    // ---------- 1. single：所選機台，組內每個參數一條線 ----------
    function drawSingle(box, data) {
        var group = box.group;
        var tool;
        for (tool in data) {
            if (data.hasOwnProperty(tool)) {
                break;
            }
        }
        var s = data[tool];
        var series = [];
        $.each(group.params, function (pi, param) {
            var points = [];
            var col = s.Data[param] || [];
            for (var i = 0; i < s.Date.length; i++) {
                points.push([s.Date[i], col[i] === undefined ? null : col[i]]);
            }
            series.push({
                name: param,
                type: 'line',
                data: points,
                connectNulls: !!group.connect,   // ini 的 connect = On：跳過空值把線連起來
                showSymbol: points.length <= 45,
                symbolSize: 8,
                color: colorOf(tool),
                lineStyle: { width: 2, type: lineTypeOf(pi) },
                emphasis: { focus: 'series' }
            });
        });
        var opt = baseOption();
        opt.legend = legendBase(group.params.slice(0));
        opt.legend.formatter = function (name) { return shortName(name, group); };
        opt.tooltip.trigger = 'axis';
        opt.tooltip.axisPointer = { type: 'line', lineStyle: { color: INK_DIM, type: 'dashed' } };
        opt.xAxis = {
            type: 'time',
            axisLine: axisLine(),
            axisLabel: { color: INK_DIM, hideOverlap: true, formatter: '{MM}-{dd}' },
            splitLine: { show: false }
        };
        opt.yAxis = valueAxis(group, 'single');
        opt.dataZoom = [{ type: 'inside' }];
        opt.series = series;
        box.chart.clear();
        box.chart.setOption(opt);
    }

    // ---------- 2. newest：X 軸機台，組內每個參數一根長條 ----------
    function drawNewest(box, data) {
        var group = box.group;
        var tools = [];
        $.each(data, function (tool) { tools.push(tool); });
        var series = [];
        $.each(group.params, function (pi, param) {
            var bars = [];
            $.each(tools, function (ti, tool) {
                var s = data[tool];
                var style = { color: colorOf(tool), borderRadius: [4, 4, 0, 0] };
                if (decalOf(pi)) {
                    style.decal = decalOf(pi);
                }
                bars.push({ value: s.Data[param][0], date: s.Date[param][0], itemStyle: style });
            });
            // series 的 itemStyle 只決定圖例的樣子（中性色 + 該參數的紋理），每根長條另用機台色
            var legendStyle = { color: NEUTRAL };
            if (decalOf(pi)) {
                legendStyle.decal = decalOf(pi);
            }
            series.push({
                name: param,
                type: 'bar',
                data: bars,
                barMaxWidth: 28,
                barGap: '15%',
                itemStyle: legendStyle,
                emphasis: { focus: 'series', itemStyle: { shadowBlur: 12, shadowColor: INK } },
                cursor: 'pointer'
            });
        });
        var opt = baseOption();
        opt.legend = legendBase(group.params.slice(0));
        opt.legend.formatter = function (name) { return shortName(name, group); };
        opt.tooltip.trigger = 'axis';
        opt.tooltip.axisPointer = { type: 'shadow', shadowStyle: { color: 'rgba(0,255,65,0.06)' } };
        opt.tooltip.formatter = function (params) {
            if (!params.length) {
                return '';
            }
            var html = '<b>' + AISLE.escape(params[0].name) + '</b>';
            $.each(params, function (i, p) {
                html += '<br>' + p.marker + AISLE.escape(p.seriesName) + '：<b>' + fmt(p.value) + '</b>' +
                    ' <span style="color:' + INK_DIM + '">(' + fmt(p.data.date) + ')</span>';
            });
            return html;
        };
        opt.xAxis = {
            type: 'category',
            data: tools,
            axisLine: axisLine(),
            axisTick: { show: false },
            axisLabel: { color: INK, interval: 0, rotate: tools.length > 14 ? 45 : 0 }
        };
        opt.yAxis = valueAxis(group, 'newest');
        opt.series = series;
        box.chart.clear();
        box.chart.setOption(opt);
    }

    // ---------- 3. TBT ----------
    // X 軸為類別軸：每台機台佔一段，段內依時間排列。每台每個參數一條 series，
    // 同一台的 series 用同一個名稱，所以圖例以機台為單位開關；其他段落填 null，
    // 所以每台只畫在自己的區段，相鄰機台以交錯底色分隔。
    function drawTbt(box, data) {
        var group = box.group;
        var keys = [];      // 類別值（唯一）："APAN01|2026-01-01"
        var segments = [];  // { tool, from, to }
        $.each(data, function (tool, s) {
            var from = keys.length;
            for (var i = 0; i < s.Date.length; i++) {
                keys.push(tool + '|' + s.Date[i]);
            }
            segments.push({ tool: tool, from: from, to: keys.length - 1 });
        });

        var centers = {};
        var bands = [];
        $.each(segments, function (i, seg) {
            centers[Math.floor((seg.from + seg.to) / 2)] = seg.tool;
            if (i % 2 === 1) {
                bands.push([{ xAxis: keys[seg.from] }, { xAxis: keys[seg.to] }]);
            }
        });

        var series = [];
        var legend = [];
        var paramOf = [];   // seriesIndex → 參數名稱（tooltip 用）
        $.each(segments, function (i, seg) {
            var s = data[seg.tool];
            legend.push(seg.tool);
            $.each(group.params, function (pi, param) {
                var col = s.Data[param] || [];
                var arr = new Array(keys.length);
                for (var k = 0; k < keys.length; k++) {
                    arr[k] = null;
                }
                for (var j = 0; j < s.Date.length; j++) {
                    arr[seg.from + j] = col[j] === undefined ? null : col[j];
                }
                paramOf.push(param);
                series.push({
                    name: seg.tool,
                    type: 'line',
                    data: arr,
                    connectNulls: !!group.connect,   // ini 的 connect = On：跳過空值把線連起來
                    showSymbol: false,
                    symbolSize: 8,
                    color: colorOf(seg.tool),
                    lineStyle: { width: 2, type: lineTypeOf(pi) },
                    emphasis: { focus: 'series' }
                });
            });
        });
        // 交錯底色放在一條不顯示的輔助 series 上
        series.push({
            name: '_bands',
            type: 'line',
            data: [],
            silent: true,
            markArea: { silent: true, itemStyle: { color: BAND }, data: bands }
        });

        var opt = baseOption();
        opt.grid.top = 64;
        opt.grid.bottom = 70;
        opt.legend = legendBase(legend);
        opt.tooltip.trigger = 'axis';
        opt.tooltip.axisPointer = { type: 'line', lineStyle: { color: INK_DIM, type: 'dashed' } };
        opt.tooltip.formatter = function (params) {
            var html = '';
            $.each(params, function (i, p) {
                if (p.seriesName === '_bands' || p.value === null || p.value === undefined) {
                    return;
                }
                if (!html) {
                    html = p.marker + AISLE.escape(p.seriesName) + '<br>' + AISLE.escape(String(p.name).split('|')[1]);
                }
                html += '<br>' + AISLE.escape(paramOf[p.seriesIndex]) + '：<b>' + fmt(p.value) + '</b>';
            });
            return html;
        };
        opt.xAxis = {
            type: 'category',
            data: keys,
            boundaryGap: false,
            axisLine: axisLine(),
            axisTick: { show: false },
            axisLabel: {
                color: INK,
                interval: function (idx) { return centers.hasOwnProperty(idx); },
                formatter: function (v) { return String(v).split('|')[0]; }
            },
            splitLine: { show: false }
        };
        opt.yAxis = valueAxis(group, 'tbt');
        opt.dataZoom = [
            { type: 'inside' },
            {
                type: 'slider', height: 18, bottom: 12,
                borderColor: AXIS, fillerColor: 'rgba(0,255,65,0.12)',
                handleStyle: { color: INK_DIM }, moveHandleStyle: { color: INK_DIM },
                dataBackground: { lineStyle: { color: AXIS }, areaStyle: { color: 'rgba(0,255,65,0.08)' } },
                textStyle: { color: INK_DIM },
                labelFormatter: function (i, v) { return String(v).replace('|', ' '); }
            }
        ];
        opt.series = series;
        box.chart.clear();
        box.chart.setOption(opt);

        var styles = $.map(group.params, function (p, i) {
            return shortName(p, group) + ' ' + LINE_NAMES[i % LINE_NAMES.length];
        });
        box.$el.find('.cd-box-info').text(segments.length + ' 台 · ' + keys.length + ' 個時間點 · ' + styles.join(' / '));
    }

    // ---------- 從 cache 取出各圖要的資料 ----------
    /** 只保留某組的參數 */
    function pick(s, params) {
        var out = { Date: s.Date, Data: {} };
        $.each(params, function (i, p) { out.Data[p] = s.Data[p] || []; });
        return out;
    }

    function showTbt() {
        eachBox('tbt', function (box) {
            var data = {};
            $.each(cache.tbt, function (tool, s) { data[tool] = pick(s, box.group.params); });
            show(box, data, drawTbt);
        });
    }

    /** 單台機台：從 cache.tbt 取出，不發 request */
    function showSingle() {
        var tool = $('#cd-tool').val();
        $('.cd-single-title').text(tool ? '· ' + tool : '');
        if (!cache.tbt || !tool) {
            return;
        }
        eachBox('single', function (box) {
            var data = {};
            if (cache.tbt[tool]) {
                data[tool] = pick(cache.tbt[tool], box.group.params);
            }
            show(box, data, drawSingle);
        });
    }

    /**
     * 最新值：每台每個參數在區間內最後一個非 null 的值，再依機型篩選，不發 request
     * 各參數最後一筆的日期可能不同，所以 Date 也依參數分開存：
     *   { Date: { param: [日期] }, Data: { param: [值] } }
     */
    function showNewest() {
        if (!cache.tbt) {
            return;
        }
        var model = $('#cd-model').val() || 'All';  // ini 沒設定機型時沒有下拉選單
        eachBox('newest', function (box) {
            var data = {};
            $.each(cache.tbt, function (tool, s) {
                if (model !== 'All' && CFG.models[tool] !== model) {
                    return;
                }
                var latest = { Date: {}, Data: {} };
                var any = false;
                $.each(box.group.params, function (pi, p) {
                    var col = s.Data[p] || [];
                    latest.Date[p] = [null];
                    latest.Data[p] = [null];
                    for (var i = col.length - 1; i >= 0; i--) {
                        if (col[i] !== null && col[i] !== undefined) {
                            latest.Date[p] = [s.Date[i]];
                            latest.Data[p] = [col[i]];
                            any = true;
                            break;
                        }
                    }
                });
                if (any) {
                    data[tool] = latest;
                }
            });
            show(box, data, drawNewest);
        });
    }

    // ---------- 選擇器 ----------
    function pad(n) { return n < 10 ? '0' + n : String(n); }
    function ymd(d) { return d.getFullYear() + '-' + pad(d.getMonth() + 1) + '-' + pad(d.getDate()); }
    function isDate(s) { return /^\d{4}-\d{2}-\d{2}$/.test(s); }

    function range() {
        var start = $.trim($('#cd-start').val());
        var end = $.trim($('#cd-end').val());
        var $msg = $('#cd-msg').text('');
        if (!isDate(start) || !isDate(end)) {
            $msg.text('> 日期格式需為 YYYY-MM-DD');
            return null;
        }
        if (start > end) {
            $msg.text('> 起始日期不可晚於結束日期');
            return null;
        }
        return { start: start, end: end };
    }

    /** 取日期區間內全部機台、全部參數的資料（所有圖共用），進頁面與改日期時呼叫 */
    function loadRange() {
        var r = range();
        if (!r) {
            return;
        }
        if (request) {
            request.abort();
        }
        eachBox(null, function (box) { box.chart.showLoading('default', loadingOpts()); });
        request = $.ajax({ url: CFG.urls.tbt, data: { start: r.start, end: r.end }, dataType: 'json', cache: false })
            .done(function (res) {
                cache.tbt = res || {};
                eachBox(null, function (box) { box.chart.hideLoading(); });
                showTbt();
                showSingle();
                showNewest();
            })
            .fail(function (xhr, status) {
                if (status === 'abort') {
                    return;
                }
                var msg = (xhr.responseJSON && xhr.responseJSON.error) || ('HTTP ' + xhr.status);
                eachBox(null, function (box) {
                    box.chart.hideLoading();
                    showMessage(box.chart, '> ERROR: ' + msg);
                });
            });
    }

    $(function () {
        if (!window.echarts) {
            $('.cd-chart').html('<p class="text-red">&gt; ECharts 載入失敗：請確認可連到 CDN，或執行 scripts/shell/fetch_vendor.sh 放到 public/assets/vendor/</p>');
            return;
        }
        $('.cd-box').each(function () {
            var $el = $(this);
            var kind = $el.data('kind');
            var group = GROUPS[$el.data('group')];
            boxes[kind + ':' + group.id] = {
                kind: kind,
                group: group,
                $el: $el,
                chart: window.echarts.init($el.find('.cd-chart')[0]),
                shown: {}
            };
        });

        if (!CFG.tools.length) {
            eachBox(null, function (box) { showMessage(box.chart, '> 沒有任何機台 // NO TOOLS'); });
            return;
        }

        $('#cd-filters').on('submit', function () {
            loadRange();
            return false;
        });
        $('#cd-tool').on('change', showSingle);
        $('#cd-model').on('change', showNewest);
        $('.cd-quick').on('click', 'button', function () {
            var days = parseInt($(this).data('days'), 10);
            var end = new Date();
            var start = new Date(end.getTime() - (days - 1) * 86400000);
            $('#cd-start').val(ymd(start));
            $('#cd-end').val(ymd(end));
            loadRange();
        });

        // 點最新值長條 → 切換單台機台
        eachBox('newest', function (box) {
            box.chart.on('click', function (p) {
                if (p.componentType === 'series' && p.name) {
                    $('#cd-tool').val(p.name);
                    showSingle();
                    var $first = $('.cd-box[data-kind="single"]').first();
                    if ($first.length) {
                        $('html, body').animate({ scrollTop: $first.offset().top - 80 }, 200);
                    }
                }
            });
        });

        function boxOf(el) {
            var $el = $(el).closest('.cd-box');
            return boxes[$el.data('kind') + ':' + $el.data('group')];
        }
        $('.cd-legend-all').on('click', function () {
            boxOf(this).chart.dispatchAction({ type: 'legendAllSelect' });
        });
        $('.cd-legend-none').on('click', function () {
            var box = boxOf(this);
            $.each(box.shown, function (tool) {

"""

      module:<資料夾>  → modules/<資料夾>/controller.php
      pages/xxx.php    → 檔案存在
      public/xxx.php   → 檔案存在，且第一段程式有 require auth_check.php
  - action.<動作> 的身份都有效
  - 頁面的 group 有對應的 [group.xxx]，[group.xxx] 有被頁面使用（警告）

  - 圖表（route = module:charts 的頁面）：charts/<名稱>.ini 存在且格式正確、

    charts/ 底下沒有頁面使用的 chart（警告）
  - 列出每個身份可用的頁面

用法：python scripts/python/check_config.py

from __future__ import print_function

import os
import re
import sys
from ConfigParser import RawConfigParser  # Python 2.7；RawConfigParser 不會把 % 當成變數

ROOT = os.path.abspath(os.path.join(os.path.dirname(__file__), '..', '..'))
INI = os.path.join(ROOT, 'config', 'config.ini')
MODULES = os.path.join(ROOT, 'modules')
CHARTS = os.path.join(ROOT, 'charts')
RE_CHART = re.compile(r'^[A-Za-z][A-Za-z0-9_]{0,31}$')
RE_PLOT = re.compile(r'^plot\.[a-z][a-z0-9_]{0,63}$')
RE_KEY = re.compile(r'^[a-z][a-z0-9_]{0,63}$')
RE_ACCOUNT = re.compile(r'^[A-Za-z0-9_.-]{3,64}$')

def unquote(value):
    value = value.strip()
    if not value.startswith('"'):
        value = value.split(';', 1)[0].strip()
    if len(value) >= 2 and value[0] == '"' and value[-1] == '"':
        value = value[1:-1]
    return value


def split_list(value):
    return [v.strip() for v in unquote(value).split(',') if v.strip()]


def read_array(section_name, key):
    """account[] 是 PHP 陣列語法，ConfigParser 遇到重複 key 只留最後一個，所以逐行讀"""
    values = []
    section = None
    pattern = re.compile(r'^' + re.escape(key) + r'\[\]\s*=')
    with open(INI) as fp:
        for line in fp:
            line = line.strip()
            if line.startswith('['):
                section = line.strip('[]')
            elif section == section_name and pattern.match(line):
                values.append(unquote(line.split('=', 1)[1]))
    return values


def chart_names():
    """charts/ 底下的 chart 名稱（不含 _ 開頭的範本）"""
    if not os.path.isdir(CHARTS):
        return []
    return sorted(f[:-4] for f in os.listdir(CHARTS) if f.endswith('.ini') and RE_CHART.match(f[:-4]))


def check_chart(name, errors, warnings):
    """檢查一張 chart 的 ini 與 php"""
    label = 'charts/%s.ini' % name
    parser = RawConfigParser()
    parser.optionxform = str
    try:
        with open(os.path.join(CHARTS, name + '.ini')) as fp:
            parser.readfp(fp)
    except Exception as e:  # 語法錯誤
        errors.append('%s 解析失敗：%s' % (label, e))
        return

    def get(section, key):
        return unquote(parser.get(section, key)) if parser.has_option(section, key) else ''

    source = (get('page', 'source') or 'php').lower() if parser.has_section('page') else 'php'
    if source not in ('php', 'sample'):
        errors.append('%s [page] source 只能是 php 或 sample' % label)
    for key in ('default_days', 'max_days'):
        v = get('page', key) if parser.has_section('page') else ''
        if v and (not v.isdigit() or int(v) < 1):
            errors.append('%s [page] %s 必須是正整數' % (label, key))

    plots = 0
    for section in parser.sections():
        if section == 'page':
            continue
        if not RE_PLOT.match(section):
            errors.append('%s 區段名稱錯誤：[%s]，應為 [page] 或 [plot.<小寫代號>]' % (label, section))
            continue
        plots += 1
        if not split_list(get(section, 'params')):
            errors.append('%s [%s] 沒有設定 params' % (label, section))
        for opt in parser.options(section):
            if opt.endswith('ymin') or opt.endswith('ymax'):
                v = get(section, opt)
                if v:
                    try:
                        float(v)
                    except ValueError:
                        errors.append('%s [%s] %s 必須是數字：%s' % (label, section, opt, v))
    if plots == 0:
        errors.append('%s 沒有任何 [plot.xxx] 圖' % label)

    php = os.path.join(CHARTS, name + '.php')
    if source == 'php':
        if not os.path.isfile(php):
            errors.append('charts/%s.php 不存在（尚未寫好時可先把 ini 的 source 設為 sample）' % name)
        else:
            with open(php) as fp:
                code = fp.read()
            if not re.search(r'class\s+' + re.escape(name) + r'Chart\s+extends\s+ChartSource\b', code):
                errors.append('charts/%s.php 裡找不到 class %sChart extends ChartSource' % (name, name))
            if '尚未實作' in code:
                warnings.append('charts/%s.php 似乎還沒寫好 SQL（仍有「尚未實作」），但 ini 的 source = php' % name)


def main():
    errors = []
    warnings = []

    parser = RawConfigParser()
    parser.optionxform = str  # 保留 key 大小寫（EE / PE）
    with open(INI) as fp:
        parser.readfp(fp)

    def get(section, key):
        return unquote(parser.get(section, key)) if parser.has_option(section, key) else ''

    roles = parser.options('roles') if parser.has_section('roles') else []

    # 選單分類
    groups = set()
    for section in parser.sections():
        if section.startswith('group.'):
            key = section[len('group.'):]
            if not RE_KEY.match(key):
                errors.append('[%s] 分類代號格式錯誤' % section)
            groups.add(key)
    used_groups = set()

    # 頁面
    pages = {}
    for section in parser.sections():
        if not section.startswith('page.'):
            continue
        key = section[len('page.'):]
        if not RE_KEY.match(key):
            errors.append('[%s] 頁面代號格式錯誤' % section)
            continue
        route = get(section, 'route') or ('module:' + key)
        pages[key] = route
        if route.startswith('module:'):
            target = os.path.join(MODULES, route[len('module:'):].strip(), 'controller.php')
            if not os.path.isfile(target):
                errors.append('[%s] 找不到 %s' % (section, os.path.relpath(target, ROOT)))
        else:
            target = os.path.join(ROOT, route.lstrip('/'))
            if not os.path.isfile(target):
                errors.append('[%s] route 檔案不存在：%s' % (section, route))
            elif route.lstrip('/').startswith('public/'):
                with open(target) as fp:
                    head = fp.read(4000)
                if 'auth_check.php' not in head:
                    errors.append('[%s] 獨立頁面 %s 沒有 require core/auth_check.php，任何人都能直接開啟' % (section, route))
        group = get(section, 'group')
        if group:
            used_groups.add(group)
            if group not in groups:
                warnings.append('[%s] group "%s" 沒有對應的 [group.%s]，將以代號當分類標題' % (section, group, group))
        for opt in parser.options(section):
            if opt.startswith('action.'):
                for r in split_list(parser.get(section, opt)):
                    if r not in roles:
                        errors.append('[%s] %s 的身份 %s 未定義' % (section, opt, r))

    for g in sorted(groups - used_groups):
        warnings.append('[group.%s] 沒有任何頁面使用' % g)

    # 身份 → 頁面
    access = {}
    superusers = []
    if not parser.has_section('access'):
        errors.append('缺少 [access] 區段')
    else:
        for role in parser.options('access'):
            if role not in roles:
                errors.append('[access] 身份 %s 未定義於 [roles]' % role)
            items = split_list(parser.get('access', role))
            if '*' in items:
                superusers.append(role)
                access[role] = sorted(pages.keys())
                continue
            for p in items:
                if p not in pages:
                    errors.append('[access] %s 的頁面 %s 沒有對應的 [page.%s]' % (role, p, p))
            access[role] = [p for p in items if p in pages]
    for role in roles:
        if role not in access:
            warnings.append('身份 %s 沒有寫在 [access]，登入後看不到任何頁面' % role)

    for key in sorted(pages):
        if not any(key in access[r] for r in access if r not in superusers):
            warnings.append('頁面 %s 只有 * 身份能使用（若是刻意的可忽略）' % key)

    module_dirs = set(r[len('module:'):].strip() for r in pages.values() if r.startswith('module:'))
    for name in sorted(os.listdir(MODULES)):
        if os.path.isdir(os.path.join(MODULES, name)) and not name.startswith('_') and name not in module_dirs:
            warnings.append('modules/%s 沒有登記在 config.ini，目前無法存取' % name)

    # 圖表
    names = chart_names()
    lower = {}
    for n in names:
        if n.lower() in lower:
            errors.append('charts/%s.ini 與 charts/%s.ini 只差大小寫，頁面代號會衝突' % (lower[n.lower()], n))
        lower[n.lower()] = n
    chart_pages = [k for k, r in pages.items() if r == 'module:charts']
    for key in sorted(chart_pages):
        if key not in lower:
            errors.append('[page.%s] route = module:charts，但 charts/ 裡沒有同名（不分大小寫）的 ini' % key)
        else:
            check_chart(lower[key], errors, warnings)
    for n in names:
        if n.lower() not in chart_pages:
            warnings.append('charts/%s.ini 沒有對應的 [page.%s]（route = "module:charts"），目前無法存取' % (n, n.lower()))

    # 註冊
    if parser.has_section('register'):
        for key in ('listed_role', 'unlisted_role'):
            role = get('register', key)
            if key == 'unlisted_role' and role == '':
                continue
            if role not in roles:
                errors.append('[register] %s "%s" 未定義於 [roles]' % (key, role))
            elif role in superusers:
                errors.append('[register] %s 不可設為超級身份 %s' % (key, role))
    seen = set()
    for account in read_array('ee_accounts', 'account'):
        if not RE_ACCOUNT.match(account):
            errors.append('[ee_accounts] 帳號格式錯誤：%s' % account)
        if account.lower() in seen:
            warnings.append('[ee_accounts] 帳號重複：%s' % account)
        seen.add(account.lower())

    print('== 身份可用頁面 ==')
    for role in roles:
        note = ' (*)' if role in superusers else ''
        print('  %-6s%s: %s' % (role, note, ', '.join(access.get(role, [])) or '-'))
    print('== EE 名單 (%d) ==' % len(seen))
    print('  ' + (', '.join(sorted(seen)) or '-'))
    print()
    for w in warnings:
        print(YELLOW + '[WARN]  ' + w + RESET)
    for e in errors:
        print(RED + '[ERROR] ' + e + RESET)
    if not errors:
        print(GREEN + '[OK] config.ini 檢查通過' + RESET)
    return 1 if errors else 0


if __name__ == '__main__':
    sys.exit(main())
